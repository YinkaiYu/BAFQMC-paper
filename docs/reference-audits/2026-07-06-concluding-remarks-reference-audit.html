引用策略

正文中有两类不同的引用需求。第一类是费米子 AFQMC 中“无符号问题判据可以由 HS 解耦后单体哈密顿量的全局对称性给出”的历史背景。这里引用早期核物理 AFMC、高能格点 QCD、凝聚态 AFQMC 和后来的 Majorana/semigroup 发展，目的是说明我们的 TRS/RP 判据与一个已有且成熟的费米子 QMC 传统相呼应。

第二类是 Concluding remarks 中的展望：受阻挫玻色子和自旋模型长期受局域权重 QMC 符号问题限制，但这些模型承载 supersolid、chiral Mott insulator 和 spin-liquid 等重要物理。这里的引用不是为了穷举领域，而是给读者一个可信的入口，说明 BAFQMC 打开的“frustrated but RP/TRS”区域对应真实且重要的物理问题。

建议作者重点复核的取舍

我认为这些条目元数据可靠，引用用途也基本匹配。唯一需要作者判断的是 citation cluster 的粒度：hands2000epjc 更像是“对称性与 determinant sign 关系的早期格点场论背景”，而不是一个直接的 sign-free construction 论文。如果正文句子保持现在的 broad phrasing，它可以保留；如果后续要把句子收窄为“所有这些文献都给出 sign-problem-free sufficient conditions”，则应重新评估是否保留该条。
