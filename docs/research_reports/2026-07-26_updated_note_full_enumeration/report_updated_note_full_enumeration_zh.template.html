3. 从 note 的候选条件到可检验问题

3.1 真正传播的是 \(e^A\)

note 已定义 \(h=\frac12\chi^TgA\chi\)，并把一个辅助场构型的矩阵写成 \(M=e^{A_1}\cdots e^{A_k}\)。因此 semigroup 若要约束这个构型， 必须对每个 \(e^{A_\ell}\) 给出在矩阵乘法下保持的条件。 设 \(\eta\) 是 Hermitian 且 \(\eta^2=I\)。标准 infinitesimal contraction condition 是

\[ \eta A+A^\dagger\eta\le0 . \]

对 \(e^{tA^\dagger}\eta e^{tA}\) 逐步求导：

\[ \begin{aligned} \frac{d}{dt}\left(e^{tA^\dagger}\eta e^{tA}\right) &=A^\dagger e^{tA^\dagger}\eta e^{tA} +e^{tA^\dagger}\eta e^{tA}A\\ &=e^{tA^\dagger}(A^\dagger\eta+\eta A)e^{tA}\le0 . \end{aligned} \]

从 \(t=0\) 积分到 \(1\) 得到

\[ (e^A)^\dagger\eta e^A\le\eta . \]

若两个矩阵都满足后一式，它们的乘积也满足，因为 \((M_1M_2)^\dagger\eta(M_1M_2) \le M_2^\dagger\eta M_2\le\eta\)。 这就是所需的 semigroup closure。

3.2 每一类必须回答四个问题

  1. \(J_2g\) 或 \(iJ_2g\) 是否 Hermitian 且平方为 \(I\)？
  2. 允许的 \(A\) 中是否存在 strict inequality，而不只是等号边界？
  3. \(J_1^TAJ_1=\bar A\) 是否把半负定方向保持为半负定方向？
  4. 生成元级条件是否进一步保证完整 bosonic/fermionic Fock trace 的正确符号与 branch？

前三个问题决定 propagation contraction；第四个问题才把 propagation result 升级成 sign-problem-free statement。以下先完整解决前三个问题，再单独审查第四个。

4.2 strict interior 对 \(J_2^2\) 的要求

玻色先算。由 \(g^T=-g\) 和 \(gA+A^Tg=0\)，

\[ (gA)^T=A^Tg^T=-A^Tg=gA . \]

若 \(J_2^2=-I\)，则 \(J_2^T=-J_2\)，于是

\[ \begin{aligned} \Tr(J_2gA) &=\Tr[(J_2gA)^T]\\ &=\Tr[(gA)^T J_2^T]\\ &=-\Tr(gAJ_2) =-\Tr(J_2gA). \end{aligned} \]

所以 \(\Tr(J_2gA)=0\)。乘整体 \(i\) 也仍为零。 相应 contraction matrix 的 trace 是 \(2\operatorname{Re}\Tr(\eta A)=0\)。 Hermitian matrix 若半负定且 trace 为零，只能是零矩阵。 因而玻色要有 strict interior，必须取

\[ \boxed{J_2^2=I\qquad\text{(boson)}} . \]

费米则由 \(g^T=g\) 得到

\[ (gA)^T=A^Tg=-gA . \]

若 \(J_2^2=I\)，即 \(J_2^T=J_2\)，则

\[ \begin{aligned} \Tr(J_2gA) &=\Tr[(J_2gA)^T]\\ &=\Tr[-gAJ_2] =-\Tr(J_2gA)=0 . \end{aligned} \]

因此费米要有 strict interior，必须取相反的平方：

\[ \boxed{J_2^2=-I\qquad\text{(fermion)}} . \]

这一步直接解释了合作者所说的“玻色子和费米子并不对等”。 差别来自 \((gA)^T\) 在两种统计下一个对称、一个反对称。

4.3 commutator/anti-commutator 为什么不能忽略

现在只考虑上一小节允许 strict interior 的情形： 玻色 \(J_2^2=I\)，费米 \(J_2^2=-I\)。 对 \(J_2^TgJ_2=\pm g\) 的两种分支，分别使用上一表给出的 \(J_2g\) 或 \(iJ_2g\)。把 \(J_1^TAJ_1=\bar A\) 代入 contraction matrix，并逐项移动 \(J_1,J_2,g\)，得到四种直接结果：

\(J_1\) 对 \(g\) 的作用 \(J_2\) 对 \(g\) 的作用 保持半负定方向所需关系 另一种关系的结果
\(J_1^TgJ_1=g\)\(J_2^TgJ_2=g\) \(\{J_1,J_2\}=0\)\([J_1,J_2]=0\) 只剩等号边界

规律可以用一句与 note 完全对齐的话表达： \(J_1\) 与 \(J_2\) 若同为保持 \(g\) 或同为翻转 \(g\)，二者必须反对易； 若一个保持 \(g\)、另一个翻转 \(g\)，二者必须对易。 \(J_1^2=I\) 或 \(-I\) 不影响这一步，所以这两个选择会成对出现。

为什么选错 commutation relation 会只剩边界？设正确的 Hermitian metric 为 \(\eta\)，并记 contraction matrix 本身为 \(\eta A+A^\dagger\eta\)。对于表中“另一种关系”，直接代入得到

\[ J_1^T\overline{\left(\eta A+A^\dagger\eta\right)}J_1 =-\left(\eta A+A^\dagger\eta\right). \]

左边只是复共轭加正交基变换，保持 eigenvalue signs； 右边却把所有 eigenvalues 变号。一个 matrix 不可能同时 strict seminegative 和 strict semipositive，所以只能等于零。

4.4 两条要求不仅必要，而且给出显式 strict point

按上一节选择 \(J_2^2\)，再按表中规则选择 commutator 或 anti-commutator。 令 \(\eta\) 为对应的 \(J_2g\) 或 \(iJ_2g\)，并直接取

\[ A_0=-\eta . \]

由 \(\eta^\dagger=\eta\) 与 \(\eta^2=I\)，contraction inequality 不是边界而是严格成立：

\[ \eta A_0+A_0^\dagger\eta =-\eta^2-\eta^2=-2I<0 . \]

再把 \(A_0=-\eta\) 代回，所选 \(J_2\) 关系保证 \(gA_0+A_0^Tg=0\)；上一小节的 commutation rule 保证 \(J_1^TA_0J_1=\bar A_0\)。因此这不是随机扫描中的“似乎通过”， 而是每一个允许类别都有明确 strict witness。

传播层面的完整判据。 玻色 strict contraction 要求 \(J_2^2=I\)，费米要求 \(J_2^2=-I\)。 在此基础上，\(J_1\) 与 \(J_2\) 若对 \(g\) 同号作用就必须反对易， 异号作用就必须对易。\(J_1^2=\pm I\) 均可。 \(J_2\) 翻转 \(g\) 时使用 metric \(J_2g\)； \(J_2\) 保持 \(g\) 时使用 metric \(iJ_2g\)。

7. 费米候选与完整权重

7.1 note 的费米不等式不是标准 \(e^A\) contraction

note 的权重公式依赖 \(M=\prod_\ell e^{A_\ell}\)，但第一节写的是

\[ iJ_2gA-iA^\dagger J_2g\le0 . \]

若 metric 是 \(\eta=iJ_2g\)，对 \(e^A\) 求导真正出现的是

\[ \eta A+A^\dagger\eta =iJ_2gA+iA^\dagger J_2g . \]

两式第二项符号相反。Wei 的 Majorana semigroup theorem 可以使用另一种 matrix convention，但从 Majorana basis 变到当前 Nambu basis 时， quadratic form、complex conjugation rule 与 propagation generator 必须一起变换。只搬运一个 inequality 不能保证等价。

7.2 一模精确反例

取 note 使用的费米 Nambu convention，并令

\[ g=\sigma_x,\qquad J_1=\sigma_x,\qquad J_2=i\sigma_y,\qquad A=iy\sigma_z . \]

逐项计算：

\[ J_1^TAJ_1=\bar A,\qquad iJ_2gA-iA^\dagger J_2g=-2yI<0\quad(y>0). \]

然而 many-body quadratic operator 与完整 Fock trace 是

\[ h=iy\left(n-\frac12\right),\qquad W(y)=\Tr e^h =e^{-iy/2}+e^{iy/2} =2\cos\frac y2 . \]

当 \(y=\pi\) 时 \(W=0\)，当 \(y=2\pi\) 时 \(W=-2\)。 所以 note 的 inequality 即使 strict，也没有阻止 Fock weight 过零并变负。

7.3 无 pairing 的多时间片反例

对与 note \(9'\) 相同的离散矩阵关系，可以完全去掉 pairing blocks， 取三个 number-conserving slices：

\[ B_1=-2\sigma_x-2\sigma_z,\qquad B_2=-2\sigma_x,\qquad B_3=2\sigma_x+\sigma_z . \]

程序逐 slice 验证相应等式 residuals 为零，但完整 determinant 为

\[ W=\det(I+e^{B_1}e^{B_2}e^{B_3}) =-24.1885664042699 . \]

把三个 \(B_\ell\) 同时乘连续参数 \(t\)，从 \(t=0\) 的正权重出发， 在 \(t=0.80967485393694\) 穿过零。因此这个负号不是 square-root 选择造成的孤立数值异常，而是与正参考点连续相连的实际 zero crossing。

证据边界。 本报告的解析判据严格证明 propagation contraction 的分类。 对玻色文章要进一步使用它，还需证明 bosonic Fock trace 收敛、无 pole， 并固定连续 square-root branch。对费米，note 当前写出的 inequality 已被上面的精确反例排除为 Nambu weight 的充分条件。

8. 对文章的影响

当前文章的主线是 bosonic AFQMC：time-reversal symmetry 通过 anti-linear pairing 控制权重，reflection positivity 通过反射关系和正锥控制权重； Fig. 1 再按是否存在 TRS/RP 与 lattice frustration 组织可计算区域。 因此更新 note 不能以“新列表”直接替换现有主线，必须先分清 propagation theorem、 full-weight theorem 和 physical HS realization。

8.1 可以吸收进 Supplemental Material 的内容

  • 用本报告第 4 节的直接玻色推导说明：strict contraction 要求 \(J_2^2=I\)。
  • 明确 \(J_2^TgJ_2=-g\) 时使用 metric \(J_2g\)，\(J_2^TgJ_2=g\) 时使用 metric \(iJ_2g\)。
  • 把 commutation rule 写成与 note 对齐的语言：\(J_1,J_2\) 对 \(g\) 同号作用时反对易，异号作用时对易。
  • 给出 \(A_0=-\eta\) 的 strict witness，并把生成元条件推到 \((e^A)^\dagger\eta e^A\le\eta\)。

8.2 在写入主文前仍需完成的工作

  • 为新增的 \(iJ_2g\) 玻色类证明完整 bosonic Fock trace 无 pole、branch 连续且非负。
  • 构造一个标准 HS decoupling 后自然落入新类的 physical Hamiltonian，而不是只给抽象 Pauli representatives。
  • 确认该 physical example 不已经被现有 TRS 或 reflection positivity criterion 覆盖。
  • 完成 numerical benchmark 后，再判断是否需要改变 Fig. 1 或主文 novelty framing。

8.3 现在不应写入文章的表述

  • 不应写“玻色有 7 个 passed cases、费米有 8 个 passed cases”，因为这些数字混合了不同判据与未证明候选。
  • 不应写 commutator/anti-commutator 无关；它决定 strict cone 是否存在。
  • 不应把 note 的费米 inequality 称为当前 Nambu weight 的充分条件。
  • 不应仅凭 64 类抽象矩阵穷举就重画文章的物理分类图。

9. 最终结论

完整覆盖 note 更新 note 第 22--1939 行已经按原顺序分成 43 个单元。 每段原文均在本报告内渲染，并紧跟公式讲解与必要的推导补全。
完整穷举 玻色、费米各 32 类都找到 real Pauli-product representatives。 每种统计各有 8 个 strict propagation classes，其中 4 个使用 \(J_2g\)，4 个使用 \(iJ_2g\)。
Comment commutator/anti-commutator 确实重要。 两个 \(J\) 对 \(g\) 同号作用时必须反对易，异号作用时必须对易。
需要修正的主张 玻色 Case 10 标题下的 matrices 实际属于 Case 6；abstract Case 10 没有 strict interior。 note 的费米 inequality 在当前 Nambu convention 下不能保证完整 Fock weight 非负。

合作者关于 \(iJ_2g\) 伙伴类的提醒是实质性的，因为它补上了每种统计 8 个 strict propagation classes 中的一半。对文章最有价值的下一步不是继续手写更多 block matrices，而是把其中一个新玻色类实现为 physical HS problem， 并完成从 propagation contraction 到 pole-free、nonnegative Fock weight 的证明与 benchmark。
