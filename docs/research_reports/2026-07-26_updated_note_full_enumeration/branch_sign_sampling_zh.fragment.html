玻色 Gaussian AFQMC 的 double-cover 符号追踪与采样

本卷讨论一个与主报告的无符号证明分开的算法问题：当一个一般 Gaussian 辅助场模型确实有正负权重时，怎样在只保存 Nambu 传播矩阵的计算中恢复、更新并采样被平方根公式丢掉的那一个符号。

1. 问题从哪里出现

对一个固定辅助场构型，把全部虚时间片的 Nambu 传播矩阵按实际顺序 相乘，记为 \(M\)。相应的 Fock-space Gaussian operator 还含一个 正规序或常数项产生的 scalar \(e^\xi\)。在不碰到 \(\det(I-M)=0\) 时，玻色 Gaussian trace 满足

\[ W=\operatorname{Tr}_{\rm Fock}\hat{\mathcal U} =\frac{e^\xi}{\sqrt{\det(I-M)}} . \]

这里的平方根不能只按终点复数的 principal square root 计算。 原因是：从 Fock-space Gaussian operator 到 classical Nambu transformation \(M\) 的映射是 two-to-one。两个相差整体负号的 Fock operators 作用在 \(\chi\) 上产生完全相同的 \(M\)，但它们的 trace 相差负号。这个 two-to-one 结构通常称为 double cover。

因而最终的 \(M\)、\(\det(I-M)\) 和普通 Green matrix \((I-M)^{-1}\) 都不足以重建 \(W\) 的符号。实际 AFQMC operator 是由一串 elementary exponentials 按次序定义的，所以符号 并非任意；必须连同这条 operator path 一起保存。

2. 沿一条无 pole 路径唯一恢复权重

令 \(t\in[0,1]\) 连续参数化一次辅助场更新，并把对应量写成 \(M(t),\xi(t),W(t)\)。假定整条路径上 \(\det[I-M(t)]\ne0\)。先对 determinant 求导：

\[ \begin{aligned} \frac{d}{dt}\log\det[I-M(t)] &=\operatorname{Tr}\!\left[ (I-M)^{-1}\frac{d(I-M)}{dt}\right]\\ &=-\operatorname{Tr}\!\left[(I-M)^{-1}\dot M\right]. \end{aligned} \]

这里的 \(\log\) 表示沿路径连续延拓的 logarithm，不是在每个 \(t\) 独立调用 principal logarithm。代入 \(W=e^\xi[\det(I-M)]^{-1/2}\)，得到

\[ \frac{d}{dt}\log W(t) =\dot\xi(t) +\frac12\operatorname{Tr}\!\left[(I-M)^{-1}\dot M\right]. \]

从已知符号的参考点 \(t=0\) 积到新构型 \(t=1\)，便得到沿实际 算符路径连续确定的权重。下文把它简称为“路径定支权重”：

\[ W(1)=W(0)e^{\xi(1)-\xi(0)} \exp\!\left\{ \frac12\int_0^1dt\, \operatorname{Tr}[(I-M)^{-1}\dot M] \right\}. \]

同一结果也可写成终点 principal logarithm 乘一个额外的 \(\mathbb Z_2\) 变量：

\[ W=e^\xi\,\sigma_{\rm lift} \exp\!\left[-\frac12 \operatorname{Log}_{\rm principal}\det(I-M)\right], \qquad \sigma_{\rm lift}=\pm1 . \]

若连续 determinant path 相对 principal argument 多绕原点一圈， 连续 logarithm 多出 \(2\pi i\)，上式的 inverse square root 就多出 \(e^{-\pi i}=-1\)。所以真正需要记录的是 determinant path 的 winding parity，而不是重新猜测终点平方根。

4. Local update 不需要重算大 determinant

设旧传播矩阵已经按更新位置分成 \(M_0=LR\)。一次局域更新只作用在 \(r\) 个物理 modes，也就是 \(2r\) 维 local Nambu space。令 \(E\) 把这个局域空间嵌入完整 Nambu space，令 \(D(t)\) 是从 \(D(0)=I\) 连续变到新局域因子的路径。完整更新路径写成

\[ M(t)=L\left[I+E(D(t)-I)E^T\right]R, \qquad M(0)=LR=M_0 . \]

旧 Green matrix 与一个 \(2r\times2r\) reduced matrix 为

\[ G=(I-M_0)^{-1},\qquad C=E^TRGLE . \]

从 \(I-M(t)=I-M_0-LE(D-I)E^TR\) 使用 matrix determinant lemma， 得到精确的小矩阵公式

\[ \frac{\det[I-M(t)]}{\det(I-M_0)} =\det\!\left[I_{2r}-(D(t)-I_{2r})C\right]. \]

所以 determinant path、它是否接近 pole、以及连续 logarithm 的导数 都可在 \(2r\) 维空间计算：

\[ \frac{d}{dt}\log \frac{\det[I-M(t)]}{\det(I-M_0)} = -\operatorname{Tr}\!\left[ \bigl(I-(D-I)C\bigr)^{-1}\dot D\,C \right]. \]

令这个小 determinant 在终点的值为 \(z_{\rm end}\)，并对上式积分。 数值上用 \(\log|z_{\rm end}|\) 固定连续 logarithm 的实部，用积分的 imaginary part 保存没有取模 \(2\pi\) 的全部绕数。若这次局域更新还使 scalar 改变 \(\Delta\xi\)，权重比就是

\[ \frac{W_{\rm new}}{W_{\rm old}} = \exp\!\left[ \Delta\xi-\frac12 \left\{\log|z_{\rm end}| +i\,\operatorname{Im}\!\int_0^1dt\, \frac{d}{dt}\log z(t)\right\} \right]. \]

接受更新后，完整 \(G\) 也可用 Woodbury identity 精确更新。记 \(D(1)-I\) 为终点局域差值，则

\[ \begin{aligned} G_{\rm new}=G +GLE(D(1)-I) \left[I-C(D(1)-I)\right]^{-1}E^TRG . \end{aligned} \]

对固定的 \(r\)，形成 \(C\) 和更新完整 \(G\) 的主要代价是 \(O(N^2r)\)，路径积分每次只解 \(2r\) 维线性方程。实现文件 boson_branch_low_rank_update.m 已包含 determinant lemma、连续相位积分、Woodbury update、 endpoint pole check 与路径最小 determinant 诊断。

6. 放进 Metropolis sampling 的完整步骤

以下算法采样一般有符号或有复相位的 Gaussian 模型。它准确记录符号， 但不会神奇地消除平均符号随系统尺寸下降的统计困难。

  1. 选择一个能够直接在 Fock space 或从 elementary factors 确定 \(W_{\rm ref}>0\) 的参考构型。保存其 \(M,G,\xi\) 以及 \(\sigma_{\rm lift}=+1\)。
  2. 对一次局域辅助场 proposal，使用实际 elementary slice 的连续变化 构造 \(D(t)\)。不能用与 operator update 无关的任意闭合路径，因为 lift 属于实际有序 operator product。
  3. 用上一节的小矩阵积分算出完整复权重比 \(R_W=W_{\rm new}/W_{\rm old}\)，其中已经包括正规序 scalar \(e^{\Delta\xi}\) 与 double-cover 符号。
  4. 把 Gaussian HS density、proposal probability 的正反向比和 \(R_W\) 合成 \(R_{\rm total}\)。以 \[ P_{\rm accept}=\min(1,|R_{\rm total}|) \] 决定是否接受。
  5. 若接受，更新 \(M,G,\xi\)，并把已存 phase 乘以 \(R_{\rm total}/|R_{\rm total}|\)。对实权重，这一步只更新 \(\pm1\)；若 proposal 拒绝，所有状态保持不变。
  6. 测量时使用标准重加权 \[ \langle O\rangle =\frac{\langle e^{i\varphi}O\rangle_{|W|}} {\langle e^{i\varphi}\rangle_{|W|}} . \] 分母同时给出平均 sign/phase，是算法统计可行性的直接诊断。

7. Pole、数值稳定与周期性重建

若小 determinant \(\det[I-(D(t)-I)C]\) 在路径上为零，则 \(\det[I-M(t)]=0\)，玻色 bare trace 在该中间构型发散。此时不能把 它当成普通的 sign flip 跨过去。对本文的 pole-free 半群， 这种情况由解析不等式排除。在一般模型中，若物理辅助场积分路径本身 穿过这个发散点，就必须回到该模型的积分轮廓或正则化定义处理； 不能把该步作为有限权重的 Metropolis 更新接受，也不能仅靠改变 square-root branch 隐去 divergence。

长虚时间乘积会产生极端尺度分离，所以实现同时采用两级校验：

  1. 每次 local update 用 reduced determinant 的最小 singular value 与 adaptive path subdivision 检查是否接近 pole。
  2. 经过固定数量的接受更新后，从保存的 elementary factors 使用 QR/SVD-stabilized multiplication 重建 \(M,G\)，并从已知 reference 沿实际 factor path 重新积分 lift。随后比较累计 phase、determinant ratio 与 Green residual；超过容差的 Markov state 不进入测量。

周期性重建不是用 principal square root 覆盖累计符号；它重放同一条 elementary-operator path，所以得到的是对累计 lift 的独立复算。

8. 与 PfQMC 的关系

Han、Wan、Yao 的 PfQMC 处理 fermionic Gaussian operators。其核心关系可写成 \[ \operatorname{Tr}\hat O=2^N\eta,\qquad 2^{2N}\eta^2=\det(I+B), \] 并用 Pfaffian product formulas 恢复 determinant square 丢失的 Gaussian-operator sign。公开 PfQMC code 在局域更新接受后把权重比的 phase 乘进已存 sign，并周期性从完整 operator string 重算；本报告核对的 repository commit 是 50b597e7f634298ae5b93aa7afe992405fbdcd5e。

本卷沿用的是同一数值设计原则，而不是直接移植 fermionic Pfaffian 公式：更新时保存被 classical matrix representation 丢掉的 lift， 用 \(|W|\) 做接受率，用保存的 sign/phase 重加权，并周期性完整复算。 玻色问题的区别是权重含 inverse square root，而且 \(\det(I-M)=0\) 是发散 pole。因此这里用连续 logarithm 与 reduced determinant path，而不是把 fermionic Pfaffian 公式换一个符号。

9. 本卷得到的结论

符号可唯一计算 只要 elementary operator path 已知且不经过 pole，连续 determinant logarithm 与正规序 scalar 唯一确定真实 Fock trace，不需要指数复杂度 枚举 Fock basis。
局域更新所需量均已有封闭公式 determinant ratio、连续绕数、Green matrix 与接受率都可由 \(2r\) 维 reduced matrices 更新；Octave rank-2 test 对 \(0,2\pi,4\pi\) 给出 \(+,-,+\)。
与主报告分开 主报告的 sign-free classes 依靠半群、实性与正参考点证明 \(\sigma_{\rm lift}=+1\)；本卷用于一般有符号模型中显式采样 \(\sigma_{\rm lift}\)，二者不是同一个论证。
