9. 对文章的影响

当前文章的主线是 bosonic AFQMC：time-reversal symmetry 通过 anti-linear pairing 控制权重，reflection positivity 通过反射关系和正锥控制权重； Fig. 1 再按是否存在 TRS/RP 与 lattice frustration 组织可计算区域。 因此更新 note 不能以“新列表”直接替换现有主线，必须先分清 propagation theorem、 full-weight theorem 和 physical HS realization。

9.1 可以吸收进 Supplemental Material 的内容

  • 用本报告第 5 节的直接玻色推导说明：strict contraction 要求 \(J_2^2=I\)。
  • 明确 \(J_2^TgJ_2=-g\) 时使用 metric \(J_2g\)，\(J_2^TgJ_2=g\) 时使用 metric \(iJ_2g\)。
  • 把 commutation rule 写成与 note 对齐的语言：\(J_1,J_2\) 对 \(g\) 同号作用时反对易，异号作用时对易。
  • 给出 \(A_0=-\eta\) 的 strict witness，并把生成元条件推到 \((e^A)^\dagger\eta e^A\le\eta\)；同时明确该 witness 只证明 cone 非空，玻色物理模型还必须有稳定零场锚点，并确认同一个 metric direction 确实压低高占据态。

9.2 对现有文章最直接的修改方向

  • 在 SM 的 “Trace convergence” 或 “Infinite variance and determinant poles” 中，把 7 月 19 日报告的 paired \(\eta\)-contraction proposition 与绝对收敛证明放在现有 number-conserving condition 之后。
  • 在 proposition 前先说明 \(J_1K\) 是文章的 \(b\leftrightarrow c\) reflection，\(J_2g=\operatorname{diag}(I,-I)\) 是 particle/hole signature，避免只给抽象 matrices。
  • 把论证写完整：稳定零场给出收敛正权重；所有 real \(U_2\) histories 位于同向 strict oscillator-semigroup interior，故 fixed-field traces 都绝对收敛；\(J_1\) 实性条件、正实的正规序标量因子与连通性随后推出 \(W(\phi)>0\)。
  • 说明 RP 与 semigroup 是两条独立证明。RP 使用 positive reflected coupling；semigroup 使用稳定锚点、正确 metric 取向和 strict propagation。当前 benchmark 同时满足两者，但后者并非只有 pole-free 作用。
  • 主文可在 paired benchmark 段末用一至两句指出这条独立的 semigroup sign-free route；完整的 trace-class/绝对收敛、连通性和 branch proof 留在 SM。

9.3 若要声称发现新的 sign-free class，仍需完成什么

  • 对新增 \(iJ_2g\) 玻色类，找到 bare trace 收敛的稳定零场 Hamiltonian，并证明 candidate metric 的 strict direction 确实压低该 Fock space 的高占据态；否则该 strict cone 只能算代数候选。若改用 regularization，还需独立证明它重现原物理 trace。
  • 本报告已给出标准 \(UO^2/2\) Gaussian HS slice candidate；下一步要证明它从稳定零场出发且完整时空场域始终留在同一个 trace-convergent strict interior，而不是再找一个抽象 Pauli representative。
  • 确认该 physical example 不已经被现有 TRS 或 reflection positivity criterion 覆盖。
  • 完成 numerical benchmark 后，再判断是否需要改变 Fig. 1 或主文 novelty framing。

10. 最终结论

完整覆盖 note 更新 note 第 22--1824 行已经按原顺序分成 42 个单元。 每段原文均在本报告内渲染，并紧跟公式讲解与必要的推导补全。
与文章物理判据的对应 physical Kramers TRS 由 \(J_1K\) 表示；RP 的 \(J_1K\) 交换 \(b,c\) reflected sectors，真正的 positivity 还来自正半定跨区耦合。 两者都不能被缩写成一组未解释的 \(J\)-matrix relations。
五条式子的地位 它们分别记录 \(J_1,J_2\) 对 \(g\) 的作用、各自的平方以及二者的 对易关系，是 \(2+2+1\) 个离散分类标签。真正限制 propagation 的仍是 \(J_1^TAJ_1=\bar A\) 与 \(\eta A+A^\dagger\eta\leq0\)； 五条关系本身不是无符号定理。
Yinkai's Case 7 的当前作用 对 strictly stable \(U_1=0\) paired benchmark，它与 7 月 19 日 \(\eta\)-contraction proof 完全对应。标准 oscillator-semigroup interior 保证逐构型 bare trace 收敛；\(J_1\)、正规序标量因子、 连通场域和正零场锚点再保证全域正权重。RP 是同一模型的 另一条独立证明。
完整穷举 玻色、费米各 32 类都找到 real Pauli-product representatives。 每种统计各有 8 个 strict propagation classes，其中 4 个使用 \(J_2g\)，4 个使用 \(iJ_2g\)。相对于 note 固定一种 \(J_2\) 的手算，玻色和费米两侧都各补出 4 个 \(iJ_2g\) classes； 16 类的 maximal-subgroup 与 invariant-cone basis 均已完整求出。
稳定锚点 + strict + 连续性 若零场 bare trace 收敛，整个连通辅助场域落在同一个能压低 高占据态的 strict oscillator semigroup，\(J_1\) 使权重为实且 operator branch 连续单值，则所有构型的 trace 都收敛并保持正号。
物理 HS 构造 note 的四个玻色 \(J_2g\) 类已有稳定 Hermitian current-square/relative-density-square models；费米侧给出了 bounded discrete cone field 与已知 Kramers-pairing models。 新增玻色 \(iJ_2g\) 类已有 Hermitian slice candidates，但普通 grand-canonical number-conserving realization 受 mixed-sign single-particle spectrum 阻碍。
Comment commutator/anti-commutator 确实重要。 两个 \(J\) 对 \(g\) 同号作用时必须反对易，异号作用时必须对易。
新版修正与剩余问题 Case 10 的 representative 和 Failed 标签现已与解析分类一致。 但 note 的费米 inequality 在当前 Nambu convention 下仍不能保证完整 Fock weight 非负， 新增的 “\(1'\) 是 \(9'\) special case” 也不消除这一反例。

合作者关于 \(iJ_2g\) 伙伴类的提醒是实质性的，因为它在玻色和费米两侧 都补上了 8 个 strict propagation classes 中尚未手算的 4 个。 本次已经不再停在 \(A_0=-\eta\)：16 类的 subgroup/cone bases 与五组 HS slices 都由 Octave 逐项验证。对连通 auxiliary-field space， 与稳定零场同向的 strict contraction 保持 bare-trace convergence， 权重为实、分支连续且单值，再加上正参考点，便可固定全域正号。 当前最清楚的文章用途是把 Case 7 写成 paired benchmark 的一条独立 semigroup sign-free theorem，而不是只称为 RP 的 pole-free 补充。 新增玻色 \(iJ_2g\) 类的下一步不是再证一遍“strict 区域不会变号”， 而是找到与其 candidate metric 相容且 fixed-field bare trace 有定义的 stable Hamiltonian；否则只能保留为代数分类。费米 \(iJ_2g\) 类已有 Majorana RP/Kramers-pairing realizations；需要做的是写清它们与 当前 Nambu 五位标签的变换，并判断哪些只是已知类的换基或 particle--hole partner。

我把你说的五个二选一关系在玻色、费米两边各 32 类都穷举完了。 穷举的目标不只是找 \(J_1,J_2\) 或 maximal subgroup，而是检查 \(J_1^TAJ_1=\bar A\) 的实性条件能否与由 \(J_2g\) 或 \(iJ_2g\) 定义的 invariant cone 同时成立，并确认 cone 中有严格小于零的生成元。我也把每个通过类的全部 maximal-subgroup generator basis 和 invariant-cone generator basis 求出来了，不再只用 \(A_0=-\eta\) 作一个存在性见证。

穷举中玻色、费米各 32 类都能找到 real Pauli-product \(J_1,J_2\) representatives，但每边都只有 8 类存在 strict contraction interior。玻色严格要求 \(J_2^2=I\)，费米严格要求 \(J_2^2=-I\)。\(J_1,J_2\) 对 \(g\) 同号作用时必须反对易， 异号作用时必须对易；\(J_1^2=\pm I\) 都可以。

玻色方面，你手算的 Cases 5--8，也就是 metric 为 \(J_2g\) 的四类， 全部通过；你标为 Failed 的其他 contraction cases 也与穷举一致。 另外确实还有你消息里提到但 note 未列出的四个 \(iJ_2g\) partner classes。它们共同满足 \(J_2^TgJ_2=g,\ J_2^2=I\)：若 \(J_1\) 保持 \(g\)， \(J_1,J_2\) 必须反对易；若 \(J_1\) 翻转 \(g\)，二者必须对易； \(J_1^2=I\) 与 \(-I\) 都允许。这四类都有显式 strict witness。 所以相对现有手算，新增的代数结果是把这四类系统补齐，并给出 8 个 strict classes 的完整 subgroup/cone structures。

对 physical HS realization，我找到两个稳定的 Hermitian 原模型。 Case 5 可由 \(H=\kappa(n_1+n_2)+\frac U2[i(a_1^+a_2-a_2^+a_1)]^2\) 产生；连续 Gaussian field 耦合到 maximal-subgroup current direction，\(\kappa>0\) 提供 strict contraction。 Cases 6、7、8 可由同一个 \(H=\kappa(n_b+n_c)+\frac U2(n_b-n_c)^2\) 的 relative-density HS slices 同时实现，说明这些五位标签并不是互斥的 physical classes。 对这两个 number-conserving families，普通单粒子 contraction、 \(J_1\) 实性条件和零场正参考点已经给出完整正权重证明。

对新补的玻色 \(iJ_2g\) branch，也能写出 Hermitian quadratic \(A_0=-\eta\) 和由 \(UO^2/2\) 产生的合法 Gaussian HS field， 所以它们并非只能对应 non-Hermitian slices。但是在目前最直接的 number-conserving representation 中，contraction inequality 强迫单粒子 \(B\) 在 \(\eta=+1\) sector 非正、在 \(\eta=-1\) sector 非负，因此不可能全负；\(A_0\) 的谱必有正、负两支， bare grand-canonical boson trace 发散。fixed gauge 若保持同一 metric 不能改变这个惯性。含 pairing、canonical ensemble 或可靠 regularization 是否能绕开这一障碍，还需要继续做。这个 \(A_0=-\eta\) 只是证明抽象 cone 非空；它没有 trace-convergent 零场锚点，所以不处于我们实际从稳定自由 Hamiltonian 出发的 连续 HS 分支上。

费米方面，在由 \(e^A\) 直接导出的标准 contraction condition \(\eta A+A^\dagger\eta\leq0\) 下，你已经展开的 \(J_2^TgJ_2=-g,\ J_2^2=-I\) 分支中，Cases \(5'\)--\(8'\) 是四个 strict \(J_2g\) classes。完整穷举还补出了四个 \(J_2^TgJ_2=g,\ J_2^2=-I\)、metric 为 \(iJ_2g\) 的 strict partner classes：\(J_1\) 保持 \(g\) 时二者反对易， \(J_1\) 翻转 \(g\) 时二者对易，且 \(J_1^2=\pm I\) 都允许。 不过你 note 中的式子 \(iJ_2gA-iA^\dagger J_2g\) 是 \(X=gA\) 与 metric \(iJ_2\) 上的 contraction；它不等于当前 Nambu propagation \(e^A\) 的 contraction。对你已展开的 \(J_2^TgJ_2=-g,\ J_2^2=-I\) 分支，直接控制 \(e^A\) 应使用 Hermitian metric \(J_2g\) 与 \(J_2gA+A^\dagger J_2g\le0\)。因此原有 Passed 标签不能和这八类 直接合并计数。另一支 metric 为 \(iJ_2g\) 的标准 cone 是 physical pairing direction，maximal subgroup 可包含 number-conserving hopping/density；它与 Wei semigroup paper 的 Majorana reflection-positive/Kramers-plus-pairing models 对应。 \(J_1\) 翻转 \(g\) 的 partners 可由 particle--hole transformation 得到。因此这里有 concrete physical models，但这四个 Nambu labels 中哪些是文献上真正的新类、哪些只是已知类换基，需要先把 Majorana-to-Nambu transformation 写全。

关于符号与收敛证明，我的理解与你的半群思路一致，但应把零场锚点 明写出来：只要 auxiliary-field configuration space 连通，零场 bare trace 收敛，所有构型都在同一个能压低该 Fock space 高占据态的 strict oscillator semigroup，且 \(J_1\) 与正规序标量因子 共同使 operator weight 为实并连续单值，那么 strict interior 先保证每个 fixed-field operator 都是 trace class，再由零场正权重推出整个辅助场积分域恒正。 不需要逐构型检查。连通性单独还不够；新增玻色 \(iJ_2g\) witness 当前缺的正是稳定零场锚点与正确 metric 取向。
