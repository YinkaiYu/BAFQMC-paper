0. 阅读前先认识物理对象

0.1 辅助场构型为什么会变成矩阵乘积

辅助场量子蒙特卡洛（auxiliary-field quantum Monte Carlo，AFQMC）先用 Hubbard--Stratonovich（HS）变换把二体相互作用改写成对辅助场的积分。 对每一个固定的辅助场构型，粒子只经历一系列二次算符，因此可以用有限维矩阵计算。 每个虚时间片都只含一个二次算符。 note 把第 \(\ell\) 个时间片写成

\[ h_\ell=\frac12\chi^TgA_\ell\chi. \]

\(\chi\) 把所有湮灭算符和产生算符排成同一列。这种把粒子与空穴分量放在一起的写法称为 Nambu 表示。矩阵 \(g\) 记录这些算符的对易关系； \(gA_\ell\) 是直接出现在二次算符中的系数。真正作用在单粒子或 Nambu 空间上的传播则是 \(e^{A_\ell}\)。一个完整辅助场构型对应

\[ M=e^{A_1}e^{A_2}\cdots e^{A_k}. \]

所以讨论极点、零点或传播收缩时必须控制 \(A_\ell\) 和 \(M\)，不能把 \(A_\ell\) 与二次型系数 \(gA_\ell\) 当成同一个矩阵。

一个构型的 Monte Carlo 权重是这些二次算符在完整多体 Hilbert 空间中的迹 \(\Tr(e^{h_1}\cdots e^{h_k})\)。这里“Fock 迹”就是对所有允许占据数态求迹： 费米单轨道只有空、占据两态；玻色单轨道还包含任意非负占据数，因此额外涉及迹是否收敛。

0.2 玻色与费米只在 \(g\) 的转置性质上先分开

为了暂时用同一套公式，记

\[ g^T=\tau g,\qquad g^2=\tau I, \qquad \tau=-1\ {\rm (boson)},\quad \tau=+1\ {\rm (fermion)}. \]

玻色 \(g\) 是反对称矩阵，费米 \(g\) 是对称矩阵。 允许的传播生成元满足 \(gA+A^Tg=0\)，这样二次算符的对易子仍对应同类矩阵。

0.3 两个 \(J\) 分别承担什么任务

第一个实正交矩阵 \(J_1\) 与复共轭一起作用。条件 \(J_1^TAJ_1=\bar A\) 让传播矩阵中的复数成共轭配对，因此它负责“现实性”。

第二个实正交矩阵 \(J_2\) 用来构造一个 Hermitian 矩阵 \(\eta\)。 如果每个时间片满足

\[ H_\eta(A)\equiv\eta A+A^\dagger\eta\leq0, \]

那么 \(e^A\) 在 \(\eta\) 所定义的二次型下不会增长。这种生成元集合在指数化后对乘法封闭， 因而称为收缩半群。若不等式严格为负定，就称该时间片位于收缩区域的严格内部； 若只能等于零，则只位于边界。

0.4 五个正负号只是关系记录

note 反复改变的五个正负号定义为

\[ J_a^TgJ_a=s_ag,\qquad J_a^2=q_aI,\qquad J_1J_2=rJ_2J_1,\qquad s_a,q_a,r=\pm1. \]

\(s_a\) 表示 \(J_a\) 保持还是翻转 \(g\)，\(q_a\) 表示 \(J_a\) 的平方， \(r=+1\) 表示对易，\(r=-1\) 表示反对易。五个二值选择共有 \(2^5=32\) 种。 这些符号只是分类标签，不是新的物理场或算符。

0.5 “矩阵代表存在”和“无符号”之间还有距离

为某组正负号写出 \(J_1,J_2\)，只说明这一代数关系可以实现。 接下来还要检查 \(\eta\) 是否 Hermitian、允许的 \(A\) 中是否有严格收缩方向、 收缩是否控制实际传播 \(e^A\)，最后还要把传播结论与完整 Fock 迹的现实性和连续分支结合。 以下各节就按这个顺序逐层检查。

0.6 note 提到的三种既有语言

时间反演对称性（time-reversal symmetry，TRS）在这里指包含复共轭的反线性变换； 在 Kramers 型情形中，它把单粒子态配成简并伙伴。反射正性（reflection positivity，RP） 比单纯的反射对称更强：除了反射关系，还要求跨反射面的耦合属于一个正锥。 因此“权重为实”和“权重非负”是不同层次。

Majorana 表示则把一个复费米子拆成两个 Hermitian Majorana 算符。 同一个二次费米算符可以在 Nambu 基或 Majorana 基中表示，但矩阵、复共轭规则和传播生成元 必须一起变换。只搬运某个不等式而不搬运整个基变换，通常不会得到等价条件。

2.1 统一写法：\(gA\) 写进算符，\(A\) 生成传播

“Let \(g=\left(\begin{smallmatrix}0&-I\\I&0\end{smallmatrix}\right)=-\Omega\) for bosons and \(g=\left(\begin{smallmatrix}0&I\\I&0\end{smallmatrix}\right)\) for fermions.”

\(h_i=\frac12\chi^TgA_i\chi,\qquad gA+A^Tg=0.\)

\[ p=\mathrm{tr}(e^{h_1}\cdots e^{h_k}) =\det(I\mp e^{A_1}\cdots e^{A_k})^{\mp1/2}. \]

这三行定义了整份 note 的对象。\(g\) 编码玻色对易关系或费米反对易关系； \(gA\) 是二次算符 \(h\) 的系数；\(A\) 才是单体传播 \(e^A\) 的生成元。 条件 \(gA+A^Tg=0\) 保证二次算符对易后仍留在同一类中。

3. 如何判断一个类别是否真有收缩内部

3.1 回到五个正负号

令

\[ g^T=\tau g,\qquad g^2=\tau I,\qquad \tau=-1\ {\rm (boson)},\quad \tau=+1\ {\rm (fermion)}. \]

对两个实正交矩阵只记录

\[ J_a^TgJ_a=s_ag,\qquad J_a^2=q_aI,\qquad J_1J_2=rJ_2J_1, \qquad s_a,q_a,r=\pm1. \]

五个正负号给出 32 类。\(s_1,q_1\) 描述 现实性结构， \(s_2,q_2\) 决定 \(J_2\) 如何与 \(g\) 组合，\(r\) 记录两个结构对易还是反对易。

3.2 什么时候用 \(J_2g\)，什么时候必须乘 \(i\)

由正交性和上述两个 \(J_2\) 关系直接得到

\[ (J_2g)^\dagger=\tau q_2s_2\,J_2g,\qquad (J_2g)^2=\tau q_2s_2\,I. \]

若 \(\tau q_2s_2=+1\)，则 \(J_2g\) 已是 Hermitian 且平方为 \(I\)； 若 \(\tau q_2s_2=-1\)，则 \(J_2g\) 是 anti-Hermitian 且平方为 \(-I\)， 所以 \(iJ_2g\) 是 Hermitian 且平方为 \(I\)。整体负号只交换锥的方向，不改变分类。

3.3 第一条必要条件：\(q_2=-\tau\)

李代数条件给出 \((gA)^T=-\tau gA\)。再用 \(J_2^T=q_2J_2\)，

\[ \Tr(J_2gA) =\Tr[(J_2gA)^T] =-\tau q_2\Tr(J_2gA). \]

若 \(q_2=\tau\)，右边等于 \(-\Tr(J_2S)\)，故该迹只能为零。 相应 \(H_\eta(A)=\eta A+A^\dagger\eta\) 也有零迹。 若要求它半负定，就只能 \(H_\eta(A)=0\)，不存在严格内部。因此

\[ \boxed{q_2=-\tau.} \]

这正是玻色与费米最清楚的不对等：玻色要求 \(J_2^2=+I\)，费米要求 \(J_2^2=-I\)。

3.4 第二条必要条件：对易号不能省略

取上一小节得到的 Hermitian \(\eta\)，并施加 \(J_1^TAJ_1=\bar A\)。 逐项移动 \(J_1,J_2,g\) 可得

\[ J_1^T\bar\eta J_1=(\tau q_2s_1s_2r)\eta. \]

在已经满足 \(q_2=-\tau\) 时，这变为

\[ J_1^T\bar\eta J_1=(-s_1s_2r)\eta, \qquad J_1^T\overline{H_\eta(A)}J_1=(-s_1s_2r)H_\eta(A). \]

左边是对 \(H_\eta(A)\) 的复共轭和正交合同，因此保持半负定性。 若右边多出负号，它又要求 \(-H_\eta(A)\) 半负定，于是只能 \(H_\eta(A)=0\)。 严格内部因此要求

\[ \boxed{r=-s_1s_2.} \]

这就是 Comment 的答案。\(r\) 决定锥是否被保持；\(q_1\) 在推导中消失， 所以 \(J_1^2=\pm I\) 两个伙伴通常同时出现。

3.5 两条条件也是充分的：直接写出严格见证

当 \(q_2=-\tau\) 且 \(r=-s_1s_2\) 时，取 \(A_0=-\eta\)。利用前面的关系可以逐项验证

\[ gA_0+A_0^Tg=0,\qquad J_1^TA_0J_1=\bar A_0, \]
\[ H_\eta(A_0) =\eta(-\eta)+(-\eta)^\dagger\eta =-2\eta^2=-2I. \]

因此它不是靠随机搜索猜到的“可能通过”，而是显式严格内部点。 两条必要条件合起来也是充分条件。

完整分类定理。 对由 \(J_2\) 直接诱导的 Hermitian 度规，且以 \(H_\eta(A)=\eta A+A^\dagger\eta\leq0\) 控制实际传播 \(e^A\) 时， 与 \(J_1\) 现实性条件 兼容的严格内部存在，当且仅当 \(q_2=-\tau\) 且 \(r=-s_1s_2\)。\(s_1,q_1,s_2\) 可独立取正负， 所以玻色、费米各有 \(2^3=8\) 类。

5. 用统一结果审读后续硬算

5.1 每个 Case 都在重复同一套五步

  1. 用 \(I,\sigma_x,i\sigma_y,\sigma_z\) 的直积写出 \(J_1,J_2\)。
  2. 写出满足 \(gA+A^Tg=0\) 的一般玻色辛生成元或费米正交生成元。
  3. 解 \(J_1^TAJ_1=\bar A\)，把 现实性条件 变成各矩阵块之间的关系。
  4. 再按 \(J_2^TAJ_2=\pm\bar A\) 分成两部分。note 把等式边界上可逆的对称变换称为 maximal subgroup，把可能产生耗散的半正定方向称为 cone 方向。
  5. 检查由 \(J_2\) 写出的矩阵是否 Hermitian 半负定，并据此写 Passed 或 Failed。

前四步都是线性代数。真正困难的是第五步：矩阵必须先是 Hermitian，半负定要求必须与 \(J_1\) 现实性条件 相容，严格内部必须非空，而且该不等式要控制实际传播 \(e^A\)。 note 的主要误差都发生在这一步，而不是前面的分块乘法。

5.2 玻色 Case 7 与 Case 8：手算的可靠部分

Case 7 是 \(s_1=+,q_1=+,s_2=-,q_2=+,r=+\)； Case 8 只把 \(q_1\) 改成 \(-\)。二者都满足完整条件 \(q_2=+1,\ r=-s_1s_2=+1\)。note 展开的块关系与这个判断一致。 \(q_1\) 的改变会改变反线性结构是普通型还是 Kramers 型，却不破坏锥兼容性。

5.3 玻色 Cases 3、4、9：为什么手算得到 Failed

这些类都有正确的 \(q_2=+1\)，所以度规本身没有迹阻挡；失败来自对易号。 现实性条件 把任何候选半负定矩阵变成它的相反数。一个矩阵不可能既严格半负又严格半正， 因而只剩等式边界。note 的逐块计算看见的是这一统一事实的三个坐标版本。

5.4 玻色 Case 10：分块子空间存在，不等于收缩锥存在

note 在 Case 10 中列出 cone 方向的 \(A\) 后直接写：

“There's a contration semigroup.”

该类为 \((-,-,-,+,+)\)。它与正确的 Case 6 \((-,-,-,+,-)\) 只差 \(J_1,J_2\) 的对易号。对 Case 10，现实性条件 将 \(H_\eta(A)=\eta A+A^\dagger\eta\) 送到 \(-H_\eta(A)\)。 因此只要同时要求 \(H_\eta(A)\leq0\)，便必有 \(H_\eta(A)=0\)。 note 确实找到了一个线性子空间，但没有写出或验证半负定不等式；“有 cone 方向”被误当成了“有收缩锥”。

5.5 玻色 Cases 11--16：为什么都只能在边界

这些手算例子取 \(q_2=-1\)，而玻色严格收缩要求 \(q_2=+1\)。 对任意允许的 \(A\)，\(H_\eta(A)\) 的迹恒为零。Hermitian 半负定矩阵若迹为零， 所有本征值只能全为零。因此这些类的失败不是某个 Pauli 代表选得不好，而是与表示无关的阻挡。

5.6 费米硬算中的两个具体阅读提醒

  • Case \(5'\) 写 \(J_1=\sigma_z\otimes I\)，但紧随其后的显示矩阵误写成 \(\operatorname{diag}(I,I)\)；后续代数实际按 \(\operatorname{diag}(I,-I)\) 在算。 这是排版笔误，也说明长手算很难审计。
  • 多处结尾从 “某块矩阵可以取半正定”直接跳到 “With positivity”。 这只证明一个生成元级候选条件，不等于由 \(e^A\) 计算的完整 Fock 权重已经非负。

“For bosonic case 4'' & 7'', is the commutator/anti-commutator there really matters? I don't think so. This observation may also apply to fermionic case 2''' & 6''', 3''' & 7''', and 4' & 8'''.”

这些配对都固定了 \(s_1,q_1,s_2,q_2\)，只改变 \(r\)。正因如此，它们是检验 对易号是否重要的最干净例子。结果如下。

7. 费米 Passed 为什么仍需谨慎

7.1 note 的不等式没有直接控制 \(e^A\)

note 的权重公式使用 \(M=\prod e^{A_\ell}\)，但它施加的不等式含 \(J_2gA\)。 映射 \(A\mapsto gA\) 一般不是相似变换，所以控制 \(gA\) 的某个 Hermitian 部分， 不能自动控制 \(e^A\) 的本征值或 \(\det(I+M)\)。

Wei 的原始半群结果确实允许用反对称 \(J_2\) 写 \(i(J_2A-\bar A J_2)\leq0\)，但那里的 \(A\) 是 Majorana 表示中直接进入二次型并生成相应传播的矩阵。 将其搬到 Nambu 表示时必须整体变换，而不是只把 \(A\) 替换成 \(gA\)。

7.2 二维精确反例：满足 note 不等式，权重仍过零变负

取

\[ g=\sigma_x,\qquad J_1=\sigma_x,\qquad J_2=i\sigma_y,\qquad A=iy\sigma_z. \]

它属于 note 的费米 \(3'\) 离散关系，并满足

\[ J_1^TAJ_1=\bar A,\qquad iJ_2gA-iA^\dagger J_2g=-2yI<0\quad(y>0). \]

但二次算符和完整一模 Fock 迹是

\[ h=iy\left(n-\frac12\right),\qquad W(y)=\Tr e^h=2\cos\frac y2. \]

\(W(\pi)=0\)，\(W(2\pi)=-2\)。所以这条不等式即使严格成立，也没有排除费米权重零点。 note 把 \(3'\) 称为 Majorana reflection positivity 时，缺少了把真正的 Majorana 正性结构正确拉回当前 Nambu 约定的步骤。

7.3 note 的 \(9'\) 也有无 pairing 的显式负权重

对与 \(9'\) 相同的五符号类，可以取三个粒子数守恒时间片，也就是不含同时产生或湮灭 两个粒子的 pairing 项：

\[ B_1=-2\sigma_x-2\sigma_z,\qquad B_2=-2\sigma_x,\qquad B_3=2\sigma_x+\sigma_z. \]

逐时间片的 note 边界等式和现实性条件残差为零，但

\[ W=\det(I+e^{B_1}e^{B_2}e^{B_3}) =-24.1885664. \]

从零整体缩放三个 \(B_\ell\) 时，权重在 \(t=0.8096748539\) 经过零。这直接否定 \(9'\) 的 “Passed” 可以被理解为无符号结论。

正确处理方式。 要么回到 Majorana 基，严格采用 Wei 定理的 \(A,J_1,J_2\) 和反对易条件； 要么留在当前 Nambu 基，直接对传播生成元写 Hermitian \(H_\eta(A)=\eta A+A^\dagger\eta\leq0\)，并要求 \(q_2=-\tau,\ r=-s_1s_2\)。 两种表示都可以使用，但不能混合半个公式。

完整穷举 玻色、费米的 32 个五符号组合全部存在实 Pauli 代表。对由 \(J_2\) 直接诱导的传播收缩度规， 每种统计各有 8 个严格类，其中 4 个使用 \(J_2g\)，4 个使用 \(iJ_2g\)。
