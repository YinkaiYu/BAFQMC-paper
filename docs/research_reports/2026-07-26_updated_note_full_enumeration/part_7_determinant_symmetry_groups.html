1. 固定辅助场构型以后，我们要证明什么

1.1 从二次 Hamiltonian 到 Monte Carlo 权重

Hubbard--Stratonovich 分解把相互作用问题变成许多依赖辅助场的二次 Hamiltonian。固定一条时空辅助场历史后，Monte Carlo 权重就是这一串 二次算符的 many-body trace：

\[ p=\operatorname{Tr}\!\left(e^{\hat h_1}e^{\hat h_2}\cdots e^{\hat h_k}\right), \qquad \hat h_\ell=\frac12\hat\chi^TgA_\ell\hat\chi . \]

这里 \(\hat\chi=(a_1,\ldots,a_N,a_1^+,\ldots,a_N^+)^T\) 同时列出湮灭算符和产生算符。玻色与费米可以使用同一个写法，区别只在

\[ g_{\rm B}=\begin{pmatrix}0&-I_N\\ I_N&0\end{pmatrix},\qquad g_{\rm F}=\begin{pmatrix}0&I_N\\ I_N&0\end{pmatrix},\qquad gA_\ell+A_\ell^Tg=0. \]

第一种 \(g\) 编码玻色 commutator，第二种编码费米 anticommutator。 二次算符作用在 \(2N\) 个 Nambu 分量上的一体传播矩阵为

\[ M=e^{A_1}e^{A_2}\cdots e^{A_k}. \]

Gaussian trace 恒等式把 many-body trace 化成有限维行列式。在本文约定下，

\[ \boxed{ p_{\rm B}=\bigl[(-1)^N\det(I-M)\bigr]^{-1/2},\qquad p_{\rm F}=\bigl[\det(I+M)\bigr]^{1/2}.} \]

平方根由左边的算符 trace 确定。这个公式可以逐模看懂。保持 commutator 或 anticommutator 的一体传播，其本征值以 \(\lambda,\lambda^{-1}\) 出现；一个费米模的两个占据态给 \(e^{-x/2}(1+e^x)\)，一个玻色模的全部占据态给 \(e^{x/2}/(1-e^x)\)，其中 \(\lambda=e^x\)。把所有物理模相乘， 正好得到上面的两个行列式公式。玻色式中的 \((-1)^N\) 来自 \((1-\lambda)(1-\lambda^{-1})=-(1-\lambda)^2/\lambda\)。

本卷的目标是直接利用每个固定辅助场构型的对称性，把 \(p\) 写成绝对值平方， 或写成一个本征值逐对相乘的普通行列式。这样实际权重的符号已经由对称性决定， 无须再单独讨论平方根选择。玻色构型若满足 \(\det(I-M)=0\)，权重有 pole； 除了这些点，下面的结论不依赖 occupation-number 求和是否收敛。

1.2 什么叫固定辅助场构型的时间反演对称性

把时间反演写成 \(\Theta=U\mathcal K\)，其中 \(\mathcal K\) 对所有复数 系数做复共轭。它要成为同一个玻色或费米 Fock space 上的物理反幺正变换， 并保持每一个时间片，需要满足

\[ U^TgU=g,\qquad C\overline UC=U,\qquad U^{-1}\overline{A_\ell}U=A_\ell, \qquad C=\begin{pmatrix}0&I_N\\I_N&0\end{pmatrix}. \]

三式的物理含义依次是：保持玻色 commutator 或费米 anticommutator； 变换产生算符时仍得到变换后湮灭算符的 Hermitian conjugate；固定这一辅助场 构型下的二次 Hamiltonian 不变。于是

\[ \Theta\hat h_\ell\Theta^{-1}=\hat h_\ell, \qquad \Theta^2=U\overline U=\pm I. \]

后文用 \(+\) 和 \(-\) 标记 \(\Theta^2=+I\) 与 \(\Theta^2=-I\)。 负平方表示 Kramers 型时间反演：任意状态 \(v\) 与 \(\Theta v\) 线性独立， 因为假如 \(\Theta v=cv\)，再作用一次便会得到 \(-v=|c|^2v\)，这是不可能的。

2. 两种基本无符号机制

2.1 \(P^2=I\) 与 \(Q^2=-I\) 的物理区别

两条反幺正变换的乘积是线性变换，因为两次复共轭相消。 这个线性变换平方为 \(+I\) 或 \(-I\) 时，承担的物理工作完全不同：

线性变换本征值物理作用
\(P^2=I\) \(P=+1\) 或 \(P=-1\) 像 flavor、layer 或 sublattice parity 一样，把系统分成两个完整的物理部分。每一部分都同时含有某些湮灭算符及其产生算符。
\(Q^2=-I\) \(Q=+i\) 或 \(Q=-i\) 不表示两个物理部分。它在每一对 Hermitian-conjugate Nambu 分量中各选一个，去掉把产生、湮灭算符同时写入 \(\hat\chi\) 所造成的重复。

这个区别可以直接由 Hermitian conjugation 看出。若 \(Pv=pv\)，其中 \(p=\pm1\) 是实数，那么与 \(v\) 对应算符的 Hermitian conjugate 仍在同一个 \(P=p\) 部分。若 \(Qv=iv\)，则与该算符的 Hermitian conjugate 对应的 列向量是 \(C\overline v\)。利用 \(C\overline Q C=Q\)，有

\[ Q(C\overline v)=C\overline{Qv}=-iC\overline v. \]

因此 \(Q=+i\) 的一半包含 \(N\) 个独立算符，\(Q=-i\) 的另一半正好包含 它们的 Hermitian conjugates。

2.2 \(\{+,-\}\)：两个完整物理部分互为复共轭

取两条反对易时间反演

\[ \Theta_+^2=+I,\qquad \Theta_-^2=-I,\qquad \Theta_+\Theta_-=-\Theta_-\Theta_+, \]

并令 \(P=\Theta_+\Theta_-\)。直接相乘得到

\[ P^2=I,\qquad [P,A_\ell]=0,\qquad P\Theta_+=-\Theta_+P. \]

第一式让我们用 \(P=\pm1\) 标记两个部分；第二式说明每个时间片都不混合它们。 第三式说明 \(\Theta_+\) 交换它们。这个交换可以一行算清楚：

\[ Pv=pv \quad\Longrightarrow\quad P(\Theta_+v)=-\Theta_+(Pv)=-p\,\Theta_+v, \qquad p=\pm1. \]

反幺正变换还会把所有复数系数共轭。因此 \(P=-1\) 部分的整个 Gaussian trace 等于 \(P=+1\) 部分 trace 的复共轭。更明确地说，若两部分的演化算符分别为 \(\widehat{\mathcal U}_+\) 和 \(\widehat{\mathcal U}_-\)，则

\[ \widehat{\mathcal U}_-=\Theta_+\widehat{\mathcal U}_+\Theta_+^{-1} \quad\Longrightarrow\quad \operatorname{Tr}\widehat{\mathcal U}_- =\overline{\operatorname{Tr}\widehat{\mathcal U}_+}. \]

若把 \(P=+1\) 部分的 trace 记为 \(p_+\)，则

\[ \boxed{p=p_+\overline{p_+}=|p_+|^2\geq0.} \]

这就是最直接的物理图像：每个辅助场构型由两份共轭的 many-body evolution 组成，任何复相位都在两份之间抵消。写成一体矩阵就是

\[ p_{\rm B}=\left|\det\!\left[I-M\big|_{P=+1}\right]\right|^{-1}>0, \qquad p_{\rm F}=\left|\det\!\left[I+M\big|_{P=+1}\right]\right|\geq0. \]

每个 \(P\) 部分本身是一套完整的物理自由度，\(\Theta_+\) 交换这两套自由度。

2.3 \(\{-,-\}\)：\(Q\) 产生守恒荷，再回到 Kramers determinant

现在取

\[ \Theta_1^2=\Theta_2^2=-I,\qquad \Theta_1\Theta_2=-\Theta_2\Theta_1, \qquad Q=\Theta_1\Theta_2. \]

这次 \(Q^2=-I\)，所以 \(iQ\) 的本征值为 \(\pm1\)。它定义二次守恒荷

\[ \widehat{\mathcal Q}=\frac12\hat\chi^Tg(iQ)\hat\chi . \]

二次算符的对易子与矩阵对易子一一对应，而 \([Q,A_\ell]=0\)，因此

\[ [\widehat{\mathcal Q},\hat h_\ell] =\frac12\hat\chi^Tg[iQ,A_\ell]\hat\chi=0. \]

每个时间片都守恒 \(\widehat{\mathcal Q}\)。把满足 \(Qv=iv\) 的 \(N\) 个 线性组合记为 \(\hat d_1,\ldots,\hat d_N\)。它们具有相同的 \(iQ\) 本征值，Hermitian conjugates 位于 \(Q=-i\) 的另一半。于是 \(Q\) 把 \(2N\) 维 Nambu 写法重新组织成一套 \(N\) 维的守恒荷空间及其 Hermitian conjugate。这正是 Majorana Kramers class 中“先由两条时间反演产生 charge conservation， 再使用通常 Kramers 条件”的物理步骤。

一个看似反常但关键的事实是：\(\Theta_1\) 与 \(Q\) 反对易，却仍把 \(Q=+i\) 的算符留在这一半。原因是 \(\Theta_1\) 既带来反对易负号，又把 \(i\) 复共轭为 \(-i\)：

\[ Qv=iv \quad\Longrightarrow\quad Q(\Theta_1v)=-\Theta_1(Qv)=-\Theta_1(iv)=i\Theta_1v. \]

所以 \(\Theta_1^2=-I\) 在这个守恒荷空间内成为通常的 Kramers 时间反演。 若 \(M|_{Q=+i}\) 表示完整传播矩阵在这个空间上的作用，那么每个 非实本征值 \(\lambda\) 都有 \(\overline\lambda\)，每个实本征值至少出现两次。 在下面两个乘积中，每一对只计一次：

\[ \det\!\left(I\mp M|_{Q=+i}\right)= \prod_{\text{每对非实 }\lambda,\overline\lambda}|1\mp\lambda|^2 \prod_{\text{每对实 Kramers 本征值 }\lambda}(1\mp\lambda)^2\geq0. \]

同一条 Kramers 关系还说明每个 \(\operatorname{Tr}(A_\ell|_{Q=+i})\) 都是实数。因为时间反演在 \(Q=+i\) 空间内把 \(A_\ell\) 变成自身，取 trace 后得到

\[ \overline{\operatorname{Tr}(A_\ell|_{Q=+i})} =\operatorname{Tr}(A_\ell|_{Q=+i}). \]

因此下面 trace 公式中的指数因子是正实数。

对费米子，可以把 \(\hat d_1,\ldots,\hat d_N\) 选成新的湮灭算符。 这是因为完整 Nambu anticommutator matrix 是 \(I_{2N}\)，而 \(Q\) 保持它； 所以 \(Q=+i\) 空间内的 anticommutator 仍是正定的，可以把这 \(N\) 个组合 正交归一化成普通费米湮灭算符。除去不影响对易关系的常数和整体正负号， 守恒荷就是

\[ \widehat{\mathcal Q}=\sum_{\mu=1}^{N}\hat d_\mu^+\hat d_\mu+\text{常数}. \]

因为每个 \(\hat h_\ell\) 都与这个粒子数对易，它不再含 \(\hat d_\mu\hat d_\nu\) 或 \(\hat d_\mu^+\hat d_\nu^+\) 项。于是通常的 粒子数守恒 trace 公式给出

\[ p_{\rm F}= \exp\!\left[-\frac12\sum_\ell \operatorname{Tr}\!\left(A_\ell|_{Q=+i}\right)\right] \det\!\left(I+M|_{Q=+i}\right)\geq0. \]

玻色子的区别来自 Nambu commutator。完整 commutator matrix 及其在 \(Q\) 作用下的变换为

\[ [\hat\chi,\hat\chi^\dagger]=-gC=\operatorname{diag}(I_N,-I_N),\qquad Q^\dagger(-gC)Q=-gC. \]

第二式来自两条时间反演都保持 commutator。它还说明 \(Q=+i\) 与 \(Q=-i\) 两个空间在这个 commutator matrix 下彼此正交。完整矩阵 \(-gC\) 没有零 本征值，所以它限制到任一空间后也没有零本征值；因此不会留下像 \(\hat b+\hat b^+\) 那样与自身 Hermitian conjugate 对易的组合。作一次保持 \(Q\) 的换基后， \(\hat d_1,\ldots,\hat d_N\) 与其 Hermitian conjugates 的 commutator matrix 可以写成两个对角 blocks：

\[ [\hat d_\mu,\hat d_\nu^+] =\begin{pmatrix}I&0\\0&-I\end{pmatrix}_{\mu\nu}. \]

上面的负 block 表示：在这个 block 中，真正的玻色湮灭算符是 \(\hat d_\mu^+\)。 每交换一次 \(\hat d_\mu\leftrightarrow\hat d_\mu^+\)，单模 trace 多出一个 负号。\(\Theta_1^2=-I\) 保持两个 commutator blocks，并在每个 block 内产生 Kramers 双重简并，所以负 block 的维数必为偶数，所有额外负号相乘为 \(+1\)。 两个 blocks 都允许为空。即使同样取最小的 \(N=2\)，不同表示也可以分别给出 commutator matrix \(I_2\) 或 \(-I_2\)。两条时间反演固定的是负 block 维数为偶数，并不固定它究竟是 0 还是 2。

\[ \boxed{ p_{\rm B}= \exp\!\left[\frac12\sum_\ell \operatorname{Tr}\!\left(A_\ell|_{Q=+i}\right)\right] \det\!\left(I-M|_{Q=+i}\right)^{-1}>0 \quad\text{（除玻色 pole 外）}.} \]

2.4 为什么只有一条时间反演时，上述 Nambu 结论不成立

在粒子数守恒问题中，湮灭算符空间本来就是一套独立的一体空间，一条 \(\Theta^2=-I\) 已足以产生 Kramers 简并。含有 superconducting 或 bosonic pairing 项时，湮灭算符会在传播中变成产生算符的线性组合；Nambu 写法因此把 两者一起保留。一条时间反演虽然让完整 \(2N\) 维谱 Kramers 简并，却没有告诉 我们怎样从 Nambu 表示中选出不重复的 \(N\) 个算符。

最小费米例已经说明这一点。取

\[ g=C=\sigma_x,\qquad U=-\sigma_y,\qquad A=\operatorname{diag}(-2ix,2ix),\qquad x\in\mathbb R. \]

这组矩阵满足

\[ U^TgU=g,\qquad C\overline UC=U,\qquad U^{-1}\overline AU=A,\qquad U\overline U=-I. \]

因而 \(\Theta=U\mathcal K\) 是平方为 \(-I\) 的时间反演。对应的算符 evolution 和 trace 是

\[ \hat n=\hat c^+\hat c,\qquad \widehat{\mathcal U}(x)=e^{-2ix(\hat n-1/2)},\qquad p_{\rm F}(x)=2\cos x. \]

它具有一条平方为 \(-I\) 的 Nambu 时间反演，但在 \(\pi/2<x<\pi\) 时权重为负。第二条反对易时间反演的作用正是产生 \(P\) 或 \(Q\)，补上 Nambu 表示中缺失的物理分解。

玻色也有同样直接的单时间反演反例。取一个玻色模

\[ g=\begin{pmatrix}0&-1\\1&0\end{pmatrix},\qquad C=\sigma_x,\qquad U=I_2,\qquad A=xg,\qquad 0<x<2\pi. \]

此时 \(\Theta=\mathcal K\) 平方为 \(+I\)，并保持该时间片；对应二次算符为 \(\hat h=-x(\hat b^2+\hat b^{+2})/2\)。然而

\[ M=e^{xg},\qquad (-1)^1\det(I-M)=-4\sin^2\!\frac{x}{2}<0. \]

所以解析延拓定义的玻色权重是纯虚数。一条平方为 \(+I\) 的时间反演同样不能 单独给 Nambu Gaussian 权重定号。

2.5 完整 Nambu 空间可以直接使用正交群条件

split-orthogonal determinant theorem 本身并不要求先删去 Nambu 分量。 只要在某组基底中传播矩阵为实矩阵，并保持一个实对称、可逆的 \(\eta\)，条件就是

\[ M^T\eta M=\eta, \qquad M\ \text{与单位矩阵连续相连}, \]

就可以直接在完整的 \(2N\) 维 Nambu 空间应用正交群定理，得到 \(\det(I+M)\geq0\)。问题在于，费米 Fock-space 权重满足

\[ p_{\rm F}^{\,2}=\det(I+M). \]

因此这个结论只给出 \(|p_{\rm F}|\)，没有给出 \(p_{\rm F}\) 的正负号。 原因不是 Nambu 写法多写了一倍矩阵元，而是从 Fock-space Gaussian 算符 到 Nambu 传播矩阵的映射是二对一的：\(\widehat{\mathcal U}\) 与 \(-\widehat{\mathcal U}\) 对所有 Nambu 算符产生完全相同的线性变换。

第 2.4 节的单模例子可以把这个区别完整算出来。改用两个 Majorana 算符

\[ \hat\gamma_1=\hat c+\hat c^+, \qquad \hat\gamma_2=-i(\hat c-\hat c^+), \]

对应的 Nambu 传播就成为二维实旋转

\[ M_\gamma(x)= \begin{pmatrix} \cos(2x)&\sin(2x)\\ -\sin(2x)&\cos(2x) \end{pmatrix}\in SO(2), \qquad \det(I+M_\gamma)=4\cos^2x. \]

但是同一个 Gaussian 算符的 Fock trace 是 \(2\cos x\)，在 \(\pi/2<x<\pi\) 为负。若希望正、负方向数目相等，可再加入一个完全 不传播的费米模：

\[ \widetilde M(x)=\operatorname{diag}(M_\gamma(x),I_2), \qquad \widetilde\eta=\operatorname{diag}(I_2,-I_2). \]

这时 \(\widetilde M(x)\in SO_0(2,2)\)，而

\[ \det(I+\widetilde M)=16\cos^2x, \qquad \operatorname{Tr}_{\rm Fock}\widehat{\mathcal U}(x)=4\cos x. \]

更强的反例出现在 \(x=\pi\)：此时 \(\widetilde M(\pi)=I_4\)，但沿着上述旋转从单位算符连续提升到 Fock 空间后，终点是 \(-I\)，其 trace 为 \(-4\)。也就是说，连最终传播矩阵 都完全相同，Fock 算符仍可能相差一个负号。因而不存在一个只读取 \(M\in SO_0(p,q)\) 就能为整个最大子群确定 Fock-space 整体号的定理。 这里下标 0 表示与单位矩阵连续相连的那一部分。

2.6 能直接计算 Fock-space 整体号的加强版

不约化 Nambu 空间时，正确的加强不是再找一个只依赖 \(M\) 的平方根公式， 而是把 Fock-space lift 一起保存。对 \(N\) 个费米模，把一个实际 Gaussian 算符记为 \(\widehat{\mathcal U}\)，并定义

\[ \zeta=2^{-N}\operatorname{Tr}\widehat{\mathcal U}. \]

当 trace 非零时，完整数据是 \((M,\zeta)\)，而不是单独的 \(M\)。 二者满足

\[ \boxed{2^{2N}\zeta^2=\det(I+M).} \]

这个等式仍保留普通 determinant theorem 的全部信息；额外保存的 \(\zeta\) 正好区分同一个 \(M\) 上的两个 Fock 算符。它还可以完全离散地 随时间片相乘。若 \((M_1,\zeta_1)\) 与 \((M_2,\zeta_2)\) 表示两个 Gaussian 算符，并令

\[ G_j=2(I+M_j)^{-1}-I\qquad(j=1,2), \]

则它们乘积的整体号由下面的 Pfaffian 唯一确定：

\[ \boxed{ \zeta_{12}=(-1)^N\zeta_1\zeta_2 \operatorname{Pf} \begin{pmatrix} G_1&-I\\ I&G_2 \end{pmatrix}, \qquad M_{12}=M_1M_2.} \]
展开 Pfaffian 乘法式的三步推导

第一步，把 Majorana 算符的有序乘积换成同样次序的 Grassmann 变量。 Grassmann 变量彼此反对易，但不是算符。任意偶宇称 fermionic Gaussian 算符都可写成

\[ \omega_{\boldsymbol\theta}(\widehat{\mathcal U}_j) =\zeta_j\, \exp\!\left(-\frac12 \boldsymbol\theta^T G_j\boldsymbol\theta\right). \]

这个 Grassmann Gaussian 的常数项就是 \(\zeta_j\)：除单位算符外， 任何非平凡 Majorana 单项式的 Fock trace 都为零，而单位算符的 trace 是 \(2^N\)，所以 \(\operatorname{Tr}\widehat{\mathcal U}_j=2^N\zeta_j\)。

第二步，在 \(\widehat{\mathcal U}_1\widehat{\mathcal U}_2\) 中间插入 fermionic coherent-state 的单位分解。相邻 coherent states 的 overlap 给出 两个非对角单位矩阵。把两套各有 \(2N\) 个 Grassmann 变量合并后， 乘积的常数项为

\[ \zeta_{12}=(-1)^N\zeta_1\zeta_2 \int d^{4N}\boldsymbol\xi\, \exp\!\left[ \frac12\boldsymbol\xi^T \begin{pmatrix}G_1&-I\\ I&G_2\end{pmatrix} \boldsymbol\xi\right]. \]

\((-1)^N\) 来自把积分变量重新排成统一的次序。Grassmann Gaussian 积分的定义正是

\[ \int d^{4N}\boldsymbol\xi\, e^{\boldsymbol\xi^TX\boldsymbol\xi/2} =\operatorname{Pf}(X), \qquad X^T=-X. \]

代入上一式便得到正文的 Pfaffian 乘法式。因为这是一个多项式，输入的 两个原始 Gaussian 算符一旦给定，输出符号也随之唯一给定。

第三步检查它与 Nambu determinant 完全一致。由 \(G_j=(I-M_j)(I+M_j)^{-1}\) 直接作 block determinant，可得

\[ \det\begin{pmatrix}G_1&-I\\ I&G_2\end{pmatrix} = \frac{2^{2N}\det(I+M_1M_2)} {\det(I+M_1)\det(I+M_2)}. \]

再使用 \(\operatorname{Pf}(X)^2=\det X\) 以及 \(2^{2N}\zeta_j^2=\det(I+M_j)\)，立即得到

\[ 2^{2N}\zeta_{12}^2=\det(I+M_1M_2). \]

所以 Pfaffian 乘法没有改变 determinant 的绝对值；它只补回 determinant 平方后丢失的正负号。

这里 Pfaffian 是反对称矩阵的有限阶多项式，满足 \(\operatorname{Pf}(X)^2=\det X\)，所以没有平方根分支选择。 这条乘法式可由两个 Grassmann Gaussian 的积分直接得到；平方以后便退回 \(2^{2N}\zeta_{12}^2=\det(I+M_{12})\)。因此它是普通 split-orthogonal determinant theorem 与 Fock-space lift 的结合： 普通定理证明根号内非负，Pfaffian 乘法再给出实际取正根还是负根。 若某个中间乘积恰有零 trace，\(G_j\) 不存在，逐片乘法式就会遇到除以零。 这不是物理权重的含糊性。下面的全时空公式不形成任何中间乘积，因此可以 直接越过这种零点。

展开不依赖中间乘积的全时空 Pfaffian

在 Majorana 基底中，把第 \(\ell\) 个实际 Fock-space 时间片写成

\[ \widehat{\mathcal U}_\ell= \exp\!\left(-\frac14\boldsymbol\gamma^T H_\ell\boldsymbol\gamma\right), \qquad H_\ell^T=-H_\ell . \]

它的 Nambu 传播矩阵是 \(M_\ell=e^{-H_\ell}\)。这个写法只是把 原来的 \(A_\ell\) 换到 Majorana 基底后再取负号：这样 \(e^{-H_\ell}\) 正好就是原约定中的 \(e^{A_\ell}\)。它没有增加新的 对称性条件。 单片归一化 trace 可直接算成

\[ \zeta_\ell=(-1)^N\operatorname{Pf} \begin{pmatrix} \sqrt2\sinh(H_\ell/4)&-I\\ I&\sqrt2\sinh(H_\ell/4) \end{pmatrix}, \qquad \operatorname{Tr}\widehat{\mathcal U}_\ell=2^N\zeta_\ell . \]

设时间片数 \(k\) 为偶数，并令 \(G_\ell=\tanh(H_\ell/2)\)。整个 Fock-space trace 一次性等于

\[ \boxed{ \operatorname{Tr}\!\left( \widehat{\mathcal U}_1\cdots\widehat{\mathcal U}_k\right) =(-1)^{Nk/2}2^N \left(\prod_{\ell=1}^{k}\zeta_\ell\right) \operatorname{Pf} \begin{pmatrix} G_1&-I&I&\cdots&-I\\ I&G_2&-I&\cdots&I\\ -I&I&G_3&\ddots&-I\\ \vdots&\vdots&\ddots&\ddots&-I\\ I&-I&I&I&G_k \end{pmatrix}.} \]

上式第 \(r\) 行、第 \(s\) 列的非对角 block（\(r<s\)）是 \((-1)^{s-r}I\)，下三角部分由整个矩阵反对称唯一确定。若原本有奇数个 时间片，补一个单位算符即可；它不改变权重。

这个公式来自把全部 \(2Nk\) 个 Grassmann 变量一次积分掉。它的每个 矩阵元都由实际时间片决定，最后只计算一个 Pfaffian，因此既没有平方根， 也没有中间整体号。若某个单片本身使 \(G_\ell\) 发散，把同一个指数精确 写成

\[ e^{-\boldsymbol\gamma^TH_\ell\boldsymbol\gamma/4} =\left[ e^{-\boldsymbol\gamma^TH_\ell\boldsymbol\gamma/(4r)} \right]^r . \]

总能选择足够大的整数 \(r\)，使细分后每片的 \(I+e^{-H_\ell/r}\) 可逆。这个操作保持原算符及其 lift 完全不变， 所以全时空公式对任意有限的 Gaussian 时间片序列都适用，不要求物理路径 避开零权重点。零权重由 Pfaffian 直接给出 0；负权重也直接给出负数。

例如把第 2.5 节的闭合旋转分成四片，每片取 \(x=\pi/4\)。四个单片 trace 都为正，传播矩阵的乘积是 \(I_2\)，但上式给出 \(2\cos\pi=-2\)。它因此能区分同一个终点矩阵上的两个 Fock lifts。

Fock-space split-orthogonal 定理。 设实际 fermionic Gaussian 算符 \(\widehat{\mathcal U}\) 在完整 Nambu 或 Majorana 空间诱导 \(M\in SO_0(p,q)\)。那么 \(\operatorname{Tr}_{\rm Fock}\widehat{\mathcal U}\) 是实数，并且 \((\operatorname{Tr}_{\rm Fock} \widehat{\mathcal U})^2=\det(I+M)\)；它的正负号由上面的 Pfaffian 乘法式或全时空 Pfaffian 唯一给出。因而这条加强版直接控制 Fock-space 整体号，而不需要去除 Nambu 分量。 在不经过 \(\det(I+M)=0\) 的任一连续区域内，这个实数的符号不变；包含 单位算符的区域取正号。最大子群中也可能含有第 2.5 节那样的二维旋转；当 \(M\) 出现本征值 \(-1\) 时，Fock trace 经过零并改变符号，所以定理会 如实给出负号，而不会把整个最大子群误判为非负。

更具体地，令 \(\widehat{\mathcal U}(t)\) 是从单位算符出发、覆盖 \(M(t)\) 的连续 Fock-space Gaussian 算符，则

\[ \boxed{ \begin{gathered} M(t)^T\eta M(t)=\eta,\qquad M(0)=I,\\ \det[I+M(t)]>0\quad(0\leq t\leq1) \end{gathered} \quad\Longrightarrow\quad \operatorname{Tr}_{\rm Fock}\widehat{\mathcal U}(1)>0.} \]

证明只有一步：左边保证 Fock trace 始终是非零实数；它随 \(t\) 连续， 而 \(t=0\) 时等于 Fock-space 维数 \(2^N>0\)，所以途中不能变号。 第 2.5 节同时证明了条件中的严格大于号不能从“属于最大子群”自动推出。

若反线性对称性使这个 Pfaffian 分解成某个 Pfaffian 与其复共轭的乘积， 或使所有可能变号的实因子具有 Kramers 双重简并，便进一步得到逐构型非负； 这正是第 2.2、2.3 节的两种时间反演机制。若严格收缩条件保证整个辅助场域 不经过零权重点，则也可从单位算符所在的正区域固定符号。除此之外， Pfaffian 公式只能准确计算负号，不能把真正存在的负权重消掉。 具体的离散更新与数值稳定化见 第 5 卷；费米 Pfaffian 公式见 PfQMC。

费米 Pfaffian 之所以特别简洁，是因为 Grassmann Gaussian 积分本身就是 一个 Pfaffian。玻色 Fock space 没有这一步，但也可以在完整 Nambu 空间中 得到同样无歧义的 lifted 乘法；下面把需要的公式列全。

展开 bosonic Fock-space split-orthogonal 定理

先看普通矩阵定理给出什么。若完整 \(2N\) 维玻色 Nambu 传播同时满足 辛条件和 \(M\in SO_0(p,q)\)，其中 \(p+q=2N\)，则

\[ (-1)^q\det(I-M)\geq0, \qquad p_{\rm B}^{-2}=(-1)^N\det(I-M). \]

因此 \(N\) 与 \(q\) 奇偶性相同时，根号内的量非负，玻色权重在 pole 以外为实数；奇偶性不同时，单靠这个最大子群得到的是纯虚解析延拓，不能 作为实采样权重。最常用的 split 情形是 \(p=q=N\)，自动属于前一种。

接着保存矩阵没有记录的整体号。把中心化 Gaussian 算符的传播矩阵分块为

\[ M=\begin{pmatrix}u&v\\w&z\end{pmatrix}, \qquad \eta_U=\langle0|\widehat{\mathcal U}|0\rangle . \]

\(\eta_U\) 是真空矩阵元，不是正交群的度规 \(\eta\)。在 \(z\) 可逆的 区域内，\(\eta_U^2=\det(z)^{-1}\)；实际保存 \(\eta_U\) 本身，不能在 每一步用主平方根覆盖它。对左、右两个 Gaussian 算符，令

\[ X_2=v_2z_2^{-1}, \qquad Z_1=-z_1^{-1}w_1. \]

Fock-space 乘法直接给出

\[ \boxed{ \begin{aligned} M_{12}&=M_1M_2,\\ \eta_{12}&=\eta_1\eta_2 \exp\!\left[-\frac12\operatorname{Tr} \operatorname{Log}_0(I-Z_1X_2)\right]. \end{aligned}} \]

\(\operatorname{Log}_0\) 表示从 \(I-Z_1X_2=I\) 出发连续得到的矩阵 logarithm。这个 exponential 正是两个 Gaussian 算符相乘时，右边的 产生算符 exponential 与左边的湮灭算符 exponential 在真空之间产生的 Gaussian contraction。它随 \(\widehat{\mathcal U}_1, \widehat{\mathcal U}_2\) 的实际 lifts 一起相乘，所以不会重新猜平方根。

乘完全部时间片以后，Fock trace 为

\[ \boxed{ \operatorname{Tr}_{\rm Fock}\widehat{\mathcal U} =\eta_U \left[ \frac{\det z}{(-1)^N\det(I-M)} \right]_{\text{同一 Gaussian 分解区域}}^{1/2}.} \]

方括号内平方根只在每个 Gaussian 分解区域用一个简单的收敛参考算符固定 一次；同一个 \(M\) 上的正、负 lift 已全部由 \(\eta_U\) 区分。若某次 乘法使 \(z\) 或 \(I-Z_1X_2\) 奇异，就改用另一种产生、湮灭算符分解次序， 或把 elementary exponentials 重新分组；不能丢弃 \(\eta_U\) 后改取主 平方根。不同分解区域之间的变换仍由同一个实际 Fock 算符唯一确定。

因而玻色加强版与费米加强版的结论相同：完整 Nambu 空间可以保留， split-orthogonal 条件先控制根号内量，lifted 乘法再控制实际整体号。 它是一条精确求号定理，不是一条把整个最大子群都宣布为正的定理。 离散 product tree、不同分解区域的处理和数值检查见 第 5 卷。

3. 三条及更多时间反演

3.1 含有负平方时间反演的三条类别

\(\{+,+,-\}\) 与 \(\{+,-,-\}\) 都包含一对 \(\{+,-\}\)， \(\{-,-,-\}\) 包含一对 \(\{-,-\}\)。因此它们分别直接使用第 2.2 或 2.3 节的机制，对玻色和费米都保证非负。三条对称性中唯一需要重新分析的 是 \(\{+,+,+\}\)。

3.2 \(\{+,+,+\}\)：为什么玻色非负而费米不能保证

前两条时间反演仍先产生第 2.3 节的守恒荷。第三条时间反演随后约束这个 守恒荷空间中的 commutator matrix 和每个时间片传播。玻色 commutator 是反对称的，约束最后产生一个具有相同数目正、负本征值的实对称矩阵；费米 anticommutator 是对称的，同一步却产生实反对称矩阵。这一差别决定了本格中 玻色与费米的不同结论。

取三条两两反对易且平方均为 \(+I\) 的时间反演。可以选取一组基，使第一条 只做复共轭。另两条与它反对易，所以其矩阵部分必为纯虚数，可以写成

\[ \Theta_1=\mathcal K,\qquad \Theta_2=iR_2\mathcal K,\qquad \Theta_3=iR_3\mathcal K, \]

其中 \(R_2,R_3\) 是实矩阵。把第 1.2 节的三条物理条件和三条时间反演 彼此反对易逐项代入，得到

\[ \begin{gathered} \overline{A_\ell}=A_\ell,\qquad [R_2,A_\ell]=[R_3,A_\ell]=0,\qquad R_2R_3=-R_3R_2,\\ R_j^2=I,\qquad R_j^TgR_j=-g,\qquad CR_jC=-R_j, \qquad j=2,3. \end{gathered} \]

前两条时间反演的乘积 \(Q=\Theta_1\Theta_2=-iR_2\) 满足 \(Q^2=-I\)，并像第 2.3 节一样 产生守恒荷。以下只在 \(Q=+i\) 的 \(N\) 维守恒荷空间工作。 \(\Theta_1=\mathcal K\) 使每个时间片矩阵及完整传播矩阵在这个空间中均为实数。 第三条时间反演给出

\[ \eta=\left.(gR_3)\right|_{Q=+i}. \]

这个限制没有零本征值。事实上，五条矩阵关系直接给出

\[ Q^T(gR_3)Q=-gR_3. \]

因为 \(+i\) 与 \(-i\) 相乘为 \(+1\)，上式使两个不同 \(Q\) 空间之间的 \(gR_3\) 矩阵元全部为零。完整 \(gR_3\) 可逆，所以两个对角 blocks 都可逆，特别是上面定义的 \(\eta\) 可逆。

先计算 \(\eta\) 的转置。由 \(R_3^TgR_3=-g\) 与 \(R_3^2=I\) 得 \(R_3^Tg=-gR_3\)。所以玻色与费米分别有

\[ \begin{array}{lll} \text{玻色：}&g^T=-g,&(gR_3)^T=-R_3^Tg=gR_3,\\[2pt] \text{费米：}&g^T= g,&(gR_3)^T= R_3^Tg=-gR_3. \end{array} \]

因而玻色的 \(\eta\) 是实对称矩阵，费米的 \(\eta\) 是实反对称矩阵。 再利用 \(gA_\ell+A_\ell^Tg=0\) 与 \([R_3,A_\ell]=0\)，逐项得到

\[ \begin{aligned} \left(A_\ell|_{Q=+i}\right)^T\eta +\eta\left(A_\ell|_{Q=+i}\right) &=\left.\left(A_\ell^TgR_3+gR_3A_\ell\right)\right|_{Q=+i}\\ &=\left.\left(-gA_\ell R_3+gR_3A_\ell\right)\right|_{Q=+i}=0. \end{aligned} \]

玻色：三条时间反演直接产生 split-orthogonal 结构

对玻色，\(\eta^T=\eta\)，而完整 Nambu commutator matrix 是 \(-gC=\operatorname{diag}(I_N,-I_N)\)。由 \(CR_2C=-R_2\) 和 \(R_2R_3=-R_3R_2\) 可得 \(CR_3\) 与 \(Q=-iR_2\) 对易，所以 \(CR_3\) 的作用不会离开 \(Q=+i\) 空间。再使用 \(CgC=-g\)、\(CR_3C=-R_3\) 及 \(R_3^Tg=-gR_3\)，直接算得

\[ \begin{aligned} (CR_3)^T(gR_3)(CR_3) &=R_3^TCgR_3CR_3=-gR_3,\\ (CR_3)^T(-gC)(CR_3) &=R_3^TC(-gC)CR_3=gC. \end{aligned} \]

这两行分别把 \(\eta=gR_3\) 和 commutator matrix \(-gC\) 变成各自的 相反数。因此它们在 \(Q=+i\) 的 \(N\) 维空间内都有相同数目的正、负 本征值，故 \(N\) 必为偶数。对 commutator matrix，这个结论具体写成

\[ [\hat d_\mu,\hat d_\nu^+] \sim\operatorname{diag}\!\left(I_{N/2},-I_{N/2}\right). \]

对 \(\eta\) 另作一次实换基后可以直接取

\[ \eta=\operatorname{diag}\!\left(I_{N/2},-I_{N/2}\right). \]

上一条生成元等式保证每层传播 \(e^{A_\ell|_{Q=+i}}\) 保持 \(\eta\)，因为

\[ \frac{d}{dt}\left[e^{t(A_\ell|_{Q=+i})^T}\eta e^{tA_\ell|_{Q=+i}}\right] =e^{t(A_\ell|_{Q=+i})^T} \left[\left(A_\ell|_{Q=+i}\right)^T\eta +\eta\left(A_\ell|_{Q=+i}\right)\right] e^{tA_\ell|_{Q=+i}}=0. \]

在 \(t=0\) 时左边为 \(\eta\)，所以 \([e^{A_\ell|_{Q=+i}}]^T\eta e^{A_\ell|_{Q=+i}}=\eta\)。完整传播为

\[ M|_{Q=+i} =e^{A_1|_{Q=+i}}e^{A_2|_{Q=+i}}\cdots e^{A_k|_{Q=+i}} \]

也保持 \(\eta\)。把每层写成 \(e^{tA_\ell|_{Q=+i}}\) 便得到一条从单位矩阵 \(t=0\) 到实际传播 \(t=1\) 的连续路径，而且路径上的每个矩阵都保持 \(\eta\)。满足 \(M^T\eta M=\eta\) 的实矩阵组成 \(O(N/2,N/2)\)。这里 \(\eta\) 的正、负 blocks 大小相同，因此称为 split orthogonal group；上面的连续路径进一步说明 实际传播位于它与单位矩阵相连的部分 \(SO_0(N/2,N/2)\)。

split-orthogonal determinant theorem 来自 Wang、Liu、Iazzi、 Troyer 与 Harcos, Phys. Rev. Lett. 115, 250601 (2015)； 该文附录说明其数学证明由 Harcos 与 Tao 完成。原定理中与这里直接相关的结论是

\[ M|_{Q=+i}\in SO_0(N/2,N/2) \quad\Longrightarrow\quad \det\!\left(I+M|_{Q=+i}\right)\geq0. \]

原论文把这条矩阵结论用于费米权重。本报告的玻色权重需要 \(\det(I-M)\)；把上述定理与紧接着给出的 Pfaffian 等式结合，得到

\[ (-1)^{N/2}\det\!\left(I-M|_{Q=+i}\right)\geq0. \]

这正是玻色 trace 所需的符号。上面的 commutator block 有 \(N/2\) 个负方向，每个方向在改写为标准玻色湮灭算符时贡献一个负号， 合计也是 \((-1)^{N/2}\)。生成元等式还给出

\[ \begin{aligned} 0 &=\operatorname{Tr}\!\left[ \eta^{-1}\left(A_\ell|_{Q=+i}\right)^T\eta +A_\ell|_{Q=+i}\right]\\ &=2\operatorname{Tr}\!\left(A_\ell|_{Q=+i}\right). \end{aligned} \]

所以第 2.3 节 trace 公式中的指数因子等于 1。行列式带来的 \((-1)^{N/2}\) 与重新识别玻色湮灭算符产生的 \((-1)^{N/2}\) 相消，最后得到

\[ \boxed{ p_{\rm B}=(-1)^{N/2} \det\!\left(I-M|_{Q=+i}\right)^{-1}>0 \quad\text{（除 pole 外）}.} \]
为什么 split-orthogonal determinant theorem 给出这两个符号

对实矩阵 \(M\)，等式 \(M^T\eta M=\eta\) 使实本征值按 \(\lambda,\lambda^{-1}\) 成对出现，非实本征值再连同复共轭组成四个一组。 非实四元组对 \(\det(I+M)\) 的贡献是绝对值平方。一个负实倒数对的贡献 \((1+\lambda)(1+\lambda^{-1})\) 为负；但在 \(SO_0(N/2,N/2)\) 中，负实倒数对只能成双出现，否则正、负两个子空间的 取向会相对单位矩阵翻转。故 \(\det(I+M)\geq0\)。 已知 \(\det(I+M)\) 的符号以后，可以通过二者之比求 \(\det(I-M)\) 的符号。由 \(M^T\eta M=\eta\) 直接得到

\[ \left[\eta(I-M)(I+M)^{-1}\right]^T =-\eta(I-M)(I+M)^{-1}. \]

方括号内是实反对称矩阵。它的行列式是 Pfaffian 的平方，故

\[ (-1)^{N/2}\frac{\det(I-M)}{\det(I+M)} =\operatorname{Pf}\!\left[\eta(I-M)(I+M)^{-1}\right]^2\geq0. \]

左边的 \((-1)^{N/2}\) 就是 \(\det\eta\)。结合第一条不等式便得到 \((-1)^{N/2}\det(I-M)\geq0\)。当 \(\det(I+M)=0\) 时由连续极限得到 同样结论。这里把两个行列式之比写成一个 Pfaffian 平方，是为了直接读出 所需的符号。

费米：\(\eta\) 为反对称矩阵，不能使用上述 determinant theorem

对费米，刚才已经算出 \(\eta^T=-\eta\)。它没有 \(\operatorname{diag}(I,-I)\) 的正、负方向，传播也不属于 split orthogonal group，所以玻色证明的关键不等式在这里不存在。三条全正时间反演本身确实允许 负权重。一个两个复费米模的构型是

\[ \begin{gathered} g=C=\sigma_x\otimes I_2,\qquad U_1=I_4,\quad U_2=i\sigma_z\otimes\sigma_x,\quad U_3=i\sigma_z\otimes\sigma_z,\\ A_1=\pi i\sigma_x\otimes\sigma_y,\qquad A_2=x\sigma_z\otimes I_2,\\ p_{\rm F}=2-e^x-e^{-x}<0\qquad(x\neq0). \end{gathered} \]

三条 \(\Theta_a=U_a\mathcal K\) 都平方为 \(+I\)、两两反对易，并保持 \(A_1,A_2\)，但 \(p_{\rm F}<0\)。因此费米 \(\{+,+,+\}\) 这一格不能 由三条时间反演保证非负。

展开：推广 split-orthogonal 判据，并彻底判定费米 \(\{+,+,+\}\)

split orthogonal group 不是一个只在 \(\eta=\operatorname{diag}(I,I,-I,-I)\) 这类特殊写法下才成立的技巧。 真正起作用的是两个物理条件：第一，存在一条平方为 \(+I\) 的时间反演， 使“取复共轭”在这套一体算符中有明确含义；第二，传播保持一个有正、负方向的 二次型。下面先把这两个条件写成不依赖基底的形式，再说明它们如何由不同的 时间反演类别产生。

原来的 Nambu 矩阵可以是复数，正、负方向也不必一样多

设 \(M=e^{A_1}\cdots e^{A_k}\) 作用在一个有限维一体向量空间上。 假定这个空间中有一条时间反演 \(\Theta_0\)，以及一个 Hermitian、可逆的 矩阵 \(\eta\)，满足

\[ \Theta_0^2=I,\qquad \Theta_0A_\ell\Theta_0^{-1}=A_\ell,\qquad \Theta_0\eta\Theta_0^{-1}=\eta, \qquad A_\ell^\dagger\eta+\eta A_\ell=0. \]

这里不要求原始基底中的 \(A_\ell\)、\(M\) 或 \(\eta\) 为实矩阵。 因为 \(\Theta_0^2=I\)，可以选取一组在 \(\Theta_0\) 下不变的基向量； 在这组基中，\(\Theta_0\) 就是普通复共轭。前两条不变性随即说明 \(A_\ell\) 与 \(\eta\) 都是实矩阵，而 Hermitian 的 \(\eta\) 在这里就是 实对称矩阵。再作一次实换基，可以把它写成

\[ \eta=\operatorname{diag}(I_p,-I_q), \qquad \dim M=p+q. \]

\(p\) 和 \(q\) 分别是 \(\eta\) 的正、负方向数目；不需要 \(p=q\)。 每一层从 \(t=0\) 到 \(t=1\) 的传播 \(e^{tA_\ell}\) 都保持 \(\eta\)， 所以它们的乘积与单位矩阵连续相连。由此得到比 split 情形更一般的结论：

\[ \boxed{ \det(I+M)\geq0,\qquad (-1)^q\det(I-M)\geq0 \quad(p+q\ \text{为偶数}).} \]

若 \(p+q\) 为奇数，保持 \(\eta\) 的本征值仍按 \(\lambda,\lambda^{-1}\) 出现，剩下的一个本征值必须是 \(+1\)，因此 \(\det(I-M)=0\)。

上述推广的完整推导

先证明 \(\det(I+M)\)。若 \(p>q\)，给系统添加 \(p-q\) 个完全不参与 传播的辅助自由度，并令这些自由度对应 \(\eta\) 的负方向：

\[ \widetilde M=\operatorname{diag}(M,I_{p-q}),\qquad \widetilde\eta=\operatorname{diag}(\eta,-I_{p-q}). \]

于是 \(\widetilde\eta\) 恰有 \(p\) 个正方向和 \(p\) 个负方向， \(\widetilde M\) 位于与单位矩阵相连的 split orthogonal group。 split-orthogonal determinant theorem 给出

\[ 0\leq\det(I+\widetilde M) =2^{p-q}\det(I+M). \]

若 \(q>p\)，改为添加 \(q-p\) 个正方向，推导完全相同。因此原定理 并不需要正、负方向数目相等；相等只是在不添加辅助自由度时的特殊情形。

再证明 \(\det(I-M)\)。当 \(I+M\) 可逆时，由 \(M^T\eta M=\eta\) 逐项展开可得

\[ \left[\eta(I-M)(I+M)^{-1}\right]^T =-\eta(I-M)(I+M)^{-1}. \]

方括号内是实反对称矩阵。偶数维实反对称矩阵的行列式等于其 Pfaffian 的平方，所以

\[ \operatorname{Pf}\!\left[\eta(I-M)(I+M)^{-1}\right]^2 =\det\eta\,\frac{\det(I-M)}{\det(I+M)} =(-1)^q\frac{\det(I-M)}{\det(I+M)}\geq0. \]

刚才已经证明分母非负，故得到第二条不等式。若 \(I+M\) 不可逆， 把 \(M\) 沿着保持 \(\eta\) 的连续路径稍微移开，再取极限即可。 这个证明同时说明：原始矩阵是否看起来是实数并不重要；重要的是是否存在 \(\Theta_0^2=I\) 来定义一套实基底。

最大子群还可以扩展成单向半群

上面的等式正是 Wei 的半群框架中 maximal subgroup 的生成元条件。等式还可放宽为所有时间片取同一个方向的 不等式

\[ A_\ell^\dagger\eta+\eta A_\ell\succeq0 \quad\text{对所有 }\ell, \qquad\text{或}\qquad A_\ell^\dagger\eta+\eta A_\ell\preceq0 \quad\text{对所有 }\ell. \]

\(\succeq0\) 表示左边的 Hermitian 矩阵所有本征值都非负。 以第一种方向为例，直接求导得到

\[ \frac{d}{dt}\left(e^{tA_\ell^\dagger}\eta e^{tA_\ell}\right) =e^{tA_\ell^\dagger} (A_\ell^\dagger\eta+\eta A_\ell)e^{tA_\ell}\succeq0. \]

因而每一层都只把 \(\eta\) 向同一个方向改变，任意层数的乘积仍具有这个 性质。单向半群 determinant theorem 给出 \(\det(I+M)\geq0\)； MathOverflow 推导 给出了直接的矩阵证明，并明确覆盖等式之外的非零半群方向。负号方向可对 \(M^{-1}\) 使用同一 结论，再利用 \(\det(I+M)=\det(M)\det(I+M^{-1})\) 与 \(\det(M)>0\)。 任意 \((p,q)\) 的情形仍可用上一段添加不传播自由度的方法化为正、负方向 相等的情形。

这条扩展在物理上意味着：时间反演给出的正交群可以只是一个边界；沿着同一 \(\eta\) 方向加入耗散或放大的 HS 时间片以后，普通费米 determinant 仍然非负。若这个一体空间已经是一套独立算符，determinant 就是实际权重； 若它是完整 Nambu 空间，矩阵不等式仍然可以直接使用，但还要按第 2.6 节 保存 Fock-space lift。严格半群不经过零权重点时，单位算符所在的正区域 自动固定 lift；只有最大子群时则可能发生第 2.5 节的旋转变号。

不同时间反演类别具体产生什么矩阵结构

上述正交结构并不限于玻色 \(\{+,+,+\}\)。例如费米 \(\{+,-\}\) 中，可选取基底使

\[ \Theta_+=\mathcal K,\qquad \Theta_-=iR\mathcal K,\qquad R\ \text{为实矩阵}. \]

两条时间反演的平方、反对易关系以及对 \(g\) 的保持条件逐项给出

\[ R^2=-I,\qquad R^TgR=-g,\qquad [R,A_\ell]=0. \]

对费米子 \(g^T=g\)。由前两式有 \(R^Tg=gR\)，所以

\[ \eta=gR,\qquad \eta^T=\eta,\qquad A_\ell^T\eta+\eta A_\ell =-gA_\ell R+gRA_\ell=0. \]

因此费米 \(\{+,-\}\) 的完整 Nambu 传播本身就有 split-orthogonal 结构。具体地，Hermitian-conjugation 条件给出 \(CRC=-R\)；由于 \(g=C\)，有 \((gR)^2=I\)，而 \(R\) 把 \(gR\) 的正、负本征空间互相交换， 所以两者维数相同。它的物理权重之所以能够确定平方根的正号，仍是第 2.2 节的两个完整 物理部分互为复共轭；正交群结论在矩阵层面给出同一机制的另一种表现。

费米 \(\{+,+,+\}\)：无附加条件时不可能有正性定理

这里不能靠进一步推广“实对称”到“实反对称”来挽救。 实反对称矩阵 \(\omega\) 满足 \(M^T\omega M=\omega\) 时，本征值仍按 \(\lambda,\lambda^{-1},\overline\lambda, \overline\lambda^{-1}\) 出现。非实的四个本征值贡献非负数，正实倒数对也 贡献正数；但是一个负实倒数对满足

\[ \lambda<-1,\qquad -1<\lambda^{-1}<0,\qquad (1+\lambda)(1+\lambda^{-1})<0. \]

正交群中，与单位矩阵相连这一条件禁止这种负实倒数对单独出现；实 symplectic group 中没有这个限制。最小矩阵例已经是

\[ \omega=\begin{pmatrix}0&1\\-1&0\end{pmatrix},\qquad M=\begin{pmatrix}-e^x&0\\0&-e^{-x}\end{pmatrix},\qquad M^T\omega M=\omega, \]
\[ \det(I+M)=(1-e^x)(1-e^{-x}) =2-e^x-e^{-x}<0\qquad(x\neq0). \]

而且这个负矩阵仍与单位矩阵连续相连： \(M=e^{\pi\omega}e^{x\sigma_z}\)，两段 \(e^{t\pi\omega}\) 与 \(e^{tx\sigma_z}\) 都保持 \(\omega\)。 因此不能像正交群那样再挑选“与单位矩阵相连的部分”来排除它。

这个 \(M\) 不是随意写出的矩阵；它正是上面两模费米 \(\{+,+,+\}\) 反例在 \(Q=+i\) 独立一体算符空间中的传播。 为了排除 Nambu 平方根或矩阵换基造成的误判，可以直接在四维 Fock space 中计算。取基底 \(|00\rangle,|01\rangle,|10\rangle,|11\rangle\)，两个时间片为

\[ \hat h_1=\pi(\hat c_1\hat c_2+\hat c_1^+\hat c_2^+), \qquad \hat h_2=x(\hat n_1+\hat n_2-1). \]

它们的指数无需任何 determinant 公式便可算出：

\[ e^{\hat h_1}=\operatorname{diag}(-1,1,1,-1),\qquad e^{\hat h_2}=\operatorname{diag}(e^{-x},1,1,e^x), \]
\[ \boxed{ \operatorname{Tr}(e^{\hat h_1}e^{\hat h_2}) =2-e^x-e^{-x}<0\qquad(x\neq0).} \]

对应的 Nambu 矩阵与三条时间反演完整写为

\[ \begin{gathered} g=C=\sigma_x\otimes I_2,\qquad U_1=I_4,\quad U_2=i\sigma_z\otimes\sigma_x,\quad U_3=i\sigma_z\otimes\sigma_z,\\ A_1=\pi i\sigma_x\otimes\sigma_y,\qquad A_2=x\sigma_z\otimes I_2,\qquad \Theta_a=U_a\mathcal K. \end{gathered} \]

利用 Pauli 矩阵乘法可逐项验证

\[ \begin{gathered} gA_\ell+A_\ell^Tg=0,\qquad U_a^TgU_a=g,\qquad C\overline U_aC=U_a,\\ U_a\overline U_a=I,\qquad U_a\overline U_b+U_b\overline U_a=0\ (a\neq b),\qquad U_a^{-1}\overline{A_\ell}U_a=A_\ell. \end{gathered} \]

所以它满足费米 \(\{+,+,+\}\) 的全部条件，却有严格负权重。 这已经构成无附加条件下的完整反证：任何只从三条正平方、两两反对易的 时间反演推出权重非负的定理，都会错误地把这个构型判为非负。 因此周期表中费米 \(\{+,+,+\}\) 必须保留为空格；这不是现有证明不够强， 而是该类别本身确实包含负权重。

3.3 四条及以上为什么全部非负

若四条时间反演中同时出现正平方和负平方，直接选出一对 \(\{+,-\}\)。若四条全部同号，取其中三条的乘积

\[ \widetilde\Theta=\Theta_2\Theta_3\Theta_4, \qquad \widetilde\Theta^2=-\Theta_2^2\Theta_3^2\Theta_4^2, \qquad \Theta_1\widetilde\Theta=-\widetilde\Theta\Theta_1. \]

三条反幺正变换的乘积仍是反幺正变换，而且平方与 \(\Theta_1\) 相反。 因而四条同号对称性也会生成一对 \(\{+,-\}\)。更多对称性只需选取其中 四条，所以玻色和费米从四条起全部保证非负。

4.2 pairing 项并不妨碍时间反演定号

pairing 项使湮灭算符与产生算符在传播中混合，因此粒子数守恒问题中预先给定的 单粒子空间不再存在。双时间反演产生的 \(P\) 或 \(Q\) 恰好完成新的物理分解， 所以时间反演正性可以直接推广到含 pairing 的模型。

一个玻色例子是两个互为复共轭的 BdG copies：

\[ \begin{aligned} \hat H_0={}& \hat b^+K\hat b+\hat c^+\overline K\hat c +\frac12\left( \hat b^+\Delta\hat b^{+T} +\hat c^+\overline\Delta\hat c^{+T} +\mathrm{h.c.}\right),\\ \hat H_I={}&U\sum_i(\hat n_{b,i}-\hat n_{c,i})^2, \qquad U>0, \end{aligned} \]

其中 \(K=K^\dagger\)、\(\Delta=\Delta^T\)。玻色二次 Hamiltonian 有下界的一个 直接条件是

\[ \begin{pmatrix}K&\Delta\\ \Delta^\dagger&K^T\end{pmatrix}>0. \]

例如令 \(K=\kappa I+T\)，取 \(\kappa>\lVert T\rVert+\lVert\Delta\rVert\) 即可。相互作用的连续 HS 分解为

\[ e^{-\Delta\tau U(\hat n_{b,i}-\hat n_{c,i})^2} \propto\int d\phi_i\,e^{-\phi_i^2/2} e^{i\sqrt{2\Delta\tau U}\phi_i(\hat n_{b,i}-\hat n_{c,i})}. \]

在 flavor space 取 \(\Theta_+=\sigma_x\mathcal K\) 与 \(\Theta_-=i\sigma_y\mathcal K\)。它们平方分别为 \(+I,-I\)，彼此反对易； hopping、pairing 和每个固定 \(\phi_i\) 的 HS 时间片都保持不变。因此第 2.2 节逐构型给出正权重。\(K\) 可以包含 triangular 或 kagome frustrated hopping， \(\Delta\) 可以包含两个 chirality 相反的 \(d\pm id\) pairing。

费米侧的同类例子是相互作用 helical \(p\pm ip\) 超导体：

\[ \begin{aligned} \hat H_0={}&\sum_{\langle ij\rangle,\sigma} \left[-t\,c_{i\sigma}^+c_{j\sigma} +\Delta_{ij,\sigma}c_{i\sigma}^+c_{j\sigma}^+ +\mathrm{h.c.}\right] -\mu\sum_{i\sigma}n_{i\sigma},\\ \hat H_I={}&-U\sum_i \left(n_{i\uparrow}-\frac12\right) \left(n_{i\downarrow}-\frac12\right),\qquad U>0, \end{aligned} \]

取 \(\Delta_\uparrow=p+ip\)、\(\Delta_\downarrow=p-ip\)，并在实 charge channel 中分解吸引相互作用。同一对 \(\Theta_+,\Theta_-\) 保持每个 HS 时间片，所以这个破坏粒子数守恒的费米模型也逐构型无符号。

5. 回到 note 的五条 \(J_1,J_2\) 关系

5.1 五条关系怎样变成物理时间反演

note 枚举的是

\[ \begin{gathered} J_1^TgJ_1=\pm g,\qquad J_1^2=\pm I,\\ J_2^TgJ_2=\pm g,\qquad J_2^2=\pm I,\\ J_1J_2=\pm J_2J_1. \end{gathered} \]

若 \(J_a^TgJ_a=g\)，取 \(U_a=J_a\)；若 \(J_a^TgJ_a=-g\)，取 \(U_a=iJ_a\)。两种情况下都有 \(U_a^TgU_a=g\)，而且 \((U_a\mathcal K)^2=J_a^2\)。随后还要逐项检查

\[ C\overline{U_a}C=U_a,\qquad U_a^{-1}\overline{A_\ell}U_a=A_\ell, \]

才能把 \(\Theta_a=U_a\mathcal K\) 称为这一辅助场构型的时间反演。 五条离散关系本身只描述 \(J_1,J_2\) 与 \(g\) 的代数关系，不会自动保证 Hermitian conjugation 相容，也不会自动保证具体 \(A_\ell\) 不变。

两条物理时间反演的相对对易号为 note 中 \(J_1J_2=\pm J_2J_1\) 的符号再乘以 \((J_1^TgJ_1)/g\) 和 \((J_2^TgJ_2)/g\) 的两个符号。这是因为只有一条 \(U_a\) 带相因子 \(i\) 时，另一条反幺正变换会把 \(i\) 复共轭成 \(-i\)。 用这条规则即可把 32 种五符号组合直接放入第 1.3 节的周期表。

5.2 \(A_{\rm group}\) 与 \(A_{\rm cone}\) 使用两条独立证明路线

对最大子群方向，note 使用

\[ J_1^TA_{\rm group}J_1=\overline{A_{\rm group}},\qquad J_2^TA_{\rm group}J_2=\overline{A_{\rm group}}. \]

当第 5.1 节的物理条件也成立时，两条时间反演逐层保持同一构型，可以直接应用 本卷的周期表。对收缩方向，第二式改为

\[ J_1^TA_{\rm cone}J_1=\overline{A_{\rm cone}},\qquad J_2^TA_{\rm cone}J_2=-\overline{A_{\rm cone}}. \]

第二条变换这时把同一个 generator 变成其相反数，不再是固定辅助场构型的 时间反演。\(A_{\rm cone}\) 非空类的主要无符号证明是第 3 卷建立的收缩半群 与连通正分支。本卷只判断 \(A_{\rm group}\) 整体或加入额外对称性后的模型 子空间能否由时间反演直接定号。这两条路线互相补充，不能互相替代。

6. 结论

  1. 固定辅助场构型的时间反演必须保持 commutator 或 anticommutator、Hermitian conjugation 和每一个时间片。满足这些条件时，正性证明与 bare trace 的收敛区域无关。
  2. 反对易 \(\{+,-\}\) 产生 \(P^2=I\)，把系统分成两个互为复共轭的完整物理部分；反对易 \(\{-,-\}\) 产生 \(Q^2=-I\)，先消除 Nambu 重复，再给出 Kramers 简并。
  3. split-orthogonal 条件可以直接施加在完整 Nambu 传播矩阵上，但普通 determinant theorem 只给出 Fock trace 的平方。保存 \((M,\zeta)\) 并用 Pfaffian 乘法即可直接计算整体号；整个最大子群却不可能无条件恒正，因为 \(SO_0(2,2)\) 已包含返回同一个 \(M=I\)、而 Fock lift 从 \(+I\) 变成 \(-I\) 的旋转路径。
  4. 玻色 \(\{+,+,+\}\) 中，两条时间反演先产生守恒荷，第三条使传播属于 \(SO_0(N/2,N/2)\)。split-orthogonal determinant theorem 与 Pfaffian 等式共同给出的 \((-1)^{N/2}\)，和 \(N/2\) 个负 commutator blocks 的符号相消。费米在同一步得到的是反对称矩阵，并且存在负权重反例。
  5. 含 pairing 的模型同样可以由双时间反演保证非负；\(P\) 或 \(Q\) 取代了粒子数守恒时预先给定的湮灭算符空间。
  6. note 的五条 \(J_1,J_2\) 关系只有在补充 Hermitian conjugation 相容性与逐时间片不变性后，才能转为物理时间反演。\(A_{\rm cone}\) 的定号仍属于独立的收缩半群路线。
