1. 固定辅助场构型以后，我们要证明什么

1.1 从二次 Hamiltonian 到 Monte Carlo 权重

Hubbard--Stratonovich 分解把相互作用问题变成许多依赖辅助场的二次 Hamiltonian。固定一条时空辅助场历史后，Monte Carlo 权重就是这一串 二次算符的 many-body trace：

\[ p=\operatorname{Tr}\!\left(e^{\hat h_1}e^{\hat h_2}\cdots e^{\hat h_k}\right), \qquad \hat h_\ell=\frac12\hat\chi^TgA_\ell\hat\chi . \]

这里 \(\hat\chi=(a_1,\ldots,a_N,a_1^+,\ldots,a_N^+)^T\) 同时列出湮灭算符和产生算符。玻色与费米可以使用同一个写法，区别只在

\[ g_{\rm B}=\begin{pmatrix}0&-I_N\\ I_N&0\end{pmatrix},\qquad g_{\rm F}=\begin{pmatrix}0&I_N\\ I_N&0\end{pmatrix},\qquad gA_\ell+A_\ell^Tg=0. \]

第一种 \(g\) 编码玻色 commutator，第二种编码费米 anticommutator。 二次算符作用在 \(2N\) 个 Nambu 分量上的一体传播矩阵为

\[ M=e^{A_1}e^{A_2}\cdots e^{A_k}. \]

Gaussian trace 恒等式把 many-body trace 化成有限维行列式。在本文约定下，

\[ \boxed{ p_{\rm B}=\bigl[(-1)^N\det(I-M)\bigr]^{-1/2},\qquad p_{\rm F}=\bigl[\det(I+M)\bigr]^{1/2}.} \]

平方根由左边的算符 trace 确定。这个公式可以逐模看懂。保持 commutator 或 anticommutator 的一体传播，其本征值以 \(\lambda,\lambda^{-1}\) 出现；一个费米模的两个占据态给 \(e^{-x/2}(1+e^x)\)，一个玻色模的全部占据态给 \(e^{x/2}/(1-e^x)\)，其中 \(\lambda=e^x\)。把所有物理模相乘， 正好得到上面的两个行列式公式。玻色式中的 \((-1)^N\) 来自 \((1-\lambda)(1-\lambda^{-1})=-(1-\lambda)^2/\lambda\)。

本卷的目标是直接利用每个固定辅助场构型的对称性，把 \(p\) 写成绝对值平方， 或写成一个本征值逐对相乘的普通行列式。这样实际权重的符号已经由对称性决定， 无须再单独讨论平方根选择。玻色构型若满足 \(\det(I-M)=0\)，权重有 pole； 除了这些点，下面的结论不依赖 occupation-number 求和是否收敛。

1.2 什么叫固定辅助场构型的时间反演对称性

把时间反演写成 \(\Theta=U\mathcal K\)，其中 \(\mathcal K\) 对所有复数 系数做复共轭。它要成为同一个玻色或费米 Fock space 上的物理反幺正变换， 并保持每一个时间片，需要满足

\[ U^TgU=g,\qquad C\overline UC=U,\qquad U^{-1}\overline{A_\ell}U=A_\ell, \qquad C=\begin{pmatrix}0&I_N\\I_N&0\end{pmatrix}. \]

三式的物理含义依次是：保持玻色 commutator 或费米 anticommutator； 变换产生算符时仍得到变换后湮灭算符的 Hermitian conjugate；固定这一辅助场 构型下的二次 Hamiltonian 不变。于是

\[ \Theta\hat h_\ell\Theta^{-1}=\hat h_\ell, \qquad \Theta^2=U\overline U=\pm I. \]

后文用 \(+\) 和 \(-\) 标记 \(\Theta^2=+I\) 与 \(\Theta^2=-I\)。 负平方表示 Kramers 型时间反演：任意状态 \(v\) 与 \(\Theta v\) 线性独立， 因为假如 \(\Theta v=cv\)，再作用一次便会得到 \(-v=|c|^2v\)，这是不可能的。

2. 两种基本无符号机制

2.1 \(P^2=I\) 与 \(Q^2=-I\) 的物理区别

两条反幺正变换的乘积是线性变换，因为两次复共轭相消。 这个线性变换平方为 \(+I\) 或 \(-I\) 时，承担的物理工作完全不同：

线性变换本征值物理作用
\(P^2=I\) \(P=+1\) 或 \(P=-1\) 像 flavor、layer 或 sublattice parity 一样，把系统分成两个完整的物理部分。每一部分都同时含有某些湮灭算符及其产生算符。
\(Q^2=-I\) \(Q=+i\) 或 \(Q=-i\) 不表示两个物理部分。它在每一对 Hermitian-conjugate Nambu 分量中各选一个，去掉把产生、湮灭算符同时写入 \(\hat\chi\) 所造成的重复。

这个区别可以直接由 Hermitian conjugation 看出。若 \(Pv=pv\)，其中 \(p=\pm1\) 是实数，那么与 \(v\) 对应算符的 Hermitian conjugate 仍在同一个 \(P=p\) 部分。若 \(Qv=iv\)，Hermitian conjugation 会同时复共轭系数， 所以相应的共轭算符满足 \(Qv^+=-iv^+\)。因此 \(Q=+i\) 的一半包含 \(N\) 个独立算符，\(Q=-i\) 的另一半正好包含它们的 Hermitian conjugates。

2.2 \(\{+,-\}\)：两个完整物理部分互为复共轭

取两条反对易时间反演

\[ \Theta_+^2=+I,\qquad \Theta_-^2=-I,\qquad \Theta_+\Theta_-=-\Theta_-\Theta_+, \]

并令 \(P=\Theta_+\Theta_-\)。直接相乘得到

\[ P^2=I,\qquad [P,A_\ell]=0,\qquad P\Theta_+=-\Theta_+P. \]

第一式让我们用 \(P=\pm1\) 标记两个部分；第二式说明每个时间片都不混合它们。 第三式说明 \(\Theta_+\) 交换它们。这个交换可以一行算清楚：

\[ Pv=pv \quad\Longrightarrow\quad P(\Theta_+v)=-\Theta_+(Pv)=-p\,\Theta_+v, \qquad p=\pm1. \]

反幺正变换还会把所有复数系数共轭。因此 \(P=-1\) 部分的整个 Gaussian trace 等于 \(P=+1\) 部分 trace 的复共轭。更明确地说，若两部分的演化算符分别为 \(\widehat{\mathcal U}_+\) 和 \(\widehat{\mathcal U}_-\)，则

\[ \widehat{\mathcal U}_-=\Theta_+\widehat{\mathcal U}_+\Theta_+^{-1} \quad\Longrightarrow\quad \operatorname{Tr}\widehat{\mathcal U}_- =\overline{\operatorname{Tr}\widehat{\mathcal U}_+}. \]

若把 \(P=+1\) 部分的 trace 记为 \(p_+\)，则

\[ \boxed{p=p_+\overline{p_+}=|p_+|^2\geq0.} \]

这就是最直接的物理图像：每个辅助场构型由两份共轭的 many-body evolution 组成，任何复相位都在两份之间抵消。写成一体矩阵就是

\[ p_{\rm B}=\left|\det\!\left[I-M\big|_{P=+1}\right]\right|^{-1}>0, \qquad p_{\rm F}=\left|\det\!\left[I+M\big|_{P=+1}\right]\right|\geq0. \]

每个 \(P\) 部分本身是一套完整的物理自由度，\(\Theta_+\) 交换这两套自由度。

2.3 \(\{-,-\}\)：\(Q\) 产生守恒荷，再回到 Kramers determinant

现在取

\[ \Theta_1^2=\Theta_2^2=-I,\qquad \Theta_1\Theta_2=-\Theta_2\Theta_1, \qquad Q=\Theta_1\Theta_2. \]

这次 \(Q^2=-I\)，所以 \(iQ\) 的本征值为 \(\pm1\)。它定义二次守恒荷

\[ \widehat{\mathcal Q}=\frac12\hat\chi^Tg(iQ)\hat\chi . \]

二次算符的对易子与矩阵对易子一一对应，而 \([Q,A_\ell]=0\)，因此

\[ [\widehat{\mathcal Q},\hat h_\ell] =\frac12\hat\chi^Tg[iQ,A_\ell]\hat\chi=0. \]

每个时间片都守恒 \(\widehat{\mathcal Q}\)。把满足 \(Qv=iv\) 的 \(N\) 个 线性组合记为 \(\hat d_1,\ldots,\hat d_N\)。它们具有相同的 \(iQ\) 本征值，Hermitian conjugates 位于 \(Q=-i\) 的另一半。于是 \(Q\) 把 \(2N\) 维 Nambu 写法重新组织成一套 \(N\) 维的守恒荷空间及其 Hermitian conjugate。这正是 Majorana Kramers class 中“先由两条时间反演产生 charge conservation， 再使用通常 Kramers 条件”的物理步骤。

一个看似反常但关键的事实是：\(\Theta_1\) 与 \(Q\) 反对易，却仍把 \(Q=+i\) 的算符留在这一半。原因是 \(\Theta_1\) 既带来反对易负号，又把 \(i\) 复共轭为 \(-i\)：

\[ Qv=iv \quad\Longrightarrow\quad Q(\Theta_1v)=-\Theta_1(Qv)=-\Theta_1(iv)=i\Theta_1v. \]

所以 \(\Theta_1^2=-I\) 在这个守恒荷空间内成为通常的 Kramers 时间反演。 若 \(M|_{Q=+i}\) 表示完整传播矩阵在这个空间上的作用，那么每个 非实本征值 \(\lambda\) 都有 \(\overline\lambda\)，每个实本征值至少出现两次。 在下面两个乘积中，每一对只计一次：

\[ \det\!\left(I\mp M|_{Q=+i}\right)= \prod_{\text{每对非实 }\lambda,\overline\lambda}|1\mp\lambda|^2 \prod_{\text{每对实 Kramers 本征值 }\lambda}(1\mp\lambda)^2\geq0. \]

同一条 Kramers 关系还说明每个 \(\operatorname{Tr}(A_\ell|_{Q=+i})\) 都是实数。因为时间反演在 \(Q=+i\) 空间内把 \(A_\ell\) 变成自身，取 trace 后得到

\[ \overline{\operatorname{Tr}(A_\ell|_{Q=+i})} =\operatorname{Tr}(A_\ell|_{Q=+i}). \]

因此下面 trace 公式中的指数因子是正实数。

对费米子，可以把 \(\hat d_1,\ldots,\hat d_N\) 选成新的湮灭算符。 这是因为完整 Nambu anticommutator matrix 是 \(I_{2N}\)，而 \(Q\) 保持它； 所以 \(Q=+i\) 空间内的 anticommutator 仍是正定的，可以把这 \(N\) 个组合 正交归一化成普通费米湮灭算符。除去不影响对易关系的常数和整体正负号， 守恒荷就是

\[ \widehat{\mathcal Q}=\sum_{\mu=1}^{N}\hat d_\mu^+\hat d_\mu+\text{常数}. \]

因为每个 \(\hat h_\ell\) 都与这个粒子数对易，它不再含 \(\hat d_\mu\hat d_\nu\) 或 \(\hat d_\mu^+\hat d_\nu^+\) 项。于是通常的 粒子数守恒 trace 公式给出

\[ p_{\rm F}= \exp\!\left[-\frac12\sum_\ell \operatorname{Tr}\!\left(A_\ell|_{Q=+i}\right)\right] \det\!\left(I+M|_{Q=+i}\right)\geq0. \]

玻色子的区别来自 Nambu commutator。完整 commutator matrix 及其在 \(Q\) 作用下的变换为

\[ [\hat\chi,\hat\chi^+]=-gC=\operatorname{diag}(I_N,-I_N),\qquad Q^+(-gC)Q=-gC. \]

第二式来自两条时间反演都保持 commutator。它还说明 \(Q=+i\) 与 \(Q=-i\) 两个空间在这个 commutator matrix 下彼此正交。完整矩阵 \(-gC\) 没有零 本征值，所以它限制到任一空间后也没有零本征值；因此不会留下像 \(\hat b+\hat b^+\) 那样与自身 Hermitian conjugate 对易的组合。作一次保持 \(Q\) 的换基后， \(\hat d_1,\ldots,\hat d_N\) 与其 Hermitian conjugates 的 commutator matrix 可以写成两个对角 blocks：

\[ [\hat d_\mu,\hat d_\nu^+] =\begin{pmatrix}I&0\\0&-I\end{pmatrix}_{\mu\nu}. \]

上面的负 block 表示：在这个 block 中，真正的玻色湮灭算符是 \(\hat d_\mu^+\)。 每交换一次 \(\hat d_\mu\leftrightarrow\hat d_\mu^+\)，单模 trace 多出一个 负号。\(\Theta_1^2=-I\) 保持两个 commutator blocks，并在每个 block 内产生 Kramers 双重简并，所以负 block 的维数必为偶数，所有额外负号相乘为 \(+1\)。 两个 blocks 都允许为空。五条关系并不固定负 block 的具体维数：最小 \(N=2\) 表示中，B15 的 commutator matrix 是 \(I_2\)，B27 的则是 \(-I_2\)。对称性固定的是负 block 维数为偶数。

\[ \boxed{ p_{\rm B}= \frac{\displaystyle \exp\!\left[\frac12\sum_\ell \operatorname{Tr}\!\left(A_\ell|_{Q=+i}\right)\right]} {\det\!\left(I-M|_{Q=+i}\right)}>0 \quad\text{（除玻色 pole 外）}.} \]

2.4 为什么只有一条时间反演时，上述 Nambu 结论不成立

在粒子数守恒问题中，湮灭算符空间本来就是一套独立的一体空间，一条 \(\Theta^2=-I\) 已足以产生 Kramers 简并。含有 superconducting 或 bosonic pairing 项时，湮灭算符会在传播中变成产生算符的线性组合；Nambu 写法因此把 两者一起保留。一条时间反演虽然让完整 \(2N\) 维谱 Kramers 简并，却没有告诉 我们怎样从 Nambu 表示中选出不重复的 \(N\) 个算符。

最小费米例已经说明这一点。取

\[ g=C=\sigma_x,\qquad U=-\sigma_y,\qquad A=\operatorname{diag}(-2ix,2ix),\qquad x\in\mathbb R. \]

这组矩阵满足

\[ U^TgU=g,\qquad C\overline UC=U,\qquad U^{-1}\overline AU=A,\qquad U\overline U=-I. \]

因而 \(\Theta=U\mathcal K\) 是平方为 \(-I\) 的时间反演。对应的算符 evolution 和 trace 是

\[ \hat n=\hat c^+\hat c,\qquad \widehat{\mathcal U}(x)=e^{-2ix(\hat n-1/2)},\qquad p_{\rm F}(x)=2\cos x. \]

它具有一条平方为 \(-I\) 的 Nambu 时间反演，但在 \(\pi/2<x<\pi\) 时权重为负。第二条反对易时间反演的作用正是产生 \(P\) 或 \(Q\)，补上 Nambu 表示中缺失的物理分解。

玻色也有同样直接的单时间反演反例。取一个玻色模

\[ g=\begin{pmatrix}0&-1\\1&0\end{pmatrix},\qquad C=\sigma_x,\qquad U=I_2,\qquad A=xg,\qquad 0<x<2\pi. \]

此时 \(\Theta=\mathcal K\) 平方为 \(+I\)，并保持该时间片；对应二次算符为 \(\hat h=-x(\hat b^2+\hat b^{+2})/2\)。然而

\[ M=e^{xg},\qquad (-1)^1\det(I-M)=-4\sin^2\!\frac{x}{2}<0. \]

所以解析延拓定义的玻色权重是纯虚数。一条平方为 \(+I\) 的时间反演同样不能 单独给 Nambu Gaussian 权重定号。

3. 三条及更多时间反演

3.1 含有负平方时间反演的三条类别

\(\{+,+,-\}\) 与 \(\{+,-,-\}\) 都包含一对 \(\{+,-\}\)， \(\{-,-,-\}\) 包含一对 \(\{-,-\}\)。因此它们分别直接使用第 2.2 或 2.3 节的机制，对玻色和费米都保证非负。三条对称性中唯一需要重新分析的 是 \(\{+,+,+\}\)。

3.2 \(\{+,+,+\}\)：为什么玻色非负而费米不能保证

前两条时间反演仍先产生第 2.3 节的守恒荷。第三条时间反演随后约束这个 守恒荷空间中的 commutator matrix 和每个时间片传播。玻色 commutator 是反对称的，约束最后产生一个具有相同数目正、负本征值的实对称矩阵；费米 anticommutator 是对称的，同一步却产生实反对称矩阵。这一差别决定了本格中 玻色与费米的不同结论。

取三条两两反对易且平方均为 \(+I\) 的时间反演。可以选取一组基，使第一条 只做复共轭。另两条与它反对易，所以其矩阵部分必为纯虚数，可以写成

\[ \Theta_1=\mathcal K,\qquad \Theta_2=iR_2\mathcal K,\qquad \Theta_3=iR_3\mathcal K, \]

其中 \(R_2,R_3\) 是实矩阵。把第 1.2 节的三条物理条件和三条时间反演 彼此反对易逐项代入，得到

\[ \begin{gathered} \overline{A_\ell}=A_\ell,\qquad [R_2,A_\ell]=[R_3,A_\ell]=0,\qquad R_2R_3=-R_3R_2,\\ R_j^2=I,\qquad R_j^TgR_j=-g,\qquad CR_jC=-R_j, \qquad j=2,3. \end{gathered} \]

前两条时间反演的乘积 \(Q=\Theta_1\Theta_2=-iR_2\) 满足 \(Q^2=-I\)，并像第 2.3 节一样 产生守恒荷。以下只在 \(Q=+i\) 的 \(N\) 维守恒荷空间工作。 \(\Theta_1=\mathcal K\) 使每个时间片矩阵及完整传播矩阵在这个空间中均为实数。 第三条时间反演给出

\[ \eta=\left.(gR_3)\right|_{Q=+i}. \]

这个限制没有零本征值。事实上，五条矩阵关系直接给出

\[ Q^T(gR_3)Q=-gR_3. \]

因为 \(+i\) 与 \(-i\) 相乘为 \(+1\)，上式使两个不同 \(Q\) 空间之间的 \(gR_3\) 矩阵元全部为零。完整 \(gR_3\) 可逆，所以两个对角 blocks 都可逆，特别是上面定义的 \(\eta\) 可逆。

先计算 \(\eta\) 的转置。由 \(R_3^TgR_3=-g\) 与 \(R_3^2=I\) 得 \(R_3^Tg=-gR_3\)。所以玻色与费米分别有

\[ \begin{array}{lll} \text{玻色：}&g^T=-g,&(gR_3)^T=-R_3^Tg=gR_3,\\[2pt] \text{费米：}&g^T= g,&(gR_3)^T= R_3^Tg=-gR_3. \end{array} \]

因而玻色的 \(\eta\) 是实对称矩阵，费米的 \(\eta\) 是实反对称矩阵。 再利用 \(gA_\ell+A_\ell^Tg=0\) 与 \([R_3,A_\ell]=0\)，逐项得到

\[ \begin{aligned} \left(A_\ell|_{Q=+i}\right)^T\eta +\eta\left(A_\ell|_{Q=+i}\right) &=\left.\left(A_\ell^TgR_3+gR_3A_\ell\right)\right|_{Q=+i}\\ &=\left.\left(-gA_\ell R_3+gR_3A_\ell\right)\right|_{Q=+i}=0. \end{aligned} \]

玻色：三条时间反演直接产生 split-orthogonal 结构

对玻色，\(\eta^T=\eta\)，而完整 Nambu commutator matrix 是 \(-gC=\operatorname{diag}(I_N,-I_N)\)。由 \(CR_2C=-R_2\) 和 \(R_2R_3=-R_3R_2\) 可得 \(CR_3\) 与 \(Q=-iR_2\) 对易，所以 \(CR_3\) 的作用不会离开 \(Q=+i\) 空间。再使用 \(CgC=-g\)、\(CR_3C=-R_3\) 及 \(R_3^Tg=-gR_3\)，直接算得

\[ \begin{aligned} (CR_3)^T(gR_3)(CR_3) &=R_3^TCgR_3CR_3=-gR_3,\\ (CR_3)^T(-gC)(CR_3) &=R_3^TC(-gC)CR_3=gC. \end{aligned} \]

这两行分别把 \(\eta=gR_3\) 和 commutator matrix \(-gC\) 变成各自的 相反数。因此它们在 \(Q=+i\) 的 \(N\) 维空间内都有相同数目的正、负 本征值，故 \(N\) 必为偶数。对 commutator matrix，这个结论具体写成

\[ [\hat d_\mu,\hat d_\nu^+] \sim\operatorname{diag}\!\left(I_{N/2},-I_{N/2}\right). \]

对 \(\eta\) 另作一次实换基后可以直接取

\[ \eta=\operatorname{diag}\!\left(I_{N/2},-I_{N/2}\right). \]

上一条生成元等式保证每层传播 \(e^{A_\ell|_{Q=+i}}\) 保持 \(\eta\)，因为

\[ \frac{d}{dt}\left[e^{t(A_\ell|_{Q=+i})^T}\eta e^{tA_\ell|_{Q=+i}}\right] =e^{t(A_\ell|_{Q=+i})^T} \left[\left(A_\ell|_{Q=+i}\right)^T\eta +\eta\left(A_\ell|_{Q=+i}\right)\right] e^{tA_\ell|_{Q=+i}}=0. \]

在 \(t=0\) 时左边为 \(\eta\)，所以 \([e^{A_\ell|_{Q=+i}}]^T\eta e^{A_\ell|_{Q=+i}}=\eta\)。完整传播为

\[ M|_{Q=+i} =e^{A_1|_{Q=+i}}e^{A_2|_{Q=+i}}\cdots e^{A_k|_{Q=+i}} \]

也保持 \(\eta\)。把每层写成 \(e^{tA_\ell|_{Q=+i}}\) 便得到一条从单位矩阵 \(t=0\) 到实际传播 \(t=1\) 的连续路径，而且路径上的每个矩阵都保持 \(\eta\)。这正是 split orthogonal group 的单位连通部分 \(SO_0(N/2,N/2)\)。

split-orthogonal determinant theorem 因而直接给出

\[ \det\!\left(I+M|_{Q=+i}\right)\geq0, \qquad (-1)^{N/2}\det\!\left(I-M|_{Q=+i}\right)\geq0. \]

第二条式子正是玻色 trace 所需的符号。上面的 commutator block 有 \(N/2\) 个负方向，每个方向在改写为标准玻色湮灭算符时贡献一个负号， 合计也是 \((-1)^{N/2}\)。生成元等式还给出

\[ \begin{aligned} 0 &=\operatorname{Tr}\!\left[ \eta^{-1}\left(A_\ell|_{Q=+i}\right)^T\eta +A_\ell|_{Q=+i}\right]\\ &=2\operatorname{Tr}\!\left(A_\ell|_{Q=+i}\right). \end{aligned} \]

所以第 2.3 节 trace 公式中的指数因子等于 1。行列式带来的 \((-1)^{N/2}\) 与重新识别玻色湮灭算符产生的 \((-1)^{N/2}\) 相消，最后得到

\[ \boxed{ p_{\rm B}= \frac{(-1)^{N/2}} {\det\!\left(I-M|_{Q=+i}\right)}>0 \quad\text{（除 pole 外）}.} \]
为什么 split-orthogonal determinant theorem 给出这两个符号

对实矩阵 \(M\)，等式 \(M^T\eta M=\eta\) 使实本征值按 \(\lambda,\lambda^{-1}\) 成对出现，非实本征值再连同复共轭组成四个一组。 非实四元组对 \(\det(I+M)\) 的贡献是绝对值平方。一个负实倒数对的贡献 \((1+\lambda)(1+\lambda^{-1})\) 为负；但在 \(SO_0(N/2,N/2)\) 中，负实倒数对只能成双出现，否则正、负两个子空间的 取向会相对单位矩阵翻转。故 \(\det(I+M)\geq0\)。 已知 \(\det(I+M)\) 的符号以后，可以通过二者之比求 \(\det(I-M)\) 的符号。由 \(M^T\eta M=\eta\) 直接得到

\[ \left[\eta(I-M)(I+M)^{-1}\right]^T =-\eta(I-M)(I+M)^{-1}. \]

方括号内是实反对称矩阵。它的行列式是 Pfaffian 的平方，故

\[ (-1)^{N/2}\frac{\det(I-M)}{\det(I+M)} =\operatorname{Pf}\!\left[\eta(I-M)(I+M)^{-1}\right]^2\geq0. \]

左边的 \((-1)^{N/2}\) 就是 \(\det\eta\)。结合第一条不等式便得到 \((-1)^{N/2}\det(I-M)\geq0\)。当 \(\det(I+M)=0\) 时由连续极限得到 同样结论。这里把两个行列式之比写成一个 Pfaffian 平方，是为了直接读出 所需的符号。

费米：\(\eta\) 为反对称矩阵，不能使用上述 determinant theorem

对费米，刚才已经算出 \(\eta^T=-\eta\)。它没有 \(\operatorname{diag}(I,-I)\) 的正、负方向，传播也不属于 split orthogonal group，所以玻色证明的关键不等式在这里不存在。三条全正时间反演本身确实允许 负权重。一个两个复费米模的构型是

\[ \begin{gathered} g=C=\sigma_x\otimes I_2,\qquad U_1=I_4,\quad U_2=i\sigma_z\otimes\sigma_x,\quad U_3=i\sigma_z\otimes\sigma_z,\\ A_1=\pi i\sigma_x\otimes\sigma_y,\qquad A_2=x\sigma_z\otimes I_2,\\ p_{\rm F}=2-e^x-e^{-x}<0\qquad(x\neq0). \end{gathered} \]

三条 \(\Theta_a=U_a\mathcal K\) 都平方为 \(+I\)、两两反对易，并保持 \(A_1,A_2\)，但 \(p_{\rm F}<0\)。因此费米 \(\{+,+,+\}\) 这一格不能 由三条时间反演保证非负。

3.3 四条及以上为什么全部非负

若四条时间反演中同时出现正平方和负平方，直接选出一对 \(\{+,-\}\)。若四条全部同号，取其中三条的乘积

\[ \widetilde\Theta=\Theta_2\Theta_3\Theta_4, \qquad \widetilde\Theta^2=-\Theta_2^2\Theta_3^2\Theta_4^2, \qquad \Theta_1\widetilde\Theta=-\widetilde\Theta\Theta_1. \]

三条反幺正变换的乘积仍是反幺正变换，而且平方与 \(\Theta_1\) 相反。 因而四条同号对称性也会生成一对 \(\{+,-\}\)。更多对称性只需选取其中 四条，所以玻色和费米从四条起全部保证非负。

4.2 pairing 项并不妨碍时间反演定号

pairing 项使湮灭算符与产生算符在传播中混合，因此粒子数守恒问题中预先给定的 单粒子空间不再存在。双时间反演产生的 \(P\) 或 \(Q\) 恰好完成新的物理分解， 所以时间反演正性可以直接推广到含 pairing 的模型。

一个玻色例子是两个互为复共轭的 BdG copies：

\[ \begin{aligned} \hat H_0={}& \hat b^+K\hat b+\hat c^+\overline K\hat c +\frac12\left( \hat b^+\Delta\hat b^{+T} +\hat c^+\overline\Delta\hat c^{+T} +\mathrm{h.c.}\right),\\ \hat H_I={}&U\sum_i(\hat n_{b,i}-\hat n_{c,i})^2, \qquad U>0, \end{aligned} \]

其中 \(K=K^+\)、\(\Delta=\Delta^T\)。玻色二次 Hamiltonian 有下界的一个 直接条件是

\[ \begin{pmatrix}K&\Delta\\ \Delta^+&K^T\end{pmatrix}>0. \]

例如令 \(K=\kappa I+T\)，取 \(\kappa>\lVert T\rVert+\lVert\Delta\rVert\) 即可。相互作用的连续 HS 分解为

\[ e^{-\Delta\tau U(\hat n_{b,i}-\hat n_{c,i})^2} \propto\int d\phi_i\,e^{-\phi_i^2/2} e^{i\sqrt{2\Delta\tau U}\phi_i(\hat n_{b,i}-\hat n_{c,i})}. \]

在 flavor space 取 \(\Theta_+=\sigma_x\mathcal K\) 与 \(\Theta_-=i\sigma_y\mathcal K\)。它们平方分别为 \(+I,-I\)，彼此反对易； hopping、pairing 和每个固定 \(\phi_i\) 的 HS 时间片都保持不变。因此第 2.2 节逐构型给出正权重。\(K\) 可以包含 triangular 或 kagome frustrated hopping， \(\Delta\) 可以包含两个 chirality 相反的 \(d\pm id\) pairing。

费米侧的同类例子是相互作用 helical \(p\pm ip\) 超导体：

\[ \begin{aligned} \hat H_0={}&\sum_{\langle ij\rangle,\sigma} \left[-t\,c_{i\sigma}^+c_{j\sigma} +\Delta_{ij,\sigma}c_{i\sigma}^+c_{j\sigma}^+ +\mathrm{h.c.}\right] -\mu\sum_{i\sigma}n_{i\sigma},\\ \hat H_I={}&-U\sum_i \left(n_{i\uparrow}-\frac12\right) \left(n_{i\downarrow}-\frac12\right),\qquad U>0, \end{aligned} \]

取 \(\Delta_\uparrow=p+ip\)、\(\Delta_\downarrow=p-ip\)，并在实 charge channel 中分解吸引相互作用。同一对 \(\Theta_+,\Theta_-\) 保持每个 HS 时间片，所以这个破坏粒子数守恒的费米模型也逐构型无符号。

4.3 main.tex 的 paired benchmark

该 benchmark 的两条自然时间反演在 flavor space 可写为

\[ \Theta_+=e^{-i\varphi}\sigma_x\mathcal K,\qquad \Theta_-=-e^{-i\varphi}\sigma_y\mathcal K, \qquad \Theta_+\Theta_-=\Theta_-\Theta_+=i\sigma_z. \]

它们彼此对易，不属于第 2 节的两种反对易双时间反演类别。因此该 benchmark 需要使用文章中针对它建立的另一条无符号证明；仅凭这里两条时间反演不能得出 逐构型非负。

5. 回到 note 的五条 \(J_1,J_2\) 关系

5.1 五条关系怎样变成物理时间反演

note 枚举的是

\[ \begin{gathered} J_1^TgJ_1=\pm g,\qquad J_1^2=\pm I,\\ J_2^TgJ_2=\pm g,\qquad J_2^2=\pm I,\\ J_1J_2=\pm J_2J_1. \end{gathered} \]

若 \(J_a^TgJ_a=g\)，取 \(U_a=J_a\)；若 \(J_a^TgJ_a=-g\)，取 \(U_a=iJ_a\)。两种情况下都有 \(U_a^TgU_a=g\)，而且 \((U_a\mathcal K)^2=J_a^2\)。随后还要逐项检查

\[ C\overline{U_a}C=U_a,\qquad U_a^{-1}\overline{A_\ell}U_a=A_\ell, \]

才能把 \(\Theta_a=U_a\mathcal K\) 称为这一辅助场构型的时间反演。 五条离散关系本身只描述 \(J_1,J_2\) 与 \(g\) 的代数关系，不会自动保证 Hermitian conjugation 相容，也不会自动保证具体 \(A_\ell\) 不变。

两条物理时间反演的相对对易号为 note 中 \(J_1J_2=\pm J_2J_1\) 的符号再乘以 \((J_1^TgJ_1)/g\) 和 \((J_2^TgJ_2)/g\) 的两个符号。这是因为只有一条 \(U_a\) 带相因子 \(i\) 时，另一条反幺正变换会把 \(i\) 复共轭成 \(-i\)。 用这条规则即可把 32 种五符号组合直接放入第 1.3 节的周期表。

5.2 \(A_{\rm group}\) 与 \(A_{\rm cone}\) 使用两条独立证明路线

对最大子群方向，note 使用

\[ J_1^TA_{\rm group}J_1=\overline{A_{\rm group}},\qquad J_2^TA_{\rm group}J_2=\overline{A_{\rm group}}. \]

当第 5.1 节的物理条件也成立时，两条时间反演逐层保持同一构型，可以直接应用 本卷的周期表。对收缩方向，第二式改为

\[ J_1^TA_{\rm cone}J_1=\overline{A_{\rm cone}},\qquad J_2^TA_{\rm cone}J_2=-\overline{A_{\rm cone}}. \]

第二条变换这时把同一个 generator 变成其相反数，不再是固定辅助场构型的 时间反演。\(A_{\rm cone}\) 非空类的主要无符号证明是第 3 卷建立的收缩半群 与连通正分支。本卷只判断 \(A_{\rm group}\) 整体或加入额外对称性后的模型 子空间能否由时间反演直接定号。这两条路线互相补充，不能互相替代。

6. 结论

  1. 固定辅助场构型的时间反演必须保持 commutator 或 anticommutator、Hermitian conjugation 和每一个时间片。满足这些条件时，正性证明与 bare trace 的收敛区域无关。
  2. 反对易 \(\{+,-\}\) 产生 \(P^2=I\)，把系统分成两个互为复共轭的完整物理部分；反对易 \(\{-,-\}\) 产生 \(Q^2=-I\)，先消除 Nambu 重复，再给出 Kramers 简并。
  3. 玻色 \(\{+,+,+\}\) 中，两条时间反演先产生守恒荷，第三条使传播属于 \(SO_0(N/2,N/2)\)。split-orthogonal determinant theorem 给出的 \((-1)^{N/2}\) 与 \(N/2\) 个负 commutator blocks 的符号相消。费米在同一步得到的是反对称矩阵，并且存在负权重反例。
  4. 含 pairing 的模型同样可以由双时间反演保证非负；\(P\) 或 \(Q\) 取代了粒子数守恒时预先给定的湮灭算符空间。
  5. note 的五条 \(J_1,J_2\) 关系只有在补充 Hermitian conjugation 相容性与逐时间片不变性后，才能转为物理时间反演。\(A_{\rm cone}\) 的定号仍属于独立的收缩半群路线。
