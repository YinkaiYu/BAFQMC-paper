4. 分类对象与判定层级

4.1 从五条离散关系到 \(2^5=32\) 个候选类

这项分类并不止于“能否写出某个 \(A\)”，也不止于寻找 maximal subgroup。它把两个 anti-linear structures 与 contraction semigroup 组合起来，系统判断五个二选一关系中的哪些组合 真正允许一个有内部的收缩区域：

  1. 先找 real orthogonal \(J_1,J_2\)，实现所选的五条离散 relations；
  2. 用 \(J_1^TAJ_1=\bar A\) 限制 \(A\)，使 determinant 或 trace weight 至少具有所需的 complex-conjugation pairing；
  3. 由 \(J_2g\) 或 \(iJ_2g\) 构造 Hermitian metric，并检查允许的 \(A\) 是否包含严格收缩方向；
  4. 最后才把抽象矩阵条件落实为 HS-decoupled physical Hamiltonian，并证明完整 Fock weight nonnegative。

第一项只回答 \(J_1,J_2\) 的 algebraic realization 是否存在。本次 Pauli-product 搜索发现 32 类全部有 realization，所以这一步并不是分类的 真正瓶颈。第二项通常也会给出非空的 linear space。真正区分 Passed 与 Failed 的是第三项：这个 space 中能否找到 strict contraction，而不只是 equality boundary。

maximal subgroup 与真正要找的 strict cone 不同

下式中的 \(J_2g\) 在相应分支可替换为 \(iJ_2g\)。若

\[ (J_2g)A+A^\dagger(J_2g)=0 , \]

\(e^A\) 保持该 metric，属于 contraction semigroup 的 maximal subgroup。它位于收缩区域的边界，描述可逆的 metric-preserving propagation。只找到这种 \(A\) 不能说明存在新的 strict contraction。 合作者在“硬算”中令 \(J_2^TAJ_2=\bar A\) 时，主要是在求这部分。

要让 semigroup 具有非空内部，还必须找到

\[ (J_2g)A+A^\dagger(J_2g)<0 . \]

合作者把 \(J_2^TAJ_2=-\bar A\) 所选出的 generators 称为 invariant cone candidates，目的正是检查其中能否满足这个严格不等式。 因此更准确的概括是：穷举在检查每组离散 relations 是否允许 “real-weight condition + nonempty strict contraction cone” 同时成立。 maximal subgroup 是计算的一部分，不是终点。

4.2 真正传播的是 \(e^A\)

note 已定义 \(h=\frac12\chi^TgA\chi\)，并把一个辅助场构型的矩阵写成 \(M=e^{A_1}\cdots e^{A_k}\)。因此 semigroup 若要约束这个构型， 必须对每个 \(e^{A_\ell}\) 给出在矩阵乘法下保持的条件。 设 \(\eta\) 是 Hermitian 且 \(\eta^2=I\)。标准 infinitesimal contraction condition 是

\[ \eta A+A^\dagger\eta\le0 . \]

对 \(e^{tA^\dagger}\eta e^{tA}\) 逐步求导：

\[ \begin{aligned} \frac{d}{dt}\left(e^{tA^\dagger}\eta e^{tA}\right) &=A^\dagger e^{tA^\dagger}\eta e^{tA} +e^{tA^\dagger}\eta e^{tA}A\\ &=e^{tA^\dagger}(A^\dagger\eta+\eta A)e^{tA}\le0 . \end{aligned} \]

从 \(t=0\) 积分到 \(1\) 得到

\[ (e^A)^\dagger\eta e^A\le\eta . \]

若两个矩阵都满足后一式，它们的乘积也满足，因为 \((M_1M_2)^\dagger\eta(M_1M_2) \le M_2^\dagger\eta M_2\le\eta\)。 这就是所需的 semigroup closure。

4.3 从矩阵候选到物理模型的四级检验

  1. \(J_2g\) 或 \(iJ_2g\) 是否 Hermitian 且平方为 \(I\)？
  2. 允许的 \(A\) 中是否存在 strict inequality，而不只是等号边界？
  3. \(J_1^TAJ_1=\bar A\) 是否把半负定方向保持为半负定方向？
  4. 生成元级条件是否进一步保证完整 bosonic/fermionic Fock trace 的正确符号与 branch？

前三级决定 propagation contraction；第四级才把 propagation result 升级成 sign-problem-free statement。后续各节依次完成这些检验。

5.2 strict interior 对 \(J_2^2\) 的要求

玻色先算。由 \(g^T=-g\) 和 \(gA+A^Tg=0\)，

\[ (gA)^T=A^Tg^T=-A^Tg=gA . \]

若 \(J_2^2=-I\)，则 \(J_2^T=-J_2\)，于是

\[ \begin{aligned} \Tr(J_2gA) &=\Tr[(J_2gA)^T]\\ &=\Tr[(gA)^T J_2^T]\\ &=-\Tr(gAJ_2) =-\Tr(J_2gA). \end{aligned} \]

所以 \(\Tr(J_2gA)=0\)。乘整体 \(i\) 也仍为零。 相应 contraction matrix 的 trace 是 \(2\operatorname{Re}\Tr(\eta A)=0\)。 Hermitian matrix 若半负定且 trace 为零，只能是零矩阵。 因而玻色要有 strict interior，必须取

\[ \boxed{J_2^2=I\qquad\text{(boson)}} . \]

费米则由 \(g^T=g\) 得到

\[ (gA)^T=A^Tg=-gA . \]

若 \(J_2^2=I\)，即 \(J_2^T=J_2\)，则

\[ \begin{aligned} \Tr(J_2gA) &=\Tr[(J_2gA)^T]\\ &=\Tr[-gAJ_2] =-\Tr(J_2gA)=0 . \end{aligned} \]

因此费米要有 strict interior，必须取相反的平方：

\[ \boxed{J_2^2=-I\qquad\text{(fermion)}} . \]

这一步直接解释了合作者所说的“玻色子和费米子并不对等”。 差别来自 \((gA)^T\) 在两种统计下一个对称、一个反对称。

5.3 commutator/anti-commutator 为什么不能忽略

现在只考虑上一小节允许 strict interior 的情形： 玻色 \(J_2^2=I\)，费米 \(J_2^2=-I\)。 对 \(J_2^TgJ_2=\pm g\) 的两种分支，分别使用上一表给出的 \(J_2g\) 或 \(iJ_2g\)。把 \(J_1^TAJ_1=\bar A\) 代入 contraction matrix，并逐项移动 \(J_1,J_2,g\)，得到四种直接结果：

规律可以用一句与 note 完全对齐的话表达： \(J_1\) 与 \(J_2\) 若同为保持 \(g\) 或同为翻转 \(g\)，二者必须反对易； 若一个保持 \(g\)、另一个翻转 \(g\)，二者必须对易。 \(J_1^2=I\) 或 \(-I\) 不影响这一步，所以这两个选择会成对出现。

为什么选错 commutation relation 会只剩边界？设正确的 Hermitian metric 为 \(\eta\)，并记 contraction matrix 本身为 \(\eta A+A^\dagger\eta\)。对于表中“另一种关系”，直接代入得到

\[ J_1^T\overline{\left(\eta A+A^\dagger\eta\right)}J_1 =-\left(\eta A+A^\dagger\eta\right). \]

左边只是复共轭加正交基变换，保持 eigenvalue signs； 右边却把所有 eigenvalues 变号。一个 matrix 不可能同时 strict seminegative 和 strict semipositive，所以只能等于零。

5.4 两条要求不仅必要，而且给出显式 strict point

按上一节选择 \(J_2^2\)，再按表中规则选择 commutator 或 anti-commutator。 令 \(\eta\) 为对应的 \(J_2g\) 或 \(iJ_2g\)，并直接取

\[ A_0=-\eta . \]

由 \(\eta^\dagger=\eta\) 与 \(\eta^2=I\)，contraction inequality 不是边界而是严格成立：

\[ \eta A_0+A_0^\dagger\eta =-\eta^2-\eta^2=-2I<0 . \]

再把 \(A_0=-\eta\) 代回，所选 \(J_2\) 关系保证 \(gA_0+A_0^Tg=0\)；上一小节的 commutation rule 保证 \(J_1^TA_0J_1=\bar A_0\)。因此这不是随机扫描中的“似乎通过”， 而是每一个允许类别都有明确 strict witness。

note 所选 ansatz 内的完整传播判据。 这里把 metric 限定为由 real orthogonal \(J_2\) 构造的 \(J_2g\) 或 \(iJ_2g\)，并将实性变换限定为 note 的 \(J_1^TAJ_1=\bar A\)。在这个范围内， 玻色 strict contraction 要求 \(J_2^2=I\)，费米要求 \(J_2^2=-I\)。 在此基础上，\(J_1\) 与 \(J_2\) 若对 \(g\) 同号作用就必须反对易， 异号作用就必须对易。\(J_1^2=\pm I\) 均可。 \(J_2\) 翻转 \(g\) 时使用 metric \(J_2g\)； \(J_2\) 保持 \(g\) 时使用 metric \(iJ_2g\)。

6. Octave 穷举、生成元与物理实现

本节把“穷举”分成三层：先完整枚举五条离散 relations，再判断 strict contraction interior 是否存在，最后求出每个通过类的全部 maximal-subgroup 与 invariant-cone generator directions。这样可以看清 程序究竟检验了什么，也不会把一个 Pauli representative 误当成已经完成的 physical sign-free model。

6.1 程序怎样逐项生成全部 32 类

程序不是随机抽样。它先固定与 note 相同的 canonical matrices：

\[ g_{\rm boson}=-(i\sigma_y)\otimes I,\qquad g_{\rm fermion}=\sigma_x\otimes I. \]

代码中的字母 Y 始终表示实矩阵 \(i\sigma_y=\left(\begin{smallmatrix}0&1\\-1&0\end{smallmatrix}\right)\)， 不是通常含复数元素的 \(\sigma_y\)。对一个、两个、三个 \(2\times2\) factors，程序依次生成所有

\[ P_1\otimes P_2\otimes\cdots,\qquad P_j\in\{I,\sigma_x,i\sigma_y,\sigma_z\}. \]

对每一对非平凡 Pauli words，代码直接相乘并读取下面五个正负号：

\[ J_1^TgJ_1=\pm g,\quad J_1^2=\pm I,\quad J_2^TgJ_2=\pm g,\quad J_2^2=\pm I,\quad J_1J_2=\pm J_2J_1. \]

五个正负号按固定顺序映射到一个五位 binary index。某一 index 第一次出现时保存当前 \(J_1,J_2\)；随后继续搜索，直到检查完三个 factors。玻色与费米各 32 个 index 都至少找到一对 representatives。 “三个 factors 足够”是本次 Pauli-product search 的计算结果，而不是 预先假定所有抽象表示都必须只有八维。

6.2 每一行具体做了哪些检查

  1. 重新计算五条关系的 Frobenius-norm residual，防止 class index 与保存的 matrices 不一致。
  2. 根据 \(J_2\) 对 \(g\) 的作用和 \(J_2^2\)，构造 \(\eta=J_2g\) 或 \(iJ_2g\)，再验证 \(\eta^\dagger=\eta\) 与 \(\eta^2=I\)。
  3. 用第 5 节的解析判据判断 strict interior：玻色必须 \(J_2^2=I\)，费米必须 \(J_2^2=-I\)；两个 \(J\) 对 \(g\) 同号作用时必须反对易，异号作用时必须对易。
  4. 对每个允许类取 \(A_0=-\eta\)，逐项验证 \(gA_0+A_0^Tg=0\)、 \(J_1^TA_0J_1=\bar A_0\)，以及 \(\eta A_0+A_0^\dagger\eta=-2I<0\)。
  5. 对不允许类不伪造一个数值 “Failed”。程序记录解析 obstruction： 要么 contraction matrix 的 trace 被迫为零，要么 \(J_1\) 把半负定方向映成半正定方向，因而只剩等号边界。

另一个脚本对 16 个 strict classes 选择便于物理解读的 \(J_1,J_2\)，再扫描矩阵空间的完整实 basis \(\{P,iP\}\)。一个 basis element 只有同时满足

\[ gA+A^Tg=0,\qquad J_1^TAJ_1=\bar A \]

才继续分类。若 \(\eta A+A^\dagger\eta=0\)，它进入 maximal-subgroup basis； 若 \(\eta A-A^\dagger\eta=0\)，它进入 invariant-cone 的线性 span，最后再对线性组合施加 \(\eta A\le0\)。因此第 6.6 节所列的 不是一个见证，而是选定 representative 下的全部生成元结构。

6.3 矩阵分类、算符收敛与物理模型的证据层级

表中的“存在 strict contraction”只陈述以下矩阵事实： 允许的 \(A\) 构成一个对 commutator 封闭的 generator region； 每个 \(e^A\) 满足 \((e^A)^\dagger\eta e^A\le\eta\)；任意数量的这类 propagators 相乘后仍满足同一不等式；strict element 没有 unit-circle eigenvalue。它没有自动包含下面这些物理要求：

  • 该 \(A\) 是否来自一个 Hermitian microscopic Hamiltonian 的合法 HS decomposition；
  • 玻色固定场 Fock trace 是否有限，正规序标量因子是否正确；
  • 玻色 metaplectic square-root representative 是否沿物理 operator branch 连续；
  • 费米 Nambu 写法是否已与 Majorana Spin representation 的符号约定完整对应；
  • 辅助场 measure 是否可归一化，以及 estimator 是否有可控方差。

所以“传播层面”不是弱化语气的内部简称，而是明确的证据边界： 它回答 \(A\) 和 \(M\) 的 matrix-semigroup question；只有再完成上述 operator 与 HS checks，才能升级为 physical sign-problem-free model。

何时可以立即升级为整个辅助场域恒正。 设辅助场构型空间连通；每个构型的完整 \(M(\phi)\) 都在同一个 strict contraction semigroup；\(J_1\) 条件连同 正规序标量因子的反线性条件使完整 operator weight \(W(\phi)\) 为实；\(W(\phi)\) 是连续、单值函数；并且至少有一个 参考构型 \(\phi_0\) 满足 \(W(\phi_0)>0\)。若另一个构型权重为负， 沿连接两点的连续路径，介值定理要求中间某点 \(W=0\)；玻色若通过 inverse determinant 换 branch，则必须经过 pole 或失去单值连续性。 strict contraction 已排除相应的 \(-1\) 或 \(+1\) eigenvalue， 因而这种改变不可能发生。所以整个连通辅助场域都在同一个正分支。 通常的连续 Gaussian field space \(\mathbb R^{N_\phi}\) 满足这里的 连通和单连通要求；零场 free configuration 常可作为正参考点。

因此一旦上述五项都验证完，不需要逐个辅助场再算符号。 本报告仍保留“传播层面”一词，是因为抽象 \(J_1,J_2,A_0\) 穷举本身 尚未替每个 candidate 指定连续的 HS map、positive reference 与 玻色 bare-trace/regularization 定义；不是因为 strict semigroup 内部 还可能无缘无故变号。

6.4 严格收缩与玻色 bare trace 收敛

下面把连通辅助场路径上的收敛论证写成一个可以逐项检查的命题。 设辅助场构型记为 \(\phi\)，完整虚时间传播矩阵为 \(\mathcal M(\phi)\)。需要同时满足：

  1. 辅助场空间是路径连通的，且 \(\mathcal M(\phi)\) 随 \(\phi\) 连续；
  2. 存在一个参考构型 \(\phi_0\)，通常取零场，使对应 bare Fock trace 有限；
  3. 存在同一个固定 Hermitian metric \(\eta\)，其 particle/hole 方向与参考构型的物理 Fock representation 一致，并且对每个构型都有 \(\mathcal M(\phi)^\dagger\eta\mathcal M(\phi)-\eta<0\)；
  4. 二次算符、正规序常数与 Nambu 平方根表示都由实际时间片乘积连续确定；正规序标量因子也满足使完整权重为实的反线性条件，而不是在每个构型上重新任选代数分支。

在通常的 real Gaussian HS transformation 中，构型空间就是 \(\mathbb R^{N_\phi}\)，第一项自动成立。第二项是物理稳定性： 自由 Hamiltonian 的化学势和 pairing gap 必须使 \(\operatorname{Tr}e^{-\beta H_0}\) 有限。第三项中的“同一个固定 metric”与“方向一致”不能删除，因为一个不定度规有 contracting 与 expanding 两种取向；只有包含稳定零场的那一种才是物理 Fock trace 所需的取向。

无配对时：收敛性不能在严格区域内丢失

number-conserving propagation 的 particle block 记为 \(\mathcal B(\phi)\)。先定义它的 singular values \(s_j\)：它们是正矩阵 \(\sqrt{\mathcal B^\dagger\mathcal B}\) 的 eigenvalues，衡量 \(\mathcal B\) 对各正交方向能放大多少。对应 Fock operator 的绝对 trace 为

\[ \operatorname{Tr}\sqrt{\hat U(\phi)^\dagger\hat U(\phi)} =\prod_{j=1}^{N}\frac{1}{1-s_j}, \qquad \max_j s_j<1. \]

这个公式可以直接从 polar decomposition 看出： \(\mathcal B=V\sqrt{\mathcal B^\dagger\mathcal B}\)，其中 \(V\) 的 Fock-space 作用是 unitary，不改变绝对值；再把正矩阵 \(\sqrt{\mathcal B^\dagger\mathcal B}\) 对角化，每个模的所有 占据数给出几何级数 \(1+s_j+s_j^2+\cdots=(1-s_j)^{-1}\)。所以 \(\max_j s_j<1\) 保证的是绝对收敛，而不只是有限维 determinant 的代数值。对一般 nonnormal \(\mathcal B\)，只知道所有 eigenvalues 位于单位圆内还不够；singular-value 条件才是这里需要的 operator statement。

标准物理取向的 strict contraction 正好直接给出这个条件。在 \((a,a^+)^T\) 顺序下，

\[ \mathcal M= \begin{pmatrix} \mathcal B&0\\0&(\mathcal B^{-1})^T \end{pmatrix}, \qquad \eta=\begin{pmatrix}I&0\\0&-I\end{pmatrix}. \]

把它代入 \(\mathcal M^\dagger\eta\mathcal M-\eta<0\)，左上 block 就是

\[ \mathcal B^\dagger\mathcal B-I<0. \]

因而所有 \(s_j<1\)，每个 fixed-field Fock operator 都是 trace class，并且普通 trace 等于 \(\det[I-\mathcal B]^{-1}\)。strict 还同时排除 unit-circle eigenvalues。若 \(\mathcal Mv=\lambda v\) 且 \(|\lambda|=1\)，则

\[ v^\dagger\!\left( \mathcal M^\dagger\eta\mathcal M-\eta\right)v =(|\lambda|^2-1)v^\dagger\eta v=0, \]

与左边对每个非零 \(v\) 都严格小于零矛盾。这给出清楚的路径图像： 轨迹不仅不能经过 \(\lambda=1\) pole，也不能从单位圆其他位置离开 收敛区域。更根本的 absolute-convergence 证明则是上面的 \(\mathcal B^\dagger\mathcal B<I\)，它对 nonnormal products 也成立。

有配对时：不能要求全部 Nambu eigenvalues 都在单位圆内

paired Nambu propagation 的 eigenvalues 以 \(\lambda,\lambda^{-1}\) 成对出现，所以完整 \(\mathcal M\) 不可能 具有 \(\rho(\mathcal M)<1\)。这里需要一个描述无限维 Fock operator 收敛性的标准术语。称 \(\hat U\) 为 trace class， 是指

\[ \operatorname{Tr}\sqrt{\hat U^\dagger\hat U}<\infty . \]

对正的热演化算符 \(\hat U=e^{-\beta\hat H}\)，这就是 \(\sum_n e^{-\beta E_n}<\infty\)：所有能量本征态，包括任意高的 玻色占据数，取绝对值后求和仍然有限。它保证普通 Fock trace 绝对收敛，并且比“算符有界”或“determinant denominator 非零”更强。 正确的 paired 陈述使用同一个 \(\eta=\operatorname{diag}(I,-I)\)，这里的上下块按 \((a,a^+)^T\) 排列。满足 \(\mathcal M^\dagger\eta\mathcal M-\eta<0\) 的 complex symplectic matrices 构成 bosonic Olshanski semigroup 的内部；其 metaplectic representation，也就是 bosonic Fock-space representation，在内部给出 trace-class operators。因此，从稳定零场出发并沿这个内部连续传播， 每个 paired fixed-field operator 都有有限 bare trace，路径同时固定 metaplectic double cover 与 determinant square root 的 operator branch。

这一 operator-level 结论不是由有限维 determinant 公式反向猜测。 Hilgert 给出 Howe oscillator semigroup 与 Bargmann--Fock realization 的对应；Neeb 的 holomorphic-representation theorem 明确说明 Olshanski semigroup 内部的 representation operators 是 trace class。可参见 J. Hilgert, A note on Howe's oscillator semigroup 和 K.-H. Neeb, Holomorphic representation theory and Olshanski semigroups。 Yamashita 的现代综述还提醒，闭半群边界可以只对应 bounded 而非 Hilbert--Schmidt operators；因此这里必须保留“内部/严格”二字： arXiv:2209.04139。

对实际连续 HS 路径的结论。 只要零场是 trace-convergent 的稳定构型，整个连续辅助场域始终留在 与它同向的 strict bosonic oscillator semigroup 内，那么所有 fixed-field bare traces 都收敛。再加上 \(J_1\) 与正规序标量因子 共同使完整 operator weight 为实、operator lift 连续且一个参考权重为正， 就得到整个辅助场域 恒正。此时既无需逐构型重新检查收敛，也无需逐构型重新决定符号。

为什么先前的 \(A_0=-\eta\) 例子不反驳这个结论

对新增 bosonic \(iJ_2g\) 类，可以取 \(A_0=-\eta\) 作为纯代数 strict witness。它确实满足 \(\eta A_0+A_0^\dagger\eta=-2I\)，但在最直接的 number-conserving physical basis 中，particle block 有一正一负两个 eigenvalues，因而 bare trace 发散。这个例子没有一个收敛的零场锚点， 它所用的 \(\eta\) 方向也不是标准 Fock convention 中“虚时间传播压低 高占据态”的 oscillator-semigroup 方向。辅助场空间即使只取这个常数矩阵仍然是 连通的，所以“连通”单独并不能排除它；它缺少的是上面第二、第三项。

因此它的正确用途只是说明：五条 \(J_1,J_2\) 离散关系加一个任意 \(\eta\)-strict witness，还不能自动产生可采样的玻色模型。它不在 由稳定自由 Hamiltonian 锚定的实际 HS 连通分支上，因此不构成对该 稳定物理分支论证的反例。若未来某个 \(iJ_2g\) candidate 找到稳定零场， 还应显式证明它同时位于标准 Fock oscillator-semigroup 的正确取向； 做到这一点后，收敛性便由上面的论证沿整个场域保持。

6.7 HS 场的正负、场的取值范围与规范变换

需要先限定命题。若采用同一个固定 metric \(\eta\)，一个连续 Gaussian HS field 线性进入同一个时间片生成元

\[ A(\phi)=A_0+\phi A_1,\qquad -\infty<\phi<\infty, \]

并要求每个实 \(\phi\) 都满足 generator inequality，则

\[ \eta A(\phi)+A(\phi)^\dagger\eta = \left(\eta A_0+A_0^\dagger\eta\right) +\phi\left(\eta A_1+A_1^\dagger\eta\right)\le0. \]

对任意向量取 expectation value，右边是关于 \(\phi\) 的一次函数。 它若在整条实轴都不为正，一次项只能为零。因此在这个特定 setting 中

\[ \eta A_1+A_1^\dagger\eta=0. \]

也就是说，连续无界且线性出现的场方向位于 maximal-subgroup Lie algebra；固定项可以提供 strict contraction。这是一个充分清楚的 构造原则，但不是所有 HS transformations 的一般前提。

至少有四种需要另算的情况：

  1. 离散或有界场。 若 \(\phi=\pm1\)，完全可以有 \(H_0+H_1\le0\) 与 \(H_0-H_1\le0\)，但 \(H_1\ne0\)。 本节的费米例子取 \(H_0=-2I,\ H_1=\operatorname{diag}(1,-1)\)， 两个场值的最大 eigenvalue 都是 \(-1\)。
  2. 非线性参数化。 若 \(A(\phi)\) 还含 \(-\phi^2\) 型 contraction contribution， 正负场可以给出同一半负定项；必须检查实际 HS identity，不能套用 一次函数论证。
  3. 因子化时间片。 AFQMC 常使用 \(e^{A_0}e^{\phi A_1}\)，而不是 \(e^{A_0+\phi A_1}\)。若要求 field factor \(e^{\phi A_1}\) 本身对所有正负 \(\phi\) 都属于同一 semigroup， 它与逆元同时出现，因而落在 maximal subgroup；但只要求完整乘积 \(e^{A_0}e^{\phi A_1}\) contraction 时，应直接检查 product inequality，固定 strict margin 有时可以容纳一个 uniformly bounded field orbit。
  4. 不同的 HS contours。 compact、complex 或 truncated contours 改变 field support； 结论必须随 contour 重新证明。

规范变换也要分两类。若固定 \(G\) 同时保持 canonical form 与 metric，

\[ G^TgG=g,\qquad G^\dagger\eta G=\eta, \]

则 \(A\mapsto G^{-1}AG\) 只是在同一 semigroup 内换 basis。 它可以把 \(\phi\) 与 \(-\phi\) 显式联系起来，也可以吸收 reflection phase，但不会改变 Hermitian matrix 的正负惯性。若使用 field-dependent \(G(\phi)\) 并让 metric 也变成 \(\eta(\phi)\)，不同时间片一般不再共享同一个 contraction inequality； 只有当中间 gauges 在相邻时间片间准确消去，或能重新证明一个固定 common metric 时，乘法封闭性才保留。因此规范变换可能有帮助，但不能只凭 “两种场值 gauge equivalent” 就跳过完整 product check。

6.8 从生成元结构到具体物理 Hamiltonian

玻色 \(J_2g\) 四类：可构造稳定的 Hermitian 相互作用模型

合作者 note 的 Cases 5--8 都可选 \(J_2=\sigma_x^{\rm Nambu}\otimes I\)，从而 \(\eta=\sigma_z^{\rm Nambu}\otimes I\)。Case 5 的一个直观粒子数守恒实现 使用两个玻色模，并定义

\[ \hat O=i(\hat a_1^+\hat a_2-\hat a_2^+\hat a_1),\qquad \hat H=\kappa(\hat n_1+\hat n_2)+\frac U2\hat O^2, \qquad \kappa>0,\ U>0. \]

repulsive-square HS identity 给出

\[ e^{-\Delta\tau U\hat O^2/2} =\int\frac{d\phi}{\sqrt{2\pi}}e^{-\phi^2/2} e^{i\sqrt{\Delta\tau U}\phi\hat O}. \]

在 \((a_1,a_2,a_1^+,a_2^+)^T\) 中，两个生成元分别是

\[ A_0=-\kappa\Delta\tau\,\sigma_z^{\rm Nambu}\otimes I,\qquad A_{\rm HS}(\phi)= -\sqrt{\Delta\tau U}\phi\,I_{\rm Nambu}\otimes(i\sigma_y). \]

对称 Trotter 时间片是 \(e^{A_0/2}e^{A_{\rm HS}(\phi)}e^{A_0/2}\)，不是默认把两个 不对易生成元相加后指数化。取 \(J_1=\sigma_z^{\rm Nambu}\otimes I\) 后，这是 Case 5： field generator 位于 maximal subgroup，而固定生成元严格收缩：

\[ \eta A_0+A_0^\dagger\eta=-2\kappa\Delta\tau I<0,\qquad \eta A_{\rm HS}+A_{\rm HS}^\dagger\eta=0 . \]

与 \(\phi\) 无关。原 Hamiltonian Hermitian 且由 \(\kappa N\) 与正算符 \(\frac U2O^2\) 从下方稳定。

Cases 6、7、8 可由同一个双组分模型同时实现：

\[ \hat H=\kappa(\hat n_b+\hat n_c) +\frac U2(\hat n_b-\hat n_c)^2,\qquad \kappa>0,\ U>0. \]

连续 HS 后的两个 Nambu generators 为

\[ \begin{aligned} A_0&=-\kappa\Delta\tau\, \sigma_z^{\rm Nambu}\otimes I_{\rm flavor},\\ A_{\rm HS}(\phi)&=i\sqrt{\Delta\tau U}\phi\, \sigma_z^{\rm Nambu}\otimes\sigma_z^{\rm flavor}. \end{aligned} \]

它分别与 Case 6 的 \(J_1=\operatorname{diag}(i\sigma_y,-i\sigma_y)\)、 Case 7 的 \(J_1=I_{\rm Nambu}\otimes\sigma_x\)，以及 Case 8 的 \(J_1=I_{\rm Nambu}\otimes i\sigma_y\) 相容； 三种选择的 \(J_2\) 和 \(\eta\) 相同；\(A_0\) 的 contraction matrix 是 \(-2\kappa\Delta\tau I\)，而 \(A_{\rm HS}\) 的是零。 这说明五条关系给出的 algebraic classes 不是互斥的 physical phases；同一个 HS slice family 可以同时承认多组 \(J_1,J_2\)。

这两个例子还是 number conserving。单粒子 \(b\)-matrix 的 Hermitian part 始终严格为负，所以每个 factor 是普通 Euclidean contraction， 完整乘积的 spectral radius 小于 1。\(J_1\) 又使 eigenvalues complex-conjugate paired；real eigenvalues 也都小于 1。因此 \(\det(I-\mathcal B)>0\)，这里可以把 propagation result 完整升级为 finite positive bosonic determinant weight。文章的 \(U_2\) benchmark 是第二个构造加 hopping、sites 与可选 pairing 的推广。有 pairing 时， 同一个 \(\eta=\operatorname{diag}(I,-I)\) 是物理 oscillator-semigroup metric；稳定零场与 strict contraction 使整个 连通 field domain 的 fixed-field operators 都是 trace class， \(J_1\) 实性条件、正实的正规序标量因子和零场正权重 再固定全域正号。RP 同时给出一条独立的 reflected-square positivity proof，而不再是唯一决定正分支的论证。 对固定 number term，正常序还产生正标量 \(e^{+\kappa\Delta\tau m/2}\)；它须计入完整 operator weight， 但不会改变上述正号。

新增玻色 \(iJ_2g\) 四类：有物理二次算符，但 grand-canonical 稳定性尚未解决

对新增 branch 可选 \(J_2=(i\sigma_y)^{\rm Nambu}\otimes(i\sigma_y)^{\rm flavor}\)， 因而

\[ \eta=iI_{\rm Nambu}\otimes(i\sigma_y)^{\rm flavor},\qquad A_0=-\eta. \]

\(A_0\) 对应 Hermitian、number-conserving flavor-current quadratic operator，而不是必然 non-Hermitian。以 \(J_1=I_{\rm Nambu}\otimes\sigma_x\) 的一类为例，还可取 maximal-subgroup field \(A_1=i(i\sigma_y)^{\rm Nambu}\otimes\sigma_z^{\rm flavor}\)。 辅助场生成元取 \(A_{\rm HS}(\phi)=\phi A_1\)，它对应 \(i\phi\hat O\)，其中

\[ \hat O=\frac12\left[ \hat{\bb a}^T\sigma_z\hat{\bb a} +\hat{\bb a}^{+T}\sigma_z\hat{\bb a}^+\right] \]

是 Hermitian pairing quadrature；所以 \(H_{\rm int}=U\hat O^2/2\) 的 Gaussian HS field 的确能产生满足 该 class 的有序时间片。Octave 分别得到 \[ \eta A_0+A_0^\dagger\eta=-2I,\qquad \eta A_{\rm HS}+A_{\rm HS}^\dagger\eta=0 . \]

但是这个构造还不是可采样的 grand-canonical boson model。 在 \(\eta\) 的 flavor 部分 \(i(i\sigma_y)\) 的 \(+1,-1\) eigenbasis 中，任意 number-conserving Hermitian generator 的 particle block 记为 \(B\)。 contraction inequality 的 diagonal expectations 分别要求

\[ B\big|_{\eta=+1}\le0,\qquad B\big|_{\eta=-1}\ge0. \]

所以 \(B\) 不可能 negative definite；显式 \(A_0\) 的单粒子 spectrum 正好是一正一负。普通 grand-canonical bosonic Gaussian trace 因负能 occupation 无上限而发散。保持同一 \(\eta\) 的固定 gauge transformation 不能改变这两个 subspaces 的惯性，因此不能把这一正一负变成全负。

当前结论的范围。 这排除了上述 fixed-metric、number-conserving、Hermitian grand-canonical realization；没有排除含 pairing 的稳定 cone、 canonical fixed-number formulation、有效 local Hilbert-space cutoff、 非 Hermitian/regularized trace，或能够重新建立 common metric 的 telescoping gauge construction。四个 \(iJ_2g\) 类目前是严格的 algebraic propagation discoveries，并有 Hermitian HS slice candidates， 但尚未得到一类完整可采样的新玻色平衡模型。这里的 mixed-sign \(A_0=-\eta\) 不在由稳定自由 Hamiltonian 锚定的物理 HS 连通分支上； 它只检验抽象 cone 非空，不能用来反驳第 6.4 节对实际连续场路径的 trace-convergence 结论。

\(J_1^2=-I\) 或 \(J_1\) 翻转 \(g\) 的另外三类可通过 flavor doubling 选择表 6.6 中的 representatives；它们共享同一个 mixed-sign \(A_0\) obstruction。因此目前不能把四行计成四种新 physical sign-free Hamiltonians。

费米 \(J_2g\) branch：离散场可以直接在 cone 内

费米 Fock space 有限，没有上面的玻色收敛障碍。取 \(\eta=\sigma_z^{\rm Nambu}\otimes I\) 和 bounded Ising field \(s=\pm1\)：

\[ A_s=-\kappa\,\sigma_z^{\rm Nambu}\otimes I +s\lambda\,\sigma_z^{\rm Nambu}\otimes\sigma_z,\qquad \kappa>|\lambda|. \]

则

\[ \eta A_s+A_s^\dagger\eta =-2\kappa I+2s\lambda(I\otimes\sigma_z)<0 \]

对两个场值都成立，但 field direction 本身不在 maximal subgroup。 这可由标准离散 Hubbard--Stratonovich identity 产生：

\[ e^{-\Delta\tau U(n_\uparrow-\frac12)(n_\downarrow-\frac12)} = \frac{e^{-\Delta\tau U/4}}2 \sum_{s=\pm1}e^{\lambda s(n_\uparrow-n_\downarrow)},\qquad \cosh\lambda=e^{\Delta\tau U/2}. \]

再由 chemical-potential/free contribution 提供 \(\kappa>|\lambda|\)，就得到一族 Hermitian Hubbard-type effective slices。这个例子直接说明：对 bounded discrete HS， “field 必须位于 maximal subgroup”并不成立。

费米 \(iJ_2g\) branch：pairing cone 有已知物理 realization

8. 费米标准收缩与 note 号约定的区别

8.1 note 的费米不等式不是标准 \(e^A\) contraction

note 的权重公式依赖 \(M=\prod_\ell e^{A_\ell}\)，但第一节写的是

\[ iJ_2gA-iA^\dagger J_2g\le0 . \]

在这一分支中 \(J_2^2=-I\)、\(J_2^TgJ_2=-g\)，所以 \(J_2g\) 是 Hermitian involution，而 \(iJ_2g\) 反而是 anti-Hermitian，不能作为 Hermitian contraction metric。 若直接控制 \(e^A\)，令 \(\eta_A=J_2g\)，求导真正出现的是

\[ \eta_A A+A^\dagger\eta_A =J_2gA+A^\dagger J_2g . \]

这与 note 的式子不是同一个 inequality。note 式子的准确来源可这样看： 暂记 \(X=gA\)，则 \(X^T=-X\)；再令 \(\eta_X=iJ_2\)，有 \(\eta_X^\dagger=\eta_X\)、\(\eta_X^2=I\)，并且

\[ iJ_2gA-iA^\dagger J_2g =\eta_X X+X^\dagger\eta_X . \]

所以原式确实是 skew-symmetric Majorana coefficient \(X\) 上的标准 contraction condition，直接控制的是 \(e^X=e^{gA}\)。 但 note 顶部的 Nambu canonical propagation 使用 \(e^A\)。 从 real Majorana basis 变到 complex Nambu basis 时， quadratic coefficient、canonical generator、complex conjugation rule 与 metric 必须一起变换；\(X=gA\) 并不一般与 \(A\) 相似。 只搬运 Majorana inequality 而不写这一步，不能保证 Nambu weight 非负。

8.2 单模精确反例

取 note 使用的费米 Nambu convention，并令

\[ g=\sigma_x,\qquad J_1=\sigma_x,\qquad J_2=i\sigma_y,\qquad A=iy\sigma_z . \]

逐项计算：

\[ J_1^TAJ_1=\bar A,\qquad iJ_2gA-iA^\dagger J_2g=-2yI<0\quad(y>0). \]

然而 many-body quadratic operator 与完整 Fock trace 是

\[ h=iy\left(n-\frac12\right),\qquad W(y)=\Tr e^h =e^{-iy/2}+e^{iy/2} =2\cos\frac y2 . \]

当 \(y=\pi\) 时 \(W=0\)，当 \(y=2\pi\) 时 \(W=-2\)。 所以 note 的 inequality 即使 strict，也没有阻止 Fock weight 过零并变负。

8.3 无配对的多时间片反例

对与 note \(9'\) 相同的离散矩阵关系，可以完全去掉 pairing blocks， 取三个 number-conserving slices：

\[ B_1=-2\sigma_x-2\sigma_z,\qquad B_2=-2\sigma_x,\qquad B_3=2\sigma_x+\sigma_z . \]

程序逐 slice 验证相应等式 residuals 为零，但完整 determinant 为

\[ W=\det(I+e^{B_1}e^{B_2}e^{B_3}) =-24.1885664042699 . \]

把三个 \(B_\ell\) 同时乘连续参数 \(t\)，从 \(t=0\) 的正权重出发， 在 \(t=0.80967485393694\) 穿过零。因此这个负号不是 square-root 选择造成的孤立数值异常，而是与正参考点连续相连的实际 zero crossing。

\[ J_2^TgJ_2=g,\qquad J_2^2=-I . \]
