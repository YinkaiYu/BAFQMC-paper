## 最终分类

| TRS 数目 | 无符号类 | 可能有符号问题 |
|---|---|---|
| 0 | 无 | 不施加 TRS |
| 1 | 无 | `{+}`、`{-}` |
| 2 | `{-,-}` | `{+,+}`、`{+,-}` |
| 3 | `{+,+,+}`、`{+,-,-}`、`{-,-,-}` | `{+,+,-}` |
| ≥4 | 全部 | 无 |

基本类为 `{-,-}` 与 `{+,+,+}`。四个及以上 TRS 的覆盖由直接计数给出：至少有两个负平方，或至少有三个正平方。

Kramers 类的约化权重保留 `(-1)^{N_-}` 与正常排序指数；负交换子方向成 Kramers 对，故 `N_-` 为偶数。对于 `{+,+,+}`，`N_-=N/2`，约化矩阵位于分裂正交群的单位连通分支；行列式符号正好补偿该因子。引用的行列式定理已与 [Wang 等的原始论文，Eq. (3)](https://arxiv.org/html/1506.05349v3) 核对。两类的显式约化表达式将收敛迹固定的分支延续到非奇异点，不能用任意选择的正平方根替代这一过程。

## 反例

单模 `h=κ(n+1/2)` 保持 `{+,+}`，其权重

\[
W=-[2\sinh(\kappa/2)]^{-1}
\]

在 `κ>0` 为负，覆盖 `{+,+}` 与 `{+}`。

两模族

\[
\hat h=-\alpha(n_b+n_c+1)
-\frac{x}{2}(b^2+b^{+2}+c^2+c^{+2})
\]

在所有实 `α,x` 保持三个实 flavor 变换 `σ_z`、`σ_x`、`iσ_y`，即 `{+,+,-}`。在 `α>|x|`，Bogoliubov 变换给出

\[
W(\alpha,x)=\frac{1}{2[\cosh\sqrt{\alpha^2-x^2}-1]}.
\]

这是 `α²-x²` 的单值亚纯函数，延拓到 `α=0` 得到 `W=-1/[4 sin²(x/2)]`。`x=π` 时 `W=-1/4` 而 `det(I-M)=16`，同时覆盖 `{+,+,-}`、`{+,-}` 与 `{-}`。

伴随的 `verify.py` 检查两组反例的物理 TRS 条件、反对易关系、稳定点的 Bogoliubov 约化和权重平方。它还沿无极点半圆 `z=π² exp(iθ)` 连续跟踪平方根：终点行列式为 `16`，连续平方根为 `-4`，权重为 `-1/4`。这只是对公式和分支的独立核验，没有增加 QMC benchmark。

## 相关内容的处理

- 主文定理采用 “the Gaussian weight W is positive wherever it is finite”，保持先定理、后机制与分块例子的顺序。
- SM 中不再将 `{+,-}` 的收敛迹因式分解列作该周期表的保护证明。反例自然置于周期表完成一节，没有在正文叙述类别变更。
- 原共轭 Bogoliubov 模型的 Hamiltonian、稳定性条件、HS 构造与可研究的物理全部保留，改由 RP 解释：每个因子均为 `exp[q+θ(q)]`，稳定条件保证真实迹收敛。
- 奇宇称配对的排除证明只需排除 `{-,-}`，保留其在统一内部 TR 下独属于 `{+,+,+}` 的结论与模型构造。
- RP 定理仍适用于有限的原始算符迹。本轮没有把其结论推广为任意延拓 Gaussian 权重的正性。
- Gaussian-cutoff Sec. IV 完整保留。此前单独记录的有限部分解释与 `U₁<0` benchmark 计算对象继续留待讨论；本轮没有改变 benchmark、图、参考文献元数据或作者研究 note。
