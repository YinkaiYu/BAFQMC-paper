文献调查报告 · 2026-09-03

新无符号类 {+,+,+}：具体模型与既有研究逐项核查

目标不是证明“相关领域很活跃”，而是逐篇回答：文献究竟算了哪个哈密顿量、哪些参数、用了什么方法、得到什么结论，以及它与本工作的严格无符号锥到底是什么关系。
结论判据推荐排序总表逐项调查写作边界来源

一、先给结论

目前没有找到一个已经被广泛研究、原封不动便属于严格 {+,+,+} 锥、同时又因传统 QMC 符号问题而长期未解的“现成名模”。

最接近直接命中的，是两种相互作用通道：准平带模型中的成对跃迁，以及腔介导模型中的吸引性实双线性平方；但这些论文的完整哈密顿量还包含单组分结构、排斥 onsite/密度项或其他不在严格锥内的项。其余候选多数是机制相近的文献母体，需要按 {+,+,+} 允许的双线性重新完成，不能把原文模型直接称为本类模型。

主文最值得写的例子：三角晶格、双谷 ±K、两组分奇宇称成对的严格 {+,+,+} 模型。它把“受挫双谷 + Ising 手性 + anomalous propagation”三件事合在一起，和冷原子双谷手性超流的理论及 2025 年实验有明确物理连接；但必须表述为受既有双谷研究启发的严格可计算新模型，而不是声称那些实验哈密顿量本身已经满足本判据。

补充材料最有说服力的两个例子：（i）准平带成对跃迁，展示允许符号分解与现有相竞争问题的直接联系；（ii）腔介导 bond-square，相互作用形式最干净，适合成为 BAFQMC 的近期数值应用。

二、严格判据与本报告的四级分类

以下比较以当前推导中的标准形式为准。对三种反幺正对称同时为正的情形，允许的二次双线性通道可组织为

H = H₀ − ½ EᵀG_EE + ½ OᵀG_OO, G_E ≥ 0, G_O ≥ 0,

其中 E 是三种对称下的偶双线性（例如实 hopping T、实 pairing X），O 是奇双线性（例如 current J、pair current Π）。因此，不能仅凭“有 pairing”“哈密顿量可取实”或“有时间反演”就判断属于 {+,+,+}；平方项前的符号、组分结构、硬核约束和复通量都必须逐项检查。

A 级通道直接命中
文献中的某个相互作用可精确写成允许的偶/奇平方符号；完整模型未必严格命中。
B 级近失配
物理现象高度相关，但 onsite 排斥、硬核投影、复通量或平方符号使原模型离开严格锥。
C 级严格新模型的文献母体
已有工作支持其色散、序参量或拓扑动机；严格哈密顿量是本工作的新完成。
D 级已有其他无符号算法
现象有趣，但不能用作“BAFQMC 打开此前不可算领域”的旗舰。

五、逐项文献调查

1. 准平带 t–J–P–U–V 模型：最强“代数命中”

A：允许通道直接出现全模型不严格
H_t = −t Σ_j (b†_{j+1}b_j + h.c.) H_J = −J Σ_j (b†_{j+1} n_j b_{j−1} + h.c.) H_PUV = Σ_j { −P[(b†_j)²b²_{j+1}+h.c.] + U n_j(n_j−1)+V n_jn_{j+1} }.

论文实际做了什么。Burgher 等（2026 预印本）研究 1D 周期链，使用 QuSpin 精确对角化和含位移/压缩的 Gaussian variational ansatz。平带切片取 t=J=0、单位填充、L=14，扫描 U/P,V/P；更一般的竞争图取 V=2P,J=0，单位填充 L=N=14 与半填充 L=16,N=8，扫描 t/P,U/P。动力学结构因子的示例为 J=.08P,t=0,U=.1P,V=2.1P,n=1。

有趣结论。U=0,V=2P 存在精确 pair-condensate 状态；但单粒子激发的抛物型低能结构意味着它并非普通 Landau 超流。论文给出用 Ũ=2U−4P、Ṽ=V−2J 表示的两体束缚阈值，并展示 single-particle/pair superfluid 竞争。

严格关系。令 z=b†_i b_j，则 −P(z²+z†²)=−(P/2)T²+(P/2)J²：偶 hopping 平方为负、奇 current 平方为正，正好是本锥允许的符号。问题在于原文是单组分，而且 U,V>0 的密度平方不能一并宣称属于严格类。

2. 腔介导 bond-order Bose–Hubbard：最干净的数值应用候选

A：吸引性 square 命中onsite U 不严格
H_BH = −tΣ_j(a†_j a_{j+1}+h.c.) + (U/2)Σ_j n_j(n_j−1), H_BCH = (U₁/L)[z²D² + zy(DB+BD)+y²B²] = (U₁/L)(zD+yB)², D=Σ_j(−1)^j n_j, B=Σ_j(−1)^j(a†_{j+1}a_j+h.c.).

论文实际做了什么。Chanda 等用固定粒子数、开边界 DMRG 研究 1D 链。光晶格深度取 V₀=4E_R，三种腔几何分别近似为：密度耦合 (z,y)=(.8279,0)；bond 耦合 (0,−.0658)；混合耦合 (.5854,−.0465)。研究单位填充与半填充，典型相图用 L=60，t/U=.01…1 的 101 个对数点，并扫描 U₁/U。

有趣结论。在纯 B² 情形，单位填充出现 bond superfluid；半填充下 bond insulator 将普通 SF 和 BSF 分开。SF–BSF 可为不连续转变，而 SF–BI、BI–BSF 连续。混合 D+B 耦合还能产生 CDW+BI、supersolid 与 bond supersolid；BSF/BSS 的中心荷约为 1。

严格关系。当 U₁<0 时，实偶双线性 zD+yB 的负平方正是允许通道；但原文维持稳定性的排斥 onsite U>0 不是严格锥的一部分。适合作为“允许 square 已经对应现实 cavity mechanism”的证据，而不是宣称整篇 DMRG 相图都属于本方法。

3. 两组分 p-wave 可积配对：解析 benchmark，而非原样命中

B：平方符号近失配
H = Σ_k η_k²(n_{ak}+n_{bk}) − (G/4)Σ_{kk′}η_kη_{k′}(b†_k a†_{−k}−a†_k b†_{−k})(b_{k′}a_{−k′}−a_{k′}b_{−k′}).

论文实际做了什么。Lerma-Hernández、Dukelsky 与 Ortiz 用 Richardson–Gaudin Bethe ansatz 给出精确解，并与热力学极限的 mean-field/quasiboson 分析比较。1D 例子取 η_k=sin(k/2)、反周期动量；常用密度 ρ=N/(2L)=.2，有限尺寸示例为 M=10 对、L=50，展示 g=GL=.5,1.2,1.8,5,6.8。

有趣结论。临界耦合 g_c=2/(2+ρ) 处为三阶量子相变：从无能隙、fragmented singlet-pair BEC 进入有能隙 pair superfluid；另有 g_∞=2/ρ 的强耦合尺度。临界态具有 Moore–Read-like 形式 (Ση_k⁻¹K†_k)^M|0⟩。

严格关系。它证明奇宇称两组分配对本身有丰富、可解析的多体物理；但原文的吸引配对写成了严格锥中 odd quadrature 的错误符号，不能列为直接实例。最佳用途是检验本文模型的弱耦合/临界直觉或构造一个允许符号的 cousin。

4. 三角晶格 correlated hopping：pair supersolid 的机制母体

B：硬核/三体结构失配
H = tΣ_⟨ij⟩(b†_i b_j+h.c.) + VΣ_⟨ij⟩n_in_j − KΣ_△(n_i b†_j b_k+h.c.), n_i=0,1.

论文实际做了什么。Jiang、Fu 与 Xu 取 t=1,V,K>0、密度 1/6，在三角晶格圆柱上做 DMRG，周长 L_y=3…9、最大尺寸约 18×9，保留超过 6000 个态，并比较圆柱/周期边界。重点切片包括 V=6 扫 K，以及 V=0 增大 K。

有趣结论。得到 SF、supersolid、pair superfluid 和 phase separation。V=6 的 SS→PSF 连续，而 V=0 增大 K 的 SF→SS 为一级。它说明三角受挫 + correlated motion 的确自然生成 pair order 与密度序竞争。

严格关系。硬核投影和 n_i b†_j b_k 三体张量不能自动化为本文允许的 bilinear squares；只能作为严格三角 pair/current-square 模型的现象动机。

5. pair tunneling 诱导 twisted superfluid：现象很近，符号恰好不对

B：quadrature 符号相反
H = (U/2)Σ_i n_i(n_i−1) − JΣ_⟨ij⟩(a†_i a_j+h.c.) − μΣ_i n_i + VΣ_⟨ij⟩n_in_j + (P/2)Σ_⟨ij⟩[(a†_i)²a_j²+h.c.].

2D 研究。Jürgensen 等用最多四格点 cluster mean-field 嵌入热力学环境，绘制三维参数相图；代表切片 P=V=.15U,J=.12U。正 P 使键能包含 −2Jφ_iφ_j cosθ+Pφ_i²φ_j²cos2θ，在适当密度下选择 θ=±π/2，得到 spontaneous-TR-breaking TSF/TSS。

1D 研究。Lühmann 在平均每站 N=4 做 DMRG，onsite Fock cutoff 16、保留约 450 态；典型扫描 J=.6U,P=.16… .24U，相关函数例子 P=.28U。发现 TSF、pair-wave Mott、PSF/PSS 等，TSF 中有限尺寸 gap 指数闭合；临界 P/U 随填充升高显著降低（N=8 约 .07）。

严格关系。正号 pair tunneling 正是产生 twist 的机制，但分解后 current-square 的符号与 {+,+,+} 所需相反；再加上 U,V>0，原模型不是严格实例。它适合说明“改一个相互作用 quadrature 就跨过严格边界”，不适合当正例。

Sci. Rep. 5, 12912 (2015) · PDF · Phys. Rev. A 94, 011603(R) (2016) · PDF

6. 2D Kitaev–Bose–Hubbard “Bubble Phase”：新奇，但证据与严格性都偏弱

B：复通量与 onsite U 失配
H = −Σ_{r,ν=x,y}[J e^{iθ_{rν}}b†_r b_{r+ν}+Δ e^{iφ_{rν}}b†_r b†_{r+ν}+h.c.] +(U/2)Σ_r n_r(n_r−1)−μΣ_r n_r.

论文实际做了什么。Zhu 与 Yang（2026 预印本）采用对称规范 θ_x=−παy, θ_y=παx 且 φ=θ，主参数 α=1/16, Δ/U=.005。方法是 inhomogeneous Gutzwiller product state，加 quantum-Gutzwiller/slave-particle BdG 修正，并人为剔除平均场冗余产生的零模；没有做无偏 QMC。μ/U=.5 下报告 MI（J/U≲.04）、Bubble（约 .04… .046）及更大 J 的不稳定 SF。文中局域结构示例还用到 J/U=.025 的切片。

有趣结论。Bubble 窗口可压缩，但超流密度只形成彼此分离的岛，cluster collective mode 有有限 gap；作者称其为 intrinsic Bose glass。

判断。“Bose glass”通常需要更强的多体、尺寸和无序/准周期诊断；这里是周期、确定性体系的 Gutzwiller/BdG 结果，表述应保留。更重要的是，复磁通和 U>0 都不在严格锥，不能作为主例。

7. binary mixture 的 onsite pair conversion：四阶超流与四重临界点

B：序参量相近，结构不同
H = −JΣ_⟨ij⟩(a†_i a_j+b†_i b_j+h.c.)−μΣ_i(n_{ia}+n_{ib}) +Σ_i[U_{aa}n_{ia}(n_{ia}−1)/2+U_{bb}n_{ib}(n_{ib}−1)/2+U_{ab}n_{ia}n_{ib}] +WΣ_i[(a†_i b_i)²+h.c.].

论文实际做了什么。Liu 与 Lin（2025 预印本）主用 square-lattice cluster Gutzwiller mean field。对称例取 Uaa=Ubb=1,Uab=.5,W=−.1，非对称例取 Ubb=.8Uaa；代表性切片 J/U=.005,.008。作者还在 1D L=32、J/Uaa=.01、同一相互作用比值下做 DMRG，检查关联函数与 noise correlations。

有趣结论。得到仅 ⟨(ab†)²⟩≠0 的 paired super-counter-fluid（PSCF），以及二阶与四阶序共存的 SSCF；组分非对称时出现四重临界点。论文也在多组 (J/U,μ/U) 点检查 demixing。

严格关系。它展示 pair-conversion order 可作为实际可识别的四阶序，但 conversion 是 onsite flavor exchange，不是拟议三角模型的空间奇宇称 pair；原 onsite 排斥也使完整模型不严格。

8. chiral Mott：受挫 Ising×U(1) 熔化的经典参照

B：受挫 hopping 可实，但 repulsive density square 不允许

完全受挫两腿梯

H = −tΣ_x(a†_x a_{x+1}+h.c.) + tΣ_x(b†_x b_{x+1}+h.c.) −t_⊥Σ_x(a†_x b_x+h.c.) +(U/2)Σ_x[n_{a,x}(n_{a,x}−1)+n_{b,x}(n_{b,x}−1)].

Dhar 等取整数填充与 t⊥=t，结合 finite-system DMRG（至 100 rungs、每站 6 个 Fock 态、约 200 kept states）、classical rotor Monte Carlo 和 Jastrow VMC。得到 chiral SF→chiral Mott 的 BKT 转变 U_c1/t≈3.98(2)，再经 Ising 转变到普通 MI，U_c2/t≈4.08(1)；两者之间是窄但可辨认的 CMI。

三角晶格与窄梯

H = tΣ_⟨ij⟩(b†_i b_j+h.c.)+VΣ_⟨ij⟩δn_iδn_j+(U/2)Σ_i(δn_i)², t,U,V>0.

Zaletel 等对 2D 做变分 mean field，并对四腿圆柱做 iDMRG：n₀=1、每站最多 2 bosons、χ≤1600，比较 V=0 与 1.6；估计 Ising 临界约 U_c≈5.99 与 7.06。两腿版本用 iDMRG + bosonization，得到 MI–χMI 的 c=1/2 Ising 与 χMI–χSF 的 BKT，且在较大 hopping 处可能有一级段/三临界结构。

价值与限制。这些工作最清楚地告诉我们受挫双谷体系为什么自然有 U(1) 与 Z₂ 两种序，但它们没有 anomalous propagation，且稳定相互作用恰是正 onsite/NN density squares。引用它们支撑“物理问题”，不能支撑“严格类已有研究”。

9. 三角晶格双谷严格模型：推荐的主文旗舰

C：严格新完成 + 强文献母体

建议写入文章的哈密顿量。在每个格点放两种玻色子 b,c，定义

T_{ij}=b†_i b_j+b†_j b_i+c†_i c_j+c†_j c_i, P†_{ij}=b†_i c†_j−b†_j c†_i, X_{ij}=P†_{ij}+P_{ij}, J_{ij}=−i(b†_i b_j−b†_j b_i+c†_i c_j−c†_j c_i), Π_{ij}=−i(P†_{ij}−P_{ij}), H = κΣ_i(n_{bi}+n_{ci}) + tΣ_⟨ij⟩T_{ij}+Δ_pΣ_{i→j}X_{ij} +U_JΣ_⟨ij⟩J²_{ij}+U_ΠΣ_{i→j}Π²_{ij}, U_J,U_Π>0.

三角晶格取受挫 t>0 时，单粒子低能谷位于 ±K；有向键上的 flavor-singlet 奇宇称 pair 同时引入 anomalous sector。各平方项的符号按偶/奇分类直接处于严格锥内。它允许研究单谷/双谷凝聚、relative-phase locking、Ising chirality、pair/current order 及其量子/有限温转变。

已有文献究竟支持什么

  • Li 等，Nat. Commun. 5, 5174 (2014)：研究具有 ±K 退简并的两组分 bosons 与密度相互作用，采用 Bogoliubov order-by-disorder、Gutzwiller、微扰和 time-dependent GP。六角 spin-dependent 例中常取总密度 1、U/t_eff=1；弱耦合边界约 V_c≈U/3，强耦合趋于 V_c=2t_eff。结论是量子涨落可在“同谷 chiral charge SF”和“异谷 chiral spin SF”之间选择，后者在广泛参数稳定。
  • Li 等，Nat. Commun. 5, 3205 (2014)：对 checkerboard p-orbital phase-only model 做经典 MC，典型 U/J∥=1,J⊥/J∥=1；报告 Ising T/J≈2.088(3) 与 BKT ≈2.072(3)，中间是很窄的 chiral Bose liquid。该顺序对应 U(1) 先熔、chirality 后熔。
  • Yu 等，arXiv:2507.07494：一维 shaken optical lattice 实验，典型驱动 ω=2π×12.55 kHz、V₀=11.3E_r、振幅 .005λ，每温度约 40 个 TOF shots。得到 chirality melting T_m=165(40)nK，而 superfluid T_c=315(11)nK：实验是 chirality 先熔，形成 paramagnetic superfluid；与上面常见理论次序相反。在较小谷间距处两转变可接近重合。

正确写法。这些论文支持 ±K 双谷、Z₂ 手性和两阶段熔化的重要性，但没有计算上面的 J²+Π² 严格模型。文章应写“motivated by / realizes a sign-free interacting completion of”，不应写“the experimental model belongs to {+,+,+}”。

10. kagome / π-flux flat band：高吸引力，也有重要反例

C：平带母体

Kagome frustrated BH。You 等研究 H=tΣ⟨ij⟩(b†_i b_j+h.c.)+UΣn_i(n_i−1)−μΣn_i，t>0 使每个三角形有 π flux，最低带平坦。方法为高密度 Hartree、Bogoliubov zero-point order-by-disorder 与三色流形的经典热涨落。代表 Uρ/t=.3,3，相图常在 Uρ/t=1 分析。极低温出现 K-point SF，但有效锁相尺度 J_eff 仅约 10⁻³t；更高温可有 b³ 准长程序的 trion SF，直至 T∼t。

Coupled π-flux plaquettes。Di Liberto 与 Goldman 将单 plaquette 投影为 H_eff=(3U/16)n²−(U/16)L_z²−(√2J+U/8)n，再用耦合 plaquettes 实现 bosonic BBH。Bogoliubov 例取 J'=.1J,g=.1J，并在 L_y=2,L_x≤48、每 plaquette 两粒子处做 DMRG，得到 SF 到具有 loop-current ferromagnetism 的 chiral Mott。

关键反例。Burgher 等（PRB 111, 064514）研究 all-flat π-flux plaquette chain，利用局域对称、Elitzur 型论证与 ED 说明局域守恒量可禁止长程 chiral order，并发现 impurity self-pinning。因而“平带 + 相互作用 ⇒ 手性序”绝不能当作普遍结论。

严格关系。原模型的 U>0 不严格；最稳妥的方向是在相同色散上换成允许的 pair/current squares，并把局域对称导致的无序风险作为待解决问题。

11. Aharonov–Bohm cages：pair delocalization 与 interaction-induced topology

C：强平带/配对母体

Rhombic chain 多体 DMRG。Cartwright、De Chiara 与 Rizzi 研究带一条 e^{iφ} 键的 rhombic chain BH：NN hopping −J 加 (U/2)Σn(n−1)。开边界 MPS/DMRG，L=3M−2，平均填充 1 与 2。φ=π 时三条带全平，onsite U 投影后产生 pair hopping。单位填充 Mott 临界从 φ=0 的 J/U≈.14±.01 推至 φ=π 的 .78±.03；pair Luttinger liquid 只在偏离 π 约 0.5% 的极窄窗口存活，c=1，entanglement spectrum 可区分普通/paired LL。

Preformed pairs。Tovmasyan 等对 Creutz/diamond/dice 全平带模型做 ED 与 DMRG。对保持局域对称的相互作用，1D 整个多体谱具有半磁通量子周期；单粒子传播有限程而 charge-2 pairs 可移动。二维 dice 也给出数值迹象。

两体拓扑。Pelegrí 等研究带轨道角动量的 diamond chain，允许 U_A,U_1,U_2。在 |U|≪ band gap 做精确投影为 pair SSH/Creutz 模型，再用 ED 检查强耦合与离开平带情形；得到 interaction-induced topological bound-pair edge states 和 doubly localized cages。

实验。2025 年 Rydberg synthetic rhombic lattice（最多约 12 个合成态）直接观察：中等相互作用会破坏单粒子 caging 并促使 pair delocalization，强相互作用则形成慢的 bound pairs。它是少体非平衡实验，不是平衡多体相图。

严格关系。这是构造严格 pair/current-square AB-cage 模型的最强物理背景；但必须重新证明 π-flux gauge、flavor doubling 与每个相互作用平方同时满足三种 TRS。

12. 高阶拓扑 triplon / parametric BBH：适合展望，不宜宣称多体问题已建立

C：quadratic BdG 母体

Triplon。Haldar、Massarelli 与 Paramekanti 从 bilayer square spin dimers 出发：强 J_D S_{rT}·S_{rB}，层内采用 tetramerized BBH-like XXZ，或带 DM 与 Γ 的 SOC-like 交换。用 bond operators 截断到 quadratic triplon BdG，并在实空间开边界求谱。tBBH 代表 J₁/J_D=.02,J₂/J_D=.2；tSOC 代表 J₁=.1,J₂=.2,D=.2,Γ=.22,J=.01（均以 J_D 为单位）。得到四个近 midgap corner triplons 及相应 bulk invariants/edge theories。

Parametric photonics。Roy 等考虑 χ² 阵列 H_NL=Σ_n(g/2)(a_na_n+h.c.) 与 SSH hopping J[1+ε(−1)^n]。在 g<2Jε 时只有拓扑边/角模先达到 parametric instability：阈值下强 squeezing，阈值上 edge/corner-only oscillation。方法为驱动耗散 classical mean-field/Langevin，不是平衡量子多体。

几何工具。Tesfaye 与 Eckardt发展 symplectic quantum metric/Berry curvature，并以弱相互作用 bosonic Haldane 为例（如 J₂=.1J₁,θ=π/2,Δ=3√3J₂/2,Un/J₁=0,3）模拟调制激发率。这给出诊断工具，不是相互作用 HOT 相图。

严格关系。可把 BBH-like real hopping 与允许 pairing/current squares 拼成严格 bosonic BdG 模型；但现有文献的 corner mode 主要是 quadratic quasiparticle 结论。论文只能说 BAFQMC “may enable interacting many-body tests of” 这些预测。

13. Bosonic Kitaev chain / 2D cousin：anomalous propagation 的实验锚点

C：real-coupling cousin 可严格
H_B = (1/2)Σ_j[t e^{iφ_t}a†_{j+1}a_j+iΔ a†_{j+1}a†_j+h.c.].

实验。Busnaina 等在三模 superconducting parametric cavity 中用 difference-frequency pump 实现 hopping、sum-frequency pump 实现 pairing。开链典型 t/2π≈2.02 MHz、Δ/2π≈.55–.62 MHz；闭环设备约 Δ/t=.417。实验观察 pump-phase-controlled chiral transport、quadrature localization 和显著 boundary sensitivity。它是可控的二次、开放、非平衡网络，不含强相互作用。

相互作用理论。Wang、You 与 Sun 研究带相位的 Kitaev hopping/pairing，加 onsite U 和三体 U₃n(n−1)(n−2)。处理 free、hard-core（spin/Jordan–Wigner）、三体约束与 soft-core DMRG；常取 t=Δ=1、链长至 192。hard-core、三体约束和 soft-core 中均找到 Ising 标度 ν≈1，并扩展到两腿梯。

严格关系。这说明 anomalous chain 的实验与临界物理都真实存在。严格例应选择可同时 realify 的相位和允许的 square interactions；原实验是二次系统，原相互作用理论的复相位/正 onsite U 则不能直接纳入。

14. 四组分 helical Hofstadter–BdG：拓扑吸引力高，强关联证据低

C：pseudo-TRS 拓扑母体

Kondo、Akagi 与 Katsura 建立满足 pseudo-time-reversal Θ′=PK、Θ′²=−1 的 bosonic BdG Z₂ 分类。显式例是 bilayer kagome ferromagnet：层内 −J S_i·S_j +Dξ_{ij}(S_i×S_j)_z，层间反铁磁 J′S_{i1}·S_{i2}。linear spin-wave/BdG 在宽度 M=20、D=.1J,J′=.1J 的 strip 上得到 helical magnon edge modes，三个 band pairs 的 Z₂ 指数为 1,0,1。

它支持“多 flavor + antiunitary square −1 能保护 bosonic BdG topology”的概念。把 complex helical sectors 成对 realify 并加入允许的 J²,Π² 可形成严格四组分模型；但这是本工作的构造，不是该文已经做过的 interacting simulation。

15. Moat band / Bose surface：问题重要，但离严格实例最远

C：只共享低能色散
H = ∫d²r { Φ†[(|k|−k₀)²/(2M)]Φ +(g/2M)(Φ†Φ)² }.

CS trial state。Wei 与 Sedrakyan 用 Chern–Simons transmutation 构造 chiral-spin-liquid-like wavefunction，再用 Monte Carlo 积分评估该变分态；这不是对原玻色哈密顿量的无偏 QMC。低密度区约 n≲k₀²/(8π) 时得到 μ∼n²ln²n，并比较 CSL、fragmented BEC 与普通 BEC。

Bilayer excitons。Maisel Licerán、Boeve 与 Stoof（2026）研究具有 quadratic/quartic moat dispersion 和软排斥的连续体，求两体 T-matrix，并比较单动量 FF、±q LO stripe、高 Q、fragmented 和 composite-fermion 变分能。大 moat、弱裸相互作用下也可因 T-matrix 重整化偏好 LO。

严格关系。这些工作证明 moat 色散有真正未决的 many-body competition，但相互作用都是 repulsive density type，和严格 square completion 不同。除非我们能写出短程、稳定且清楚处于锥内的 lattice realization，否则不建议放主文。

16. 两个“物理很像但已有无符号 QMC”的对照组

D：已有专门无符号算法

三角晶格 pair hopping + 三体约束

H=−μΣn_i +(U/2)Σn_i(n_i−1)+VΣ_⟨ij⟩n_in_j −tΣ_⟨ij⟩(a†_i a_j+h.c.)−t_pΣ_⟨ij⟩[(a†_i)²a_j²+h.c.], n_i=0,1,2.

六、文章中可以说什么、不能说什么

不要写：“这些模型都属于新发现的 {+,+,+} 类。”绝大多数只提供色散、序参量或相互作用通道的母体。

不要写：“双谷手性超流总是先失去 U(1) 再失去 Z₂。”2014 phase-only MC 是这个次序，但 2025 shaken-lattice 实验得到相反次序：chirality 先熔，留下 paramagnetic SF。

不要写：“flat band interaction 必然产生 chiral order。”all-flat π-flux plaquette chain 的局域对称可禁止长程手性序。

不要写：“HOT corner mode 说明 interacting higher-order topological phase 已确立。”现有主要证据是 quadratic triplon BdG 或驱动耗散 parametric oscillator。

不要写：“Bubble Phase 已被无偏方法确认为 Bose glass。”目前依据是周期模型的 Gutzwiller/BdG 预印本。

推荐的准确中心表述：

“The {+,+,+} cone contains interacting bosonic BdG Hamiltonians whose elementary channels—pair hopping, cavity-induced bond squares, odd-parity interflavor pairing, and current interactions—already underpin a broad range of proposed chiral, paired, flat-band, and topological phenomena. The full Hamiltonians studied previously generally contain additional repulsive-density, hard-core, or complex-flux structures outside this cone. The present criterion therefore identifies sign-problem-free interacting completions of these physically established mechanisms, including a frustrated double-valley triangular-lattice model inaccessible to conventional world-line formulations.”

最小而有力的主文组合

  1. 只写一个完整哈密顿量：上面的三角晶格双谷模型，并逐项说明 T,X 偶、J,Π 奇及其平方符号。
  2. 紧接一句物理目标：双谷凝聚、Ising chirality 与 pair/current order 的竞争；引用双谷理论、chiral Bose liquid 与实验。
  3. 再用一句说明可实现相互作用不是凭空构造：pair-hopping 和 cavity bond-square 在现有模型中已经出现。
  4. 把其他 kagome/AB-cage/HOT/Kitaev/moat 候选放入 Supplemental 的“future applications”表，不稀释主线。
