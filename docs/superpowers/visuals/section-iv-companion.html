Recommended Main-Text Flow

1. State one benchmark family. Use a two-flavor Bose-Hubbard model on the triangular lattice with real positive hopping.
2. Mark the sign-free structure. For U1 <= 0 and U2 >= 0, the density channels admit the RP/TRS-compatible auxiliary-field form. Delta adds an onsite reflected pairing channel.
3. Present two cuts. Fig. 2 uses Delta=0 and number conservation. Fig. 3 turns on Delta and uses the paired Nambu formulation.
4. Move details to the SM. Keep ED cutoffs, block-size diagnostics, K-point conventions, and observable formulae out of the main text unless a compact definition is needed.
