# Sec. IV Rewrite Design

Date: 2026-06-20

Scope: rewrite `Sec. IV. Examples and applications` around the new triangular-lattice benchmark figures and move technical benchmark details to the Supplemental Material. This is a design checkpoint only. It does not change `main.tex` or `SM.tex`.

## Agreed Direction

Use a unified model and two benchmark cuts.

The main text should present one two-flavor triangular-lattice Bose-Hubbard family, then show:

1. The number-conserving cut, `Delta = 0`, benchmarked in Fig. 2 by scanning `U_2` and `U_1`.
2. The paired cut, `Delta != 0`, benchmarked in Fig. 3 by scanning `Delta` with the Nambu-basis BAFQMC formulation.

This replaces the current split between a proof-heavy model subsection and an unfinished benchmark subsection.

## Main-Text Hamiltonian

Write only the physical Hamiltonian in the main-text model equation. Do not introduce `n_{i,+}` or `n_{i,-}` notation. Do not write `H_mu = H_phys - mu N` in the model equation.

Candidate structure:

```tex
\hat H =
t\sum_{\langle ij\rangle,\alpha=b,c}
(\hat a_{\alpha i}^\dagger \hat a_{\alpha j}+\hc)
+U_1\sum_i(\hat n_{b,i}+\hat n_{c,i})^2
+U_2\sum_i(\hat n_{b,i}-\hat n_{c,i})^2
+\Delta\sum_i(\hat b_i^\dagger \hat c_i^\dagger+\hat b_i\hat c_i).
```

Use the report convention for the pairing term:

```tex
+\Delta(\hat b^\dagger \hat c^\dagger+\hat b\hat c).
```

The chemical potential `mu` appears only in benchmark parameter text and figure captions. The energy observable is the thermal average of the physical Hamiltonian, not of `H - mu N`.

## Sign-Free Structure In Main Text

The main text should apply the criteria from Sec. III rather than merely assert sign freedom.

For `Delta = 0`, include a compact density-channel HS explanation:

- For `U_1 <= 0`, the total-density interaction is decoupled by a real auxiliary field coupled equally to `n_b` and `n_c`.
- For `U_2 >= 0`, the relative-density interaction is decoupled by an imaginary auxiliary field coupled with opposite signs to `n_b` and `n_c`.
- The resulting number-conserving one-body slice has the reflected pair form already covered by the RP criterion, and equivalently the block-conjugate form used in the TRS criterion.
- This connects the example to the upper frustrated/RP-TRS region of Fig. 1. Use positive statements and avoid a negative framing such as "not ... but ...".

For `Delta != 0`, explain that the onsite pairing term is represented in the Nambu-basis Gaussian slice and satisfies the RP block criterion. Before implementing the final prose, verify the block sign against the report convention `+\Delta(b^\dagger c^\dagger+bc)`. If a convention or gauge transformation is needed to map this positive `Delta` to the RP block form, put the full algebra in the SM and keep the main text concise.

Mention the comparison to earlier bosonic/Bose-Fermi AFQMC carefully:

- The previous finite-temperature Bose-Fermi AFQMC method in Phys. Rev. A 86, 053606 does not cover the anomalous one-body propagators generated by the paired Nambu formulation used here.
- Add or update the reference only after verifying metadata against APS or DOI records.

## Frustration Statement

Use a positive, Fig. 1-compatible statement:

- Positive hopping on the triangular lattice places the benchmark in the frustrated local-weight setting.
- The density-channel HS slices obey RP/TRS, so BAFQMC samples them with nonnegative weights.
- Avoid the slogan that frustration is "not a no-go." Avoid attributing a misconception to the reader.

## Observables In Main Text

Define the four plotted observables compactly in the main text, using inline formulas where possible:

- `rho = <N_b+N_c>/N_s`.
- `E = <H>` for the physical Hamiltonian above; the panels plot `-E`.
- `S_SF(K) = N_s^{-2} sum_{ij,alpha} exp[iK.(r_i-r_j)] <a^dag_{alpha i} a_{alpha j}>`.
- `S_DW(K) = N_s^{-2} sum_{ij} exp[iK.(r_i-r_j)] <n_i n_j>`, where `n_i=n_{b,i}+n_{c,i}`.

The main text should not dwell on K-point coordinate conventions unless needed for clarity. Detailed geometry can go to the SM.
