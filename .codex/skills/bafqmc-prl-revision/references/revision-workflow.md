# Revision Workflow

Read the current text and nearby context before editing. Preserve its physical
purpose and author-approved logic, and make coherent changes within the task.

Do the research or derivation needed to establish correctness before compressing
it into prose. Check that the result reads smoothly for someone without the
authors' private context. Be confident and direct; remove unnecessary defensive
qualifications while preserving conditions that matter to the result.

Use the supporting guides when useful, without turning each edit into a full
manuscript audit or requiring a separate report.

Follow repository `AGENTS.md` for compilation, diff generation, validation, and
commits. Use the existing build scripts. The default diff baseline is the previous
substantive content-edit commit unless the user requests another comparison.

Check relevant warnings, citations, labels, figures, and surrounding text after
manuscript changes. For documentation-only changes, validate the documentation
instead of rebuilding the manuscript. Preserve unrelated user changes.
